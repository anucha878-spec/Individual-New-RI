| No | Component Type | Component Name | Default Value | Validation Rules/Action | Example | Remark |
|---|---|---|---|---|---|---|
| 1 | Button | ปิด | Enable | เมื่อกดปุ่มปิด ระบบจะทำการปิดหน้าจอรายละเอียดการพิจารณาอนุมัติครั้งที่ 1 |   |   |
| 2 | Button | บันทึกตรวจสอบ | Enable | เมื่อกดปุ่ม ระบบจะตรวจสอบรายการที่บันทึก โดยกรณีที่เลือกไม่ถูกต้อง จะต้องระบุสาเหตุ กรณีที่ไม่ระบุสาเหตุอย่างน้อย 1 รายการ ระบบจะไม่อนุญาตให้บันทึกตรวจสอบกรณีที่มีการระบุการตรวจสอบที่ตรวจสอบผ่านระบบแล้ว ระบบจะทำการบันทึกรายการจ่ายให้สถานะตรวจสอบ เป็น ตรวจสอบเรียบร้อยแล้ว แล้ว Refresh หน้าจอ Popup กลับมาอีกครั้ง ถ้าเป็นกรณีที่ทุกรายการมีสถานะตรวจสอบเป็น ตรวจสอบเรียบร้อยแล้ว ระบบจะ Enable ปุ่มยืนยันตรวจสอบให้กด |   |   |
| 3 | Button | ยืนยันตรวจสอบ | Disable | ระบบจะ Enable ปุ่มยืนยันตรวจสอบ ก็ต่อเมื่อสถานะตรวจสอบ ของทุกรายการเป็น ตรวจสอบเรียนร้อยแล้ว โดยผู้ใช้งานจะกดปุ่มยืนยันตรวจสอบ เพื่อให้ระบบบันทึก สถานะ Batch ตรวจสอบเป็น รออนุมัติ จากนั้นระบบจะทำการปิด Popup หน้าจอแล้วกลับมาแสดงหน้าจอ [PC-003-FC-001 หน้าจออนุมัติรายการเตรียมจ่ายครั้งที่ 1](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252076) ตามเดิม |   |   |
