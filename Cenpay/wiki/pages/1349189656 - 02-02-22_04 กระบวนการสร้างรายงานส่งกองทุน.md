## Post-conditions : System

1. สร้างเอกสารในรูปแบบ "{Fund_Detail_Statement}+_{CURRENT_DATE}.xlxs"
2. อัพโหลดเอกสารเข้าสู่ระบบ DMS และจัดเก็บข้อมูลเข้าสู่ตาราง [tx_batch_fund_document](/display/RDSCPENH/tx_batch_fund_document)

## Post-conditions : Part User

1. ระบบ สร้างไฟล์เป็นนามสกุล .xlxs
2. User บันทึกข้อมูลเป็น .txt (โดยต้องลบข้อมูล Header ด้วยตัวเอง บันทึกส่งกองทุนเฉพาะรายละเอียดเท่านั้น และมีคอลัมน์ของลำดับ เป็น Null)
3. User ต้องแปลงไฟล์เป็น UTF-8 with BOM
