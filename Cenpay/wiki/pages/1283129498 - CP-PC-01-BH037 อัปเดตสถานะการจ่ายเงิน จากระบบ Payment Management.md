## Objectives

- เพื่อนำเข้าข้อมูลรายละเอียดการทำจ่าย จากระบบ Payment Management
- เพื่ออัปเดตข้อมูลรายการจ่ายที่ระบบต้นทางให้สอดคล้องกัน
- เพื่อ Trigger การกระบวนการหลังทำจ่าย
- เพื่อส่ง Line หรือ SMS Notification ให้ลูกค้ารับทราบผลการทำจ่ายเงิน

## Process Overview

1. List ข้อมูลโดย Query ข้อมูล Master Transaction ที่ระบบ Cenpay ที่สถานะการจ่ายเป็นอย่างใดอย่างหนึ่งต่อไปนี้
  1. รอยืนยันทำจ่าย (ฝ่ายการเงิน)
  2. รอตรวจสอบ (ฝ่ายการเงิน)
  3. รออนุมัติจ่าย (ฝ่ายการเงิน)
  4. รอบันทึกผลการจ่าย (ฝ่ายการเงิน)
2. Batch ทำการส่ง List ข้อมูลไปตรวจสอบเพื่อรับสถานะและข้อมูลทำจ่ายโดยการเรียก [WS ตรวจสอบข้อมูลการจ่ายเงินจากระบบ Payment Management](/pages/viewpage.action?pageId=1284112423) จากระบบ Payment Management
3. Batch ดำเนินการบันทึกรายการจ่ายไม่สำเร็จ
4. ระบบจะทำการเรียก Web Service เพื่ออัปเดตข้อมูลรายการจ่ายที่ระบบต้นทาง
5. ระบบจะทำกาส่ง Line/SMS Notification ให้ลูกค้า
6. ระบบจะทำงานทุก 5 นาที

## Preconditions

1. รายการ Transaction ต้องมีสถานะที่อยู่ระหว่างกระบวนการทำจ่ายของฝ่ายการเงินที่ระบบ Payment Management โดยมีสถานะเป็นอย่างใดอย่างหนึ่งต่อไปนี้เท่านั้น
  1. รอยืนยันทำจ่าย (ฝ่ายการเงิน)
  2. รอตรวจสอบ (ฝ่ายการเงิน)
  3. รออนุมัติจ่าย (ฝ่ายการเงิน)
  4. รอบันทึกผลการจ่าย (ฝ่ายการเงิน)
  5. จ่ายสำเร็จ >> R2. ปรับแก้ไขเรื่องยกเลิกเช็คในกระบวนการบันทึกผลการจ่าย โดยการแยกออกมาเป็น Batch สำหรับเช็ค

8. หลังจาก Run Batch สำเร็จ Update ข้อมูลที่ตาราง [Table : lg_batch_process](/display/RDSCP/Table+%3A+lg_batch_process) (benefitbank)FieldDescriptionValuestatusสถานะการทำงานกรณี Success บันทึก 'S' กรณี Fail บันทึก 'F'error_messageรายละเอียดของการทำงานที่ Errorบันทึกข้อความ Exception กรณีมี Errorprocess_end_dateวันที่และเวลา Batch ประมวลผลสิ้นสุดวันและเวลาปัจจุบันupdated_dateวันที่แก้ไขรายการล่าสุดวันและเวลาปัจจุบันupdated_byผู้แก้ไขรายการล่าสุดFix : SYSTEM

## Postconditions

1. ระบบ Cenpay รับรู้สถานะการจ่ายเงินของรายการธุรกรรม
2. ระบบต้นทางของธุรกรรมรับรู้สถานะการจ่ายเงินของรายการธุรกรรม
3. ระบบ AS400 รับรู้ความเคลื่อนไหวกรมธรรม์ ในส่วนของธุรกรรมการจ่ายเงินผลประโยชน์
4. ลูกค้ารับทราบผลการจ่ายเงินผ่านทาง Line Notification หรือ SMS Notification
5. หน่วยงานที่เกี่ยวข้องรับทราบผลการจ่ายเงิน โดยได้รับการแจ้งอีเมลล์เพื่อทำกระบวนการจ่ายใหม่ กรณีทำจ่ายไม่สำเร็จ
