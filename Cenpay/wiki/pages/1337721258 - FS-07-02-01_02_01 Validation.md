1. Validation :
  1. ตรวจสอบข้อมูลที่จำเป็นต้องระบุดังนี้
    - ข้อมูลทั่วไป
      - ประเภทคำร้อง
      - เลขที่กรมธรรม์
    - เอกสารประกอบคำร้อง
      - เอกสารแนบ
  3. ตรวจสอบข้อมูลยอดเงินจ่ายสุทธิ : ยอดเงินผลประโยชน์สุทธิ รวมทั้งสิ้น ([tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).total_benefit_amount) กรณีน้อยกว่าเท่ากับ 0.00 ให้ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้Alert CodeReplace Value[err_pr_011](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
  4. ตรวจสอบข้อมูลผู้รับเงิน
    1. ตรวจสอบช่องทางการรับเงิน กรมบังคับคดี กรณี**ไม่ใช่**โอนเงิน ('LT','LC') ให้ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้ Alert CodeReplace Value[err_pr_009](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
    2. กรณีช่องทางการรับเงิน กรมบังคับคดี เท่ากับ โอนเงิน ('LT') แต่**ไม่**มีข้อมูลเลขที่บัญชี ให้ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้ Alert CodeReplace Value[err_pr_010](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
    3. กรณีช่องทางการรับเงิน กรมบังคับคดี เท่ากับ เช็คบริษัท ('LC') และ ชื่อผู้รับเงิน เท่ากับ อื่นๆ แต่**ไม่ได้ระบุข้อมูลผู้รับเงิน** ให้ระบบทำการ focus cursor และแสดงข้อความแจ้งเตือนเป็นตัวหนังสือสีแดง ที่ใต้ field นั้นๆ ด้วย Alter Code ดังนี้Alert CodeReplace Value[err_pr_012](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
    4. หากไม่เข้าเงื่อนไข ให้ระบบทำการตรวจสอบข้อ c. ต่อไป
2. ตรวจสอบว่ามีการยื่นคำร้องซ้ำหรือไม่ **(หน้าแก้ไขคำร้องไม่ต้องตรวจสอบ)**
  1. นำประเภทคำร้อง และเลขที่กรมธรรม์ ไปค้นหารายการคำร้องที่ Table [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request) โดยสถานะคำร้องจะต้องไม่ใช่ 'ยกเลิก' หรือ 'ยกเลิกรายการจ่าย' <![CDATA[select policy_no, request_code, status_code from tx_request where request_code = :requestCode and policy_no = :policyNo and status_code not in (&#39;CAN&#39;, &#39;SPP&#39;)]]>
