## List of Batch Processes

| Batch ID | Batch Name | Description | Target Time |
|---|---|---|---|
| BATCH-001 | [นำเข้าข้อมูลการจ่ายเงินคืนทันที APU จากระบบ APL Improvement เข้าสู่ระบบ Centralized Payment](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1255703321) | นำเข้าข้อมูลการจ่ายเงินคืนทันที APU จากระบบ APL Improvement เข้าสู่ระบบ Centralized Payment ในส่วนของข้อมูลส่วนกลาง | ทุกวันเวลา ช่วงเช้า (04.00 น.) |
| BATCH-002 | [นำเข้าข้อมูลการจ่ายเงินคืนทันที APU จากฐานข้อมูล Centralized Payment เข้าสู่กระบวนการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1273267113) | นำเข้าข้อมูลการจ่ายเงินคืนทันที APU จากฐานข้อมูล Centralized Payment ในส่วนของข้อมูลส่วนกลาง เข้าสู่กระบวนการเตรียมจ่าย | ทุกวันเวลา ช่วงเช้า (05.00 น.) |
| BATCH-003 | [Update ข้อมูลการจ่ายเงินที่ติด CIS](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1273692570) | Update ข้อมูลการจ่ายเงินที่ติด CIS โดยการตรวจสอบกับข้อมูลที่ระบบ CIS ว่าข้อมูลที่ติดอยู่ผ่านการอนุมัติแล้วหรือยัง เพื่อ Update รายการพร้อมสู่การเตรียมจ่าย | ทุกๆ X นาที |
| BATCH-004 | [ข้อมูลการจ่ายเงินสำเร็จ หรือไม่สำเร็จ สำหรับเงินจ่ายคืนทันที APU ไปยังระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1273692752) | Update ข้อมูลการจ่ายเงินสำเร็จ หรือไม่สำเร็จ สำหรับเงินจ่ายคืนทันที APU ไปยังระบบ AS400 | ทุกๆ X นาที หรือ ตามรอบเวลาที่กำหนด |
