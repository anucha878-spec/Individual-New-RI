## Process

1. Update สถานะรายการคำร้องที่ตาราง [tx_cp_rep](http://wiki.thaisamut.co.th/display/RDSCPENH/03_15+tx_cp_rep) ที่ DB: [benefitregister](http://wiki.thaisamut.co.th/display/RDSCPENH/03.+DB+%3A+benefitregister) ดังนี้**Update** <![CDATA[UPDATE tx_cp_rep rep SET status_code = :statusCode, updated_by = :createdBy, updated_date = :createdDate FROM tx_cp_rep_mapping_reqno map INNER JOIN tx_cp_rep_source res ON map.tx_cp_rep_id = res.tx_cp_rep_id WHERE rep.id = map.tx_cp_rep_id AND map.request_no = :requestNo ----- Centralize Payment Enhance Phase 2 Add by kanawoot.ou 20/07/2026 ---- AND res.oper_ref_no = :operRefNo;]]>
2. Insert Log Process ข้อมูลคำร้องที่ตาราง [lg_cp_rep_process](http://wiki.thaisamut.co.th/display/RDSCPENH/03_26+lg_cp_rep_process) ตามจำนวนรายการทะเบียนรอจ่ายใหม่ ที่ DB: [benefitregister](http://wiki.thaisamut.co.th/display/RDSCPENH/03.+DB+%3A+benefitregister) ดังนี้**จำนวนรายการที่ต้อง Insert** <![CDATA[select distinct res.tx_cp_rep_id from tx_cp_rep_mapping_reqno map inner join tx_cp_rep_source res on map.tx_cp_rep_id = res.tx_cp_rep_id where map.request_no = :requestNo and res.oper_ref_no = :operRefNo; ]]> Field NameBusiness RuleidAuto Running จากระบบtx_cp_rep_id**----- Centralize Payment Enhance Phase 2 Add by kanawoot.ou 20/07/2026 ----** tx_cp_rep_id จากเงื่อนไขการค้นหารายการทะเบียนรอจ่ายใหม่status_codeInput Entity Name*: statusCode*created_byInput Entity Name*: createdBy*created_dateInput Entity Name*: createdDate*
3. ตรวจสอบสถานะที่จะอัพเดท
  - กรณีอัพเดทสถานะเป็น 'รอดำเนินการ' (input statusCode = 'PND') ให้ทำการเคลียร์ค่า [tx_cp_rep](http://wiki.thaisamut.co.th/display/RDSCPENH/03_15+tx_cp_rep).request_no ออก
