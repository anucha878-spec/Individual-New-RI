## Screen Overview

### วัตถุประสงค์ (Objective)

เพื่อให้ฝ่ายปฏิบัติการดูรายละเอียดรายกรมธรรม์ (Detail) ที่อยู่ภายใต้รอบ Header ที่เลือกไว้จากหน้าจอหลัก ตรวจสอบยอดเงินรับ/หัก/โอนสุทธิ และ Preview เอกสาร PDF ก่อนที่ระบบจะ Generate เอกสารจริงหลังยืนยัน

### ผู้ใช้งาน (Target Users)

เจ้าหน้าที่ฝ่ายปฏิบัติการ (Operations) กลุ่มเดียวกับหน้าจอหลัก LB03

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- ผู้ใช้กดปุ่ม "ดูรายละเอียด" มาจากแถว Header ใดแถวหนึ่งของหน้าจอหลัก LB03 แล้ว (ทุกสถานะเข้าดูได้ ไม่จำกัดเฉพาะ `รอยืนยันสร้างจดหมาย`)
- มีข้อมูล Detail ผูกกับ Header แถวนั้นอยู่ในตาราง `TX_LETTER_DETAIL` แล้ว (ผ่าน FK `LETTER_SUMMARY_ID`)

### การกระทำกับหน้าจอ (Actions)

- ระบุเงื่อนไขค้นหาเพิ่มเติม (วันที่ครบกำหนดรับเงิน, ประเภทกรมธรรม์, ประเภทการจ่าย, เลขที่กรมธรรม์) แล้วกด "ค้นหา" — field "วันที่สร้างจดหมาย ตั้งแต่/ถึง" ถูก pre-fill และ disable ตามช่วงต้น-ปลายเดือนของ "ปี/เดือนที่ประมวลผล" ของ Header แถวที่เลือกมา แก้ไขไม่ได้
- แก้ไข "วันที่ครบกำหนดรับเงิน ตั้งแต่/ถึง" ได้ แต่ต้องอยู่ในขอบเขตช่วงของ Header แถวนั้นเท่านั้น
- กดปุ่ม "Preview PDF" จากตารางหลัก → เปิด PDF Preview ของรายการนั้น
- กดลิงก์ "← กลับ" เพื่อกลับสู่หน้าจอหลัก (Header) ของ LB03

### เงื่อนไขหลังการทำงาน (Post-Condition)

- หน้าจอนี้เป็น **read-only** ไม่มีการเปลี่ยนสถานะข้อมูลใดๆ — การยืนยัน/ยกเลิกทำที่หน้าจอหลัก (Header) เท่านั้น
- การเปิด PDF Preview ไม่กระทบข้อมูลในตาราง

### การจัดการข้อผิดพลาด (Exceptional Handling)

- ค้นหาแล้วไม่พบข้อมูล → แสดงข้อความ "ไม่พบรายการที่ตรงกับเงื่อนไข" (ไม่ error)
- ผู้ใช้แก้ไข "วันที่ครบกำหนดรับเงิน" นอกขอบเขตของ Header แถวที่เลือก (ก่อนวันเริ่มต้น/เกินวันสิ้นสุดของรอบ) → แสดง error message และ reset กลับเป็นค่าขอบเขตที่ใกล้ที่สุด
- **[TBD]** ข้อมูลกรมธรรม์ไม่ครบ (เช่น ไม่มีที่อยู่จัดส่ง) → ต้อง flag ไม่ให้ Preview/ยืนยันได้จนกว่าจะแก้ไข ยังไม่ยืนยันจาก BA ว่าจะ block ที่หน้านี้หรือหน้าหลัก

## หมายเหตุ / Open Items

- อ้างอิงจาก REQ-pension-letter.md (feature_id: CP-LTR-001) — FR-03 (ดูรายละเอียด) และ FR-04 (Preview เอกสาร)
- FR-03 อ้างอิงจากหน้าจอระบบเดิมจริงของ LD14 เป็นฐานออกแบบ (ใช้โครงสร้างร่วมกัน) — ส่วน PDF Preview เป็น gap ที่ต้องพัฒนาใหม่ทั้งหมดสำหรับทั้ง LB03 และ LD14 (ระบบเดิมมีแค่ popup ตัวเลขสรุป ไม่มี PDF Preview จริง)
- ยังไม่ยืนยัน: การ block ไม่ให้ Preview/ยืนยันเมื่อข้อมูลกรมธรรม์ไม่ครบ (เช่น ไม่มีที่อยู่จัดส่ง) ควร flag ที่หน้า Detail นี้หรือหน้าหลัก
- ยังไม่ยืนยัน: ปุ่ม "Export Excel" ของหน้าตาราง Detail โดยรวม (เดิมอยู่ที่ PDF Preview ถูกถอนออกแล้ว ต้องยืนยันตำแหน่งใหม่กับ BA)
- รูปแบบหน้าจอ/field ในหน้านี้เป็นฉบับร่างจาก Requirement เท่านั้น ยังไม่ได้อ้างอิง Data Source/API จริงแบบละเอียดเหมือนหน้าจออื่นในระบบ — ต้องเติมภายหลังเมื่อยืนยัน backend design
