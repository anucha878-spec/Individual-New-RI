| ส่วนแสดงข้อมูล |
|---|
| No |   | Component Name | Action / Data Value | Example | Remark |
| 1 | Label | เหตุผลยกเลิกเช็ค | แสดงข้อความเหตุผลยกเลิกเช็ค | สินไหมคืนเช็ค เนื่องจากผู้เอาประกันต้องการเปลี่ยนแปลงช่องทางการรับเงินชดเชยรายวัน |   |
| 2 | Button | Mode Add : ยกเลิก | Enable : เสมอ เมื่อกดยกเลิก ให้กลับสู่ [หน้าจอบันทึกผลจ่ายเช็ค Manual](/pages/viewpage.action?pageId=1271988606) โดยค้างรายการ Checkbox ที่เลือกไว้ และค้างเงื่อนไขค้นหาข้อมูลที่เลือกไว้ |   |   |
| 3 | Button | Mode Add : บันทึก | Enable : เมื่อมีการระบุข้อความตัวอักษร Disable : เมื่อเป็นค่าว่างให้แสดงแจ้งเตือน "ยืนยันบันทึกข้อมูล หรือไม่"เมื่อกดยกเลิกให้แสดงหน้าจอเดิมเมื่อกดตกลงให้กลับสู่ [หน้าจอบันทึกผลจ่ายเช็ค Manual](/pages/viewpage.action?pageId=1271988606) ให้นำข้อความเหตุผลไปแสดงในคอลัมน์ "เหตุผลยกเลิกเช็ค" โดยค้างรายการ Checkbox ที่เลือกไว้ และค้างเงื่อนไขค้นหาข้อมูลที่เลือกไว้ |   |   |
| 4 | Button | Mode View : ปิด | Enable : เสมอ เมื่อกดปุ่มระบบจะปิดหน้าจอ Popup กลับสู่ [หน้าจอบันทึกผลจ่ายเช็ค Manual](/pages/viewpage.action?pageId=1271988606) โดยค้างรายการ Checkbox ที่เลือกไว้ และค้างเงื่อนไขค้นหาข้อมูลที่เลือกไว้ |   |   |
