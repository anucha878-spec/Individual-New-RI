ระบบจะส่งรายการคำร้องไปที่หน้าจอรวมการจ่ายของฝ่ายปฏิบัติการ ของระบบ Cenpay แบบ Real Time ดังนี
1. Validation
  1. กรณีที่ไม่ได้ระบุหมายเหตุการโอนเงินแบบด่วน ให้ระบบทำการ focus cursor และแสดงข้อความแจ้งเตือนเป็นตัวหนังสือสีแดง ที่ใต้ field นั้นๆ ด้วย Alter Code ดังนี้ Alter CodeReplace Value[wrn_com_002](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
  2. กรณีระบุข้อมูลที่จำเป็นครบถ้วน ให้ระบบทำการตามข้อ 2. ต่อไป
2. Update ข้อมูลที่ Table : **[tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request)**No.FieldData SourceCondition [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).id = Input [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).id ที่ส่งมาจากหน้าจอ [FS-05-01-01 หน้าจอค้นหา/ ตรวจสอบรายการคำร้อง](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1303740846)1payment_dateวันที่จ่ายเงินจากหน้าจอ 2status_codeFix 'WAV' (รอเตรียมจ่าย (ปฎิบัติการ)) 3updated_byLogin User 4updated_by_fullnameLogin User 5updated_datesystemDate
3. Insert ข้อมูลที่ Table : **[lg_request_process](http://wiki.thaisamut.co.th/display/RDSCPENH/03_08+lg_request_process)**No.FieldData Source1status_codeFix 'WAV' (รอเตรียมจ่าย (ปฎิบัติการ))2remarktext จากการเลือก Dropdown List หมายเหตุการโอนเงินแบบด่วน3created_byผู้สร้างข้อมูล (เก็บ User ที่ใช้ Login เข้าระบบ เช่น Ocean.co)4created_by_fullnameผู้สร้างข้อมูล (เก็บ fullname ที่ใช้ Login เข้าระบบ เช่น สมชาย ใจดี)5created_dateวันที่และเวลาสร้างข้อมูล
4. ส่งรายการคำร้องไปที่หน้าจอรวมการจ่ายของฝ่ายปฏิบัติการ ของระบบ Cenpay แบบ Real Time โดยใช้ [Process ส่งรายการคำร้องไปที่หน้าจอรวมการจ่ายของฝ่ายปฏิบัติการ กรณีโอนด่วน](/pages/viewpage.action?pageId=1333395562) และส่ง Input ดังนี้inputvaluerequestIdInput [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).id ที่ส่งมาจากหน้าจอ [FS-05-01-01 หน้าจอค้นหา/ ตรวจสอบรายการคำร้อง](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1303740846)
