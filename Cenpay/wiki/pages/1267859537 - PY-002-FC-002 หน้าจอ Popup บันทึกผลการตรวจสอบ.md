### วัตถุประสงค์ (Objective)

- เพื่อให้ผู้ใช้งานสามารถระบุผลการตรวจสอบที่ได้จากธนาคาร

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ฝ่ายการเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ผู้ใช้งานจะต้องกดปุ่ม บันทึกผลการตรวจสอบ ที่หน้าจอหลัก
  - รายการที่เลือกจะต้องมีสถานะดำเนินการเป็น รอตรวจสอบผล

### การกระทำกับหน้าจอ (Actions)

- ยกเลิกบันทึกผลการตรวจสอบ
- ยืนยันบันทึกผลการตรวจสอบ

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - กรณียกเลิก ระบบจะล้างข้อมูลที่กรอกในหน้าจอนี้ทั้งหมด และกลับไปยังหน้าจอหลัก
  - กรณีบันทึก
    - กรณีไม่ถูกต้องระบบจะปรับสถานะดำเนินการเป็น**ส่งกลับตรวจสอบ** และกลับไปยังหน้าจอหลัก
    - กรณีถูกต้องระบบจะปรับสถานะดำเนินการเป็น**รออนุมัติ** และส่งข้อมูลไปประมวลผลข้อมูลบัญชี EDW และส่งข้อมูลไปยังหน้าจอ [CP-PY-005 : อนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1266811252)
    - ส่งอัปเดตสถานะรายการที่ระบบ Cenpay ทุกรายการธุรกรรมย่อยภายใต้ Batch การเงิน เพื่อให้รับทราบสถานะรายการปัจจุบัน

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการที่ถูกเปลี่ยนแปลงสถานะดำเนินการ ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการเปลี่ยนแปลงข้อมูล" และกลับสู่หน้าจอหลัก
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"

### รายละเอียดเงื่อนไขการตรวจสอบ

| ส่วนแสดงข้อมูลผลการค้นหา |
|---|
| No |   | Component Name | Action / Data Value | Example | Remark |
| 1 | Radio Button | บันทึกผลการตรวจสอบ* | แสดง Required Fieldสามารถเลือกข้อมูลดังนี้ถูกต้องไม่ถูกต้อง |   |   |
| 2 | Button | ยกเลิก | Enable : เสมอกรณีมีการเลือก บันทึกผลการตรวจสอบ แล้ว ให้แสดงแจ้งเตือน "ยกเลิกบันทึกผลการตรวจสอบ"เมื่อกดยกเลิกให้แสดงหน้าจอเดิมเมื่อกดตกลงให้กลับสู่หน้าจอ [CP-PY-002: Generate Batch Payment](/display/RDSCPENH/CP-PY-002%3A+Generate+Batch+Payment) โดยค้างเงื่อนไขค้นหาข้อมูลที่เลือกไว้ |   |   |
| 3 | Button | บันทึก | Enable : เสมอให้แสดงแจ้งเตือน "ยืนยันการบันทึกผลการตรวจสอบ"เมื่อกดยกเลิกให้แสดงหน้าจอเดิมเมื่อกดตกลงกรณีเลือกถูกต้อง ให้บันทึกสถานะดำเนินการเป็น รออนุมัติระบบส่งข้อมูลไปประมวลผลข้อมูลบัญชี EDW และส่งข้อมูลไปยังหน้าจอ [CP-PY-005 : อนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1266811252)ระบบส่งอัปเดตสถานะรายการที่ระบบ Cenpay หน้าจอ [PC-001-FC-001 หน้าจอรวมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252010), [หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252003) และ หน้าจอ [AC-001-FC-002 หน้าจอรายละเอียด Support Booking](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1272906268)รายการธุรกรรมย่อยภายใต้ Batch การเงินเป็น รออนุมัติจ่าย (ฝ่ายการเงิน) กรณีเลือกไม่ถูกต้อง ให้บันทึกสถานะดำเนินการเป็น ส่งกลับตรวจสอบ |   |   |
