# Screen Overview

### วัตถุประสงค์ (Objective)

- เพื่อให้ผู้ใช้งานสามารถอัปโหลดผลไม่ผ่านการตรวจสอบจากธนาคาร
- เพื่อให้ผู้ใช้งานสามารถระบุผู้รับเงินที่ไม่ผ่านตรวจสอบแบบ Manual

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ฝ่ายการเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ผู้ใช้งานจะต้องกดปุ่ม บันทึกรายการไม่ผ่านตรวจสอบ ที่หน้าจอหลัก
  - รายการที่เลือกจะต้องมีสถานะดำเนินการเป็น ส่งกลับตรวจสอบ

### การกระทำกับหน้าจอ (Actions)

- อัปโหลดไฟล์ผลการตรวจสอบจากธนาคาร
- ระบุผู้รับเงินที่ไม่ผ่านตรวจสอบแบบ manual
- ยกเลิกบันทึกรายการไม่ผ่านตรวจสอบ
- บันทึกรายการไม่ผ่านตรวจสอบ

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - กรณีอัปโหลดไฟล์จากธนาคาร ระบบจะตรวจสอบรายชื่อผู้รับเงินที่ไม่ผ่านตรวจสอบจากธนาคาร และแสดงข้อมูลให้ถูกต้อง
  - กรณีระบุผู้รับเงิน ระบบจะนำผู้ใช้งานไปหน้าจอที่เกี่ยวข้องได้
  - กรณียกเลิก ระบบจะล้างข้อมูลที่กรอกในหน้าจอนี้ทั้งหมด และกลับไปยังหน้าจอหลัก
  - กรณีบันทึก ระบบจะปรับสถานะดำเนินการเป็น **รอดำเนินการใหม่**เพื่อให้ผู้ใช้งาน Generate txt,csv file ธนาคารอีกครั้ง

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีอัปโหลดไฟล์จากธนาคาร แต่ไม่มีข้อมูลเลข reference เดียวกันกับข้อมูลใน Batch การเงิน ระบบจะแสดง Popup แจ้งเตือน "กรุณาตรวจสอบไฟล์ที่อัปโหลดไม่ตรงกับข้อมูลใน Batch"
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการที่ถูกเปลี่ยนแปลงสถานะดำเนินการ ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการเปลี่ยนแปลงข้อมูล" และกลับสู่หน้าจอหลัก
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
