### วัตถุประสงค์ (Objective)

- เพื่อแสดงข้อมูลรายการรออนุมัติจ่ายและบันทึกบัญชี
- เพื่อให้ผู้ใช้งานสามารถค้นหาและดูข้อมูลการจ่ายได้ตามเงื่อนไขที่กำหนด

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่การเงิน (Authorizer)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Authorizer)
  - ระบบจะต้องสามารถเชื่อมต่อกับฐานข้อมูลเพื่อดึงข้อมูลรายการ Voucher ที่ยืนยันตรวจสอบมาจากหน้าจอ
    - [PY-002-FC-002 หน้าจอ Popup บันทึกผลการตรวจสอบ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1267859537)
    - [PY-004-FC-002 หน้าจอ Popup ตรวจสอบเช็คและ Paperbase อื่นๆ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1269858926)

### การกระทำกับหน้าจอ (Actions)

- กดปุ่ม "ล้างเงื่อนไข" เพื่อล้างเงื่อนไขการค้นหา
- กดปุ่ม "ค้นหา" เพื่อค้นหาข้อมูลตามเงื่อนไข
- กด Checkbox เพื่อทำรายการ ไม่อนุมัติ หรือ อนุมัติ
- กดปุ่ม "ไม่อนุมัติ" เพื่อไม่อนุมัติจ่าย
- กดปุ่ม "อนุมัติ" เพื่ออนุมัติจ่าย
- กดปุ่ม "Export Data" เพื่อ Export ข้อมูลที่ค้นหาในรูปแบบไฟล์ Excel (.xlsx)
- กด Icon ![img](http://wiki.thaisamut.co.th/download/attachments/1271234731/2025-08-04_101001.png?version=1&modificationDate=1754277018380&api=v2) "รายละเอียด" เพื่อแสดงรายละเอียด Support Booking
- กด Icon ![img](http://wiki.thaisamut.co.th/download/attachments/1271234731/2025-08-04_101001.png?version=1&modificationDate=1754277018380&api=v2) "คู่บัญชี" เพื่อแสดงรายละเอียดคู่บัญชี
- กด Icon ![img](http://wiki.thaisamut.co.th/download/thumbnails/1271234731/2022-10-12_132317.png?version=1&modificationDate=1754276911478&api=v2) "เอกสารแนบ" เพื่อแสดงรายการเอกสารของ Batch Number ฝ่ายการเงิน
- กด Icon ![img](/download/thumbnails/1273267201/2023-03-31_135952.png?version=1&modificationDate=1756865913302&api=v2) "Payment Date" เพื่อแก้ไขวันที่ตัดเงิน (แสดงใน EDW booking)

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - เมื่อผู้ใช้งานกดปุ่ม ค้นหา หน้าจอจะแสดงรายการ Voucher ที่ตรงตามเงื่อนไขการค้นหา และจัดเรียงตาม Reference Number ฝ่ายการเงิน, Batch Number ฝ่ายการเงิน, ช่องทางการจ่ายเงิน, Request Payment Date
  - เมื่อผู้ใช้งานกดปุ่ม ล้างเงื่อนไข เงื่อนไขการค้นหาทั้งหมดจะถูก Reset เป็นค่าเริ่มต้น
  - เมื่อผู้ใช้งานกดปุ่ม ไม่อนุมัติ ระบบจะส่งรายการกลับไปกระบวนการบันทึกผลตรวจสอบ Format ที่หน้าจอ Generate Batch Payment หรือ กระบวนการพิมพ์เลขที่เช็คที่หน้าจอ Paper-based Payment
  - เมื่อผู้ใช้งานกดปุ่ม อนุมัติ ระบบจะ
    - Trigger บันทึกบัญชีไปยังระบบ EDW และ Generate GL Text File SUN รวมถึงส่งรายการเข้าไปรอดำเนินการกระบวนการบันทึกผลการจ่ายเงิน
  - เมื่อผู้ใช้งานกดปุ่ม Download Excel ระบบจะสร้างรายงานและ Download ลง Target Local Path ที่เครื่องของผู้ใช้งาน

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานไม่ระบุเงื่อนไขการค้นหาอย่างน้อยหนึ่งอย่าง เมื่อกดปุ่มค้นหาระบบจะแสดง Popup ข้อความแจ้งเตือน "กรุณาระบุเงื่อนไขการค้นหาข้อมูล"
  - กรณีระบุวันที่ในเงื่อนไขการค้นหาไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือน "ระบุช่วงวันที่ได้ไม่เกิน 120 วัน" ใต้ Text Box
  - กรณีไม่มีข้อมูลตามเงื่อนไขการค้นหา ระบบจะแสดงตารางผลลัพธ์ว่างเปล่า และแสดงข้อความที่ตาราง "ไม่พบข้อมูล"
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการที่ถูกเปลี่ยนแปลงสถานะดำเนินการ ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการเปลี่ยนแปลงข้อมูล" และ Refresh หน้าจอและดึงข้อมูลมาแสดงผลใหม่อีกครั้ง
  - กรณีผู้ใช้งานเลือก ไม่อนุมัติรายการ ที่สถานะดำเนินการไม่ใช่ รออนุมัติ ระบบจะแสดงแจ้งเตือน "เนื่องจากสถานะบางรายการเปลี่ยนเป็น อนุมัติจ่ายเงิน หรือ อนุมัติ เรียบร้อยแล้ว กรุณาตรวจสอบข้อมูลและทำรายการใหม่อีกครั้ง"
  - กรณีผู้ใช้งานเลือก อนุมัติรายการ ที่สถานะดำเนินการไม่ใช่ รออนุมัติ ระบบจะแสดงแจ้งเตือน "เนื่องจากสถานะบางรายการเปลี่ยนเป็น อนุมัติจ่ายเงิน หรือ อนุมัติ เรียบร้อยแล้ว กรุณาตรวจสอบข้อมูลและทำรายการใหม่อีกครั้ง"
  - กรณีเกิดปัญหาในการเชื่อมต่อกับฐานข้อมูลเมื่อผู้ใช้งานกดปุ่มค้นหา ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถเชื่อมต่อฐานข้อมูลได้ กรุณาลองใหม่อีกครั้ง"
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
  - กรณีผู้ใช้งานอนุมัติ Voucher ประเภทการจ่าย API Payment แต่ไม่สามารถดึงข้อมูลเบอร์โทรศัพท์ ระบบจะแสดงแจ้งเตือน "ไม่พบข้อมูลเบอร์โทรศัพท์ กรุณาติดต่อผู้ดูแลระบบ"
