| 3 | Button | บันทึก | กรณีไม่มีรายการ Upload File ระบบจะ Disable ปุ่มกรณีมีรายการ Upload File ระบบจะ Enable ปุ่มเมื่อกดปุ่มระบบจะดำเนินการดังนี้ระบบจัดเก็บไฟล์เข้าสู่ระบบ DMSระบบดำเนินการประมวลผลการโอนเงินจากไฟล์ข้อมูลที่อัปโหลดกรณีพบข้อมูลผลการโอนเงิน (อ้างอิงการอ่านข้อมูลจาก เลขที่อ้างอิง, เลขที่บัญชี และจำนวนเงินจ่าย)ปรับสถานะดำเนินการระดับ Transaction จากสถานะ รอทำจ่าย เปลี่ยนเป็น จ่ายสำเร็จ หรือ จ่ายไม่สำเร็จ (อ้างอิงตามผลการโอนเงิน)ปรับสถานะดำเนินการระดับ Voucher ที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1271234731) หากรายการระดับ Transaction ที่ถูกอนุมัติจ่ายภายใต้ Voucher นั้นถูกบันทึกผลครบทุกรายการ ดังนี้ ปรับจาก อนุมัติจ่ายเงิน เป็น จ่ายสำเร็จ - กรณีภายใต้ Voucher นั้นสำเร็จทุกรายการปรับจาก อนุมัติจ่ายเงิน เป็น จ่ายสำเร็จบางส่วน - กรณีภายใต้ Voucher นั้นสำเร็จบางส่วน และระบบจะส่งข้อมูลไปประมวลผลข้อมูลบัญชี EDW เพื่อสร้างรายการบันทึกบัญชีจ่ายไม่สำเร็จ (พร้อมทั้งรับคืนค่าธรรมเนียมธนาคาร) ที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1271234731) เพิ่มเป็นรายการใหม่ปรับจาก อนุมัติจ่ายเงิน เป็น จ่ายไม่สำเร็จ - กรณีภายใต้ Voucher นั้นไม่สำเร็จเลย และระบบจะส่งข้อมูลไปประมวลผลข้อมูลบัญชี EDW เพื่อสร้างรายการบันทึกบัญชีจ่ายไม่สำเร็จ (พร้อมทั้งรับคืนค่าธรรมเนียมธนาคาร) ที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1271234731) เพิ่มเป็นรายการใหม่ดำเนินการอัปเดตข้อมูลกลับที่ระบบ Cenpay หากรายการระดับ Transaction ที่ถูกอนุมัติจ่ายภายใต้ Batch การเงิน นั้นถูกบันทึกผลครบทุกรายการ ดังนี้อัปเดตสถานะรายการธุรกรรมย่อยระดับ Transaction ที่ Module เตรียมจ่าย ปฏิบัติการ : [PC-001-FC-001 หน้าจอรวมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252010) และ [หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252003) ดังนี้จ่ายเงินสำเร็จ กรณีเป็นรายการที่ธนาคารโอนเงินสำเร็จโอนเงินไม่สำเร็จ กรณีเป็นรายการที่ธนาคารโอนเงินไม่สำเร็จ พร้อมทั้ง สร้างรายการที่หน้าจอ [PC-004-FC-001 หน้าจอยืนยันการโอนเงิน](/pages/viewpage.action?pageId=1278017914) โดยระบุสถานะเป็น โอนเงินไม่สำเร็จ หากรายการทำจ่ายไม่สำเร็จ จากการโอนเงินไม่สำเร็จ อัปเดตสถานะรายการธุรกรรมย่อยระดับ Transaction ที่ Module ตรวจจ่าย บัญชี : [AC-001-FC-002 หน้าจอรายละเอียด Support Booking](/pages/viewpage.action?pageId=1272906268) ดังนี้จ่ายเงินสำเร็จ กรณีเป็นรายการที่ธนาคารโอนเงินสำเร็จโอนเงินไม่สำเร็จ กรณีเป็นรายการที่ธนาคารโอนเงินไม่สำเร็จ ปิดหน้าจอ Popup กลับสู่ [หน้าจอบันทึกผลการจ่าย](/pages/viewpage.action?pageId=1271988595) โดยค้างรายการ Checkbox ที่เลือกไว้ และค้างเงื่อนไขค้นหาข้อมูลที่เลือกไว้ |   |   |
