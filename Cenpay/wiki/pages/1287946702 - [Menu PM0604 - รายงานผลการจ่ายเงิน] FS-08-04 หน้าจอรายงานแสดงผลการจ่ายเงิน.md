# Screen Overview

### วัตถุประสงค์ (Objective)

- เพื่อแสดงข้อมูลผลการจ่ายเงิน ช่องทางโอนเงิน
- เพื่อให้ผู้ใช้งานสามารถค้นหาและดูข้อมูลได้ตามเงื่อนไขที่กำหนด
- เพื่อให้ผู้ใช้งานสามารถส่งออกข้อมูลในรูปแบบไฟล์ PDF ได้

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ฝ่ายการเงิน
- เจ้าหน้าที่ฝ่ายปฎิบัติการ ([https://redmine.ochi.link/issues/50850](https://redmine.ochi.link/issues/50850))

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน
  - ระบบจะต้องสามารถเชื่อมต่อกับฐานข้อมูลเพื่อดึงข้อมูลรายการธนาคารที่สร้างไว้มาแสดงที่หน้าจอ

### การกระทำกับหน้าจอ (Actions)

- กดปุ่ม "ล้างเงื่อนไข" เพื่อล้างเงื่อนไขการค้นหา
- กดปุ่ม "ค้นหา" เพื่อค้นหาข้อมูลตามเงื่อนไข
- กดปุ่ม "Download File" เพื่อ Download ข้อมูลที่ค้นหาในรูปแบบไฟล์ PDF (.pdf)

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - เมื่อผู้ใช้งานกดปุ่ม ค้นหา หน้าจอจะแสดงรายการที่ตรงตามเงื่อนไขการค้นหา และจัดเรียงตามวันที่โอนเงิน, เลขที่กรมธรรม์
  - เมื่อผู้ใช้งานกดปุ่ม ล้างเงื่อนไข เงื่อนไขการค้นหาทั้งหมดจะถูก Reset เป็นค่าเริ่มต้น
  - เมื่อผู้ใช้งานกดปุ่ม Download File ระบบจะสร้างรายงานและ Download ลง Target Local Path ที่เครื่องของผู้ใช้งาน

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานไม่ระบุเงื่อนไขการค้นหาอย่างน้อยหนึ่งอย่าง เมื่อกดปุ่มค้นหาระบบจะแสดง Popup ข้อความแจ้งเตือน "กรุณาระบุเงื่อนไขการค้นหาข้อมูล"
  - กรณีระบุวันที่ในเงื่อนไขการค้นหาไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือน "ระบุช่วงวันที่ได้ไม่เกิน 120 วัน" ใต้ Text Box
  - กรณีไม่มีข้อมูลตามเงื่อนไขการค้นหา ระบบจะแสดงตารางผลลัพธ์ว่างเปล่า และแสดงข้อความที่ตาราง "ไม่พบข้อมูล"
  - กรณีเกิดปัญหาในการเชื่อมต่อกับฐานข้อมูลเมื่อเข้าสู่หน้าจอ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถเชื่อมต่อฐานข้อมูลได้ กรุณาลองใหม่อีกครั้ง"
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
