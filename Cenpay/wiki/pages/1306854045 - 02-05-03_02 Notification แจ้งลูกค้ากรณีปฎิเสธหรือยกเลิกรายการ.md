# 02-05-03_02 Notification แจ้งลูกค้ากรณีปฎิเสธหรือยกเลิกรายการ

- **Page ID:** 1306854045
- **URL:** http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1306854045

- **Depth:** 5

---

1. ตรวจสอบรายการที่ต้องส่งข้อความแจ้งลูกค้ากรณีปฎิเสธหรือยกเลิกรายการ
- ตรวจสอบธุรกรรมเวนคืนกรมธรรม์ หรือ Freelook ([tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).request_code in ('S','F')
- ตรวจสอบสถานะคำร้องเป็น ยกเลิก [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).status_code = 'CAN' - ยกเลิกรายการ
2.ดึงข้อความจาก [cf_notification](/display/RDSCPENH/cf_notification).sms_message และ [cf_notification](/display/RDSCPENH/cf_notification).line_message ด้วยเงื่อนไข [cf_notification](/display/RDSCPENH/cf_notification).noti_code = 'PR_CANCEL'
และประกอบข้อความกับ variable ดังนี้

| variable | description | mapping data |
|---|---|---|
| $(var1) | รายการธุรกรรมเวนคืนกรมธรรม์ยกเลิกกรมธรรม์**----- Centralize Payment Enhance Phase 2 Add by thidarat.lu 17/04/2026 ----**ขอรับเงินผลประโยชน์ | [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value).namewhere [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value).value = [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).request_codeand [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value).group = 'REQUEST_SMS**' -** ชื่อธุรกรรมสำหรับส่ง SMS |
| $(var2) | เลขกรมธรรม์ | [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).policy_noMasking โดยอ้างอิงเงื่อนไขข้อ 5 เลขกรมธรรม์ ใน [IT Development Common Validation](/display/RnD/IT+Development+Common+Validation) |
| $(var3) | จำนวนเงิน | [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).total_benefit_amount |
