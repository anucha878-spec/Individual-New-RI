## Overview

ใช้สำหรับ Generate จดหมายติดตาม กรณีที่เช็คใกล้หมดอายุ หรือหมดอายุแล้ว แต่ยังไม่มีการขึ้นเงิน

<แสดงข้อมูล Parameter ที่ต้องการ>

| Input | Type | Description | Example | Mandatory (Y/N) | Validation |
|---|---|---|---|---|---|
| beneficiaryName | varchar(100) | ชื่อผู้รับผลประโชน์ | สมศรี | Y |   |
| beneficiarySurname | varchar(100) | นามสกุลผู้รับผลประโชน์ | ใจงาม | Y |   |
| address1 | varchar(100) | ที่อยู่สำหรับส่งจดหมาย (1) | 33 หมู่ 2 | Y |   |
| address2 | varchar(100) | ที่อยู่สำหรับส่งจดหมาย (2) | ตำบลท่ายาง อำเภอหนองไผ่ | Y |   |
| address3 | varchar(100) | ที่อยู่สำหรับส่งจดหมาย (2) | จังหวัดเพชรบุรี 67140 | Y |   |
| barcode | varchar(50) | barcode |   | Y |   |
| barcodeReferenceText | varchar(50) | เลขจดหมายตีกลับ | C-RETURNED 03-2569 RIND-00098070666 | Y |   |
| mailNo | varchar(20) | เลขที่จดหมาย | FB 000764/2569 | Y |   |
| policyNo | varchar(20) | เลขที่กรมธรรม์ | ข0113017 | Y |   |
| planName | varchar(100) | ชื่อแบบประกัน | สินมรดก 3 | Y |   |
| phone | varchar(50) | โทรศัพท์ | 0 2261 2300 ต่อ1868 | Y |   |

## Process

1. ทำการ Generate จดหมายติดตาม ตามรายละเอียดดังนี้
  1. ****ตัวอย่าง****Template PDF: [https://drive.google.com/file/d/1uKlPzlGVHQ3d_o4lNqpGI7C0_noB6Wh7/view?usp=sharing](https://drive.google.com/file/d/1uKlPzlGVHQ3d_o4lNqpGI7C0_noB6Wh7/view?usp=sharing)
  2. **ตัวอย่าง** Template Tex File : [https://docs.google.com/document/d/1J3P4F2Q3DhPQ7pXUJE3GMurDkGT_1LePoOCiq9Eedbc/edit?tab=t.0](https://docs.google.com/document/d/1J3P4F2Q3DhPQ7pXUJE3GMurDkGT_1LePoOCiq9Eedbc/edit?tab=t.0) <ให้เว้น margin สำหรับ Logo บริษัท **[อ้างอิงตัวอย่าง Text File](#id-02-05-18ProcessGenerateจดหมายติดตาม-A_TextFile)**> เรียน คุณ<beneficiaryName>+ ' ' +<beneficiarySurname> <address1><address2><barcode><barcodeReferenceText> วันที่ DD MM(ชื่อเดือนภาษาไทย) YYYY(พ.ศ.) <วันที่พิมพ์ (T+1) – Buddhist year> ที่ <mailNo>เรื่อง แจ้งเตือนให้ติดต่อรับเงินตามเงื่อนไขกรมธรรม์ ตามที่ บริษัท ไทยสมุทรประกันชีวิต จำกัด(มหาชน) ได้แจ้งให้ท่านทราบแล้วว่า กรมธรรม์ประกันภัยเลขที่ <policyNo> แบบประกัน <planName> มีเงินตามเงื่อนไขกรมธรรม์ที่ถึงกำหนดได้รับ และ บริษัทฯ ได้ดำเนินการจ่ายเงินตามเงื่อนไขกรมธรรม์ดังกล่าวให้กับท่านแล้ว แต่มีเหตุขัดข้องทำให้ท่านยังไม่ได้รับเงินตามเงื่อนไขกรมธรรม์ดังกล่าว บริษัทฯ จึงเรียนมาเพื่อขอให้ท่านโปรดติดต่อ สำนักงานสาขาของบริษัทฯ ที่ท่านสะดวก เพื่อรับเงินตามเงื่อนไขกรมธรรม์ดังกล่าว หรือติดต่อสอบถามเพิ่มเติมได้ที่ ฝ่ายปฏิบัติการประกันชีวิต โทรศัพท์ <phone> ขอแสดงความนับถือ บริษัท ไทยสมุทรประกันชีวิต จำกัด (มหาชน)ฝ่ายปฎิบัติการประกันชีวิต
