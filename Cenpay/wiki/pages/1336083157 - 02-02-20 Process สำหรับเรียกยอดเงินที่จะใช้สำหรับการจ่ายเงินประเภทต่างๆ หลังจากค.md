# **Input**

| Input | Desciption | Example Data |
|---|---|---|
| paymentType | ประเภทคำร้อง | paymentType จากรายการนำเข้า |
| policyNo | เลขที่กรมธรรม์ | policyNo จากรายการนำเข้า |
| policyType | ประเภทกรมธรรม์ | policyType จากรายการนำเข้า |
| effectiveDate | วันที่มีผลบังคับ | requestDate จากรายการนำเข้า |

# **Process**

1.เรียก WS : [10 WS สำหรับ Call Program : PBFLIB_BFCCLPVL เพื่อคำนวนยอดเงินที่จะใช้สำหรับการจ่ายเงินประเภทต่างๆ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1333395518) โดยการส่ง Input Parameter ดังนี้

| Field | Description | Value |
|---|---|---|
| effectiveDate | วันที่มีผลบังคับ | requestDate จากรายการนำเข้า |
| paymentType | ประเภทคำร้อง | paymentType จากรายการนำเข้า |
| policyNo | เลขที่กรมธรรม์ | policyNo จากรายการนำเข้า |
| policyType | ประเภทกรมธรรม์ | policyType จากรายการนำเข้า |

2. จากนั้นนำ calID ที่ได้เรียก WS : [11 WS สำหรับเรียกยอดเงินที่จะใช้สำหรับการจ่ายเงินประเภทต่างๆ หลังจากคำนวนข้อมูลที่ PBFLIB_BFCCLPVL](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1333395676) เพิ่อดึงรายละเอียดเงิน

| Field | Description | Value |
|---|---|---|
| calID | Key ที่ได้จากการคำนวน | calID จากข้อ 1 |
