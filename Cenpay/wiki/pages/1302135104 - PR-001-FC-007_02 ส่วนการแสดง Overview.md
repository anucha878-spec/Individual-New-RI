### วัตถุประสงค์ (Objective)

- เพื่อใช้ในการ Preview แบบฟอร์มรับเรื่องเวนคืนกรมธรรม์ หรือ แบบฟอร์มรับเรื่อง ยกเลิกกรมธรรม์ (Free look)

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ธุรการ (สาขา) ([benefitregister:department:branch](http://benefitregisterdepartmentbranch/))
- ผู้จัดการสาขา ([benefitregister:department:branchmanager](http://benefitregisterdepartmentbranchmanager/))

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- กดไอคอน พิมพ์แบบฟอร์มรับเรื่อง หน้ารายการคำร้องที่ต้องการที่หน้าจอ [PR-001-FC-001 : หน้าจอค้นหารายการคำร้อง](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1297973377)

### การกระทำกับหน้าจอ (Actions)

- กดปุ่ม ปิด เพื่อปิดหน้าจอ Preview แบบฟอร์มรับเรื่อง และกลับไปที่หน้าจอ [PR-001-FC-001 : หน้าจอค้นหารายการคำร้อง](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1297973377)
- กดปุ่ม พิมพ์ เพื่อพิมพ์แบบฟอร์มรับเรื่องเวนคืนกรมธรรม์ หรือ แบบฟอร์มรับเรื่อง ยกเลิกกรมธรรม์ (Free look) ระบบจะทำการ download file (pdf) ลงที่เครื่องอัตโนมัติ

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานสามารถพิมพ์แบบฟอร์ม แบบฟอร์มรับเรื่องเวนคืนกรมธรรม์ หรือ แบบฟอร์มรับเรื่อง ยกเลิกกรมธรรม์ (Free look) เป็น File PDF ตามรายการที่ต้องการได้

### การจัดการข้อผิดพลาด (Exceptional Handling)

- ไม่มี เป็นเพียงหน้าจอที่ใช้พิมพ์แบบฟอร์มคำร้องเท่านั้น
