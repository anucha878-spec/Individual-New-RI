### วัตถุประสงค์ (Objective)

- เพื่อใช้ในการเปลี่ยนช่องทางการจ่ายเงิน แบบโอนเงิน-ปกติ, โอนเงิน-ด่วน หรือ โอนเงิน-พร้อมเพย์ เป็นช่องทางการโอนเงิน หรือเช็คได้

### ผู้ใช้งาน (Target Users)

- ฝ่ายปฎิบัติการ (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- กดปุ่ม เปลี่ยนช่องทางการจ่ายเงิน ที่หน้าจอ [PC-002-FC-001 หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) บนรายการที่มีสถานะรายการเป็น รอเตรียมจ่าย และไม่ใช่ช่องทางการจ่ายเงินที่เป็น เช็คบริษัท, เช็คธนาคาร และบัตรเครดิต

### การกระทำกับหน้าจอ (Actions)

- กดปุ่มปิด เพื่อปิดหน้าจอเปลี่ยนช่องทางการจ่ายเงิน
- กดปุ่มยืนยัน เพื่อบันทึกข้อมูลการเปลี่ยนช่องทางการจ่ายเงินที่ต้องการ

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้เปลี่ยนช่องทางการจ่ายเงินตามที่ระบุ และสามารถทำจ่ายได้ตามเวลาที่ต้องการ

### การจัดการข้อผิดพลาด (Exceptional Handling)

- มีการตรวจสอบข้อมูลการเปลี่ยนช่องทางการจ่ายเงินตามที่ระบุ โดย
  - ตรวจสอบข้อมูลที่จำเป็นต้องระบุ คือ ช่องทางการจ่าย วันที่จ่าย และหมายเหตุ
  - ตรวจสอบข้อมูลที่ระบุไว้ในระบบ CIS ต้องตรงกับข้อมูลการรับเงินของประเภทเงินที่จ่าย

### รายละเอียดเงื่อนไขปุ่ม

| No | Component Type | Component Name | Default Value | Validation Rules/Action | Example | Remark |
|---|---|---|---|---|---|---|
| 1 | Button | ปิด | Enable | เมื่อกดปุ่มปิด ระบบจะทำการปิดหน้าจอ Popup ดังกล่าวทิ้ง โดยจะกลับไปแสดงที่หน้าจอหลักเดิมก่อนหน้า และไม่ทำอะไรกับข้อมูลใดๆทั้งสิ้น |   |   |
| 2 | Button | ยืนยัน | Enable | เมื่อกดปุ่มยืนยันระบบจะทำการตรวจสอบข้อมูลที่จำเป็นระบุ ดังนี้ช่องทางการจ่าย ว่ามีการระบุข้อมูลหรือไม่วันที่จ่าย ว่ามีการระบุข้อมูลหรือไม่หมายเหตุ ว่ามีการระบุข้อมูลหรือไม่ถ้าไม่ระบุ ระบบจะขึ้นข้อความแจ้งเตือนว่า "กรุณาระบุช่องทางการจ่าย (ใหม่) ก่อนกดยืนยัน" พร้อมด้วยปุ่ม ปิด ให้ปิดข้อความแจ้งเตือนแล้วกลับมาอยู่ในหน้าจอเดิมกรณีเลือกช่องทางการจ่ายเงินเป็นโอนเงิน-ปกติ หรือโอนเงิน-พร้อมเพย์ หรือเช็คบริษัท หรือเช็คธนาคาร ต้องมีการตรวจสอบกับระบบ CIS ว่าช่องทางการรับเงิน ตามประเภทเงินที่ระบุ มีการบันทึกในระบบ CIS หรือไม่ ถ้าไม่พบในระบบ CIS ให้ระบบขึ้นข้อความแจ้งเตือนว่า "ช่องทางการรับเงินไม่ตรงกับข้อมูลในระบบ CIS กรุณาเปลี่ยนช่องทางการรับเงินให้สอดคล้องกับช่องทางการจ่ายเงินที่เลือก" พร้อมด้วยปุ่ม ปิด ให้ปิดข้อความแจ้งเตือนแล้วกลับมาอยู่ในหน้าจอเดิมเมือผ่านการตรวจสอบแล้ว ระบบจะทำการบันทึกเปลี่ยนแปลงข้อมูลการจ่ายเงินตามที่ระบุ โดยกรณีที่เปลี่ยนเป็นช่องทาง เช็คบริษัท หรือ เช็คธนาคาร จะทำให้ข้อมูลเลขที่บัญชีเป็นค่าว่าง ส่วนกรณีเปลี่ยนช่องทางเป็น โอนเงิน-พร้อมเพย์ ระบบจะเปลี่ยนเลขบัญชีธนาคารเป็นเลขบัตรประชาชนผู้รับเงินแทน |   |   |
