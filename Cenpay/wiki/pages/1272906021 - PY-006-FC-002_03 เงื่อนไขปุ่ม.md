| 2 | Button | จ่ายไม่สำเร็จ | Disable | กรณีไม่มีการเลือก Checkbox ระบบจะ Disable ปุ่มกรณีมีการเลือก Checkbox ระบบจะ Enable ปุ่มเมื่อกดปุ่ม ระบบจะตรวจสอบรายการโอนเงินที่เลือกระบบจะตรวจสอบสถานะดำเนินการของทุกรายการกรณีสถานะดำเนินการเป็น รอทำจ่าย ทุกรายการระบบจะแสดงแจ้งเตือน "ยืนยันทำรายการหรือไม่"เมื่อกด ยกเลิก ให้ค้างการเลือก Checkbox เดิมไว้ และปิดการแจ้งเตือนเมื่อกด ตกลง ระบบจะดำเนินการดังนี้ปรับสถานะดำเนินการเป็น จ่ายไม่สำเร็จ (ระบบจะส่งรายการ กลับไปยัง [หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1271234731))ปรับสถานะดำเนินการระดับ Voucher ที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1271234731) หากรายการระดับ Transaction ที่ถูกอนุมัติจ่ายภายใต้ Voucher นั้นถูกบันทึกผลครบทุกรายการ ดังนี้ปรับจาก อนุมัติจ่ายเงิน เป็น จ่ายสำเร็จบางส่วน - กรณีภายใต้ Voucher นั้นสำเร็จบางส่วน และระบบจะส่งข้อมูลไปประมวลผลข้อมูลบัญชี EDW เพื่อสร้างรายการบันทึกบัญชีจ่ายไม่สำเร็จ (พร้อมทั้งรับคืนค่าธรรมเนียมธนาคาร) ที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1271234731) เพิ่มเป็นรายการใหม่ปรับจาก อนุมัติจ่ายเงิน เป็น จ่ายไม่สำเร็จ - กรณีภายใต้ Voucher นั้นไม่สำเร็จเลย และระบบจะส่งข้อมูลไปประมวลผลข้อมูลบัญชี EDW เพื่อสร้างรายการบันทึกบัญชีจ่ายไม่สำเร็จ (พร้อมทั้งรับคืนค่าธรรมเนียมธนาคาร) ที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1271234731) เพิ่มเป็นรายการใหม่ดำเนินการอัปเดตข้อมูลกลับที่ระบบ Cenpay หากรายการระดับ Transaction ที่ถูกอนุมัติจ่ายภายใต้ Batch การเงิน นั้นถูกบันทึกผลครบทุกรายการ ดังนี้อัปเดตสถานะรายการธุรกรรมย่อยระดับ Transaction ที่ Module เตรียมจ่าย ปฏิบัติการ : [PC-001-FC-001 หน้าจอรวมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252010) และ [หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252003) เป็น โอนเงินไม่สำเร็จ พร้อมทั้ง สร้างรายการที่หน้าจอ [PC-004-FC-001 หน้าจอยืนยันการโอนเงิน](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1278017914) โดยระบุสถานะเป็น โอนเงินไม่สำเร็จอัปเดตสถานะรายการธุรกรรมย่อยระดับ Transaction ที่ Module ตรวจจ่าย บัญชี : [AC-001-FC-002 หน้าจอรายละเอียด Support Booking](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1272906268) เป็น โอนเงินไม่สำเร็จRefresh หน้าจอกรณีสถานะดำเนินการไม่เป็น รอทำจ่ายระบบจะแสดงแจ้งเตือน "เนื่องจากสถานะบางรายการเปลี่ยนเป็น จ่ายทำเร็จ หรือ จ่ายไม่สำเร็จ เรียบร้อยแล้ว กรุณาตรวจสอบข้อมูลและทำรายการใหม่อีกครั้ง"เมื่อกด ตกลง ให้ปิดการแจ้งเตือน และ Refresh หน้าจอ |   |   |
