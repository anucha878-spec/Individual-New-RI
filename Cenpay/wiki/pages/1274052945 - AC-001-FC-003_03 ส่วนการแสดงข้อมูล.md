| ส่วนแสดงข้อมูลผลการค้นหา |
|---|
| 1 |   | การเรียงลำดับข้อมูล | เรียงลำดับตามวันและเวลาที่ดำเนินการ โดยเรียงเริ่มจากวันที่ก่อนหน้า > วันที่หลังสุด |   |   |
| **ส่วนการแสดงข้อมูล (Header)** |
| No | Component Type | Component Name | Action / Data Value | Example | Remark |
| 1 | Label | เลขที่ธุรกรรม | แสดงเลขที่ธุรกรรมของรายการเอกสารแนบ |   |   |
| 2 | Label | ชือ-นามสกุล ผู้รับเงิน | แสดงชื่อ-นามสกุล ของผู้รับเงินที่เกี่ยวข้องกับเอกสารแนบ |   |   |
| **ส่วนการแสดงข้อมูล (Header ย่อย 1)** |
| **No** | **Component Type** | **Component Name** | **Action / Data Value** | **Example** | **Remark** |
| 1 | Label | เอกสารจากระบบต้นทาง | Fix แสดง "เอกสารจากระบบต้นทาง" |   |   |
| **ส่วนการแสดงข้อมูล (Table Display ย่อย 1)** |
| **No** | **Component Type** | **Component Name** | **Action / Data Value** | **Example** | **Remark** |
| 1 | Button | ดำเนินการ | แสดงปุ่มเพื่อกดดูรายละเอียดของเอกสารแนบ ที่มีการบันทึกไว้ที่ระบบ DMS |   |   |
| 2 | Label | ชื่อไฟล์เอกสาร | แสดงชื่อของเอกสารนั้นๆ ที่มีการบันทึกลงในระบบ DMSโดยจะใช้เป็นชื่อตามที่บันทึกในระบบนั้นๆ อาจจะใช้เหมือนกับที่บันทึกในระบบ DMS หรือไม่เหมือนก็ได้ | เอกสารการจ่ายเงิน.png |   |
| 3 | Label | ชื่อเอกสาร | แสดงชื่อประเภทเอกสารที่ถูกจัดเก็บในระบบ DMSโดยอาจจะเป็นชื่อประเภทเอกสาร หรือชื่อตามประเภทเอกสารที่แยกไว้ในระบบ DMS ก็ได้ | เอกสารการจ่ายเงิน |   |
| 4 | Label | วันและเวลาที่ดำเนินการ | แสดงวันที่และเวลาที่ทำการนำเข้าเอกสาร |   |   |
