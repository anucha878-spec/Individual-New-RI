# การจัดการข้อมูล

- เรียก [WS สำหรับดึงข้อมูล SUN Booking](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1282244649) โดยส่ง Input ดังนี้ --> ปรับแก้ส่ง Parameter เพิ่มเติม ariya.pi 01/12/2568NameDescriptionValuereferenceNumberReference Number ของ EDW[tx_payment_account](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_account).reference_numbersystemNameระบบที่ดึงข้อมูลFix "CENPAY"userNameusername ผู้ใช้งานLogin User
- เปิด contentId และนำข้อมูลใน List File มาแสดงบนหน้าจอ
