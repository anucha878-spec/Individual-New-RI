### หน้าจอหลัก : Screen Design

### วัตถุประสงค์ (Objective)

- เพื่อรวมรายการจ่ายเงินเป็นประเภทการจ่าย, Service (Format ธนาคาร), Bank Account, Request Payment Date เดียวกัน
- เพื่อให้ผู้ใช้งานสามารถดูข้อมูลสรุปรายการที่เลือกรวม Batch การเงิน
- เพื่อให้ผู้ใช้งานเลือกและยืนยันวิธีการจ่ายเงิน

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ฝ่ายการเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ผู้ใช้งานจะต้องกดปุ่ม ยืนยันรวม Batch ที่หน้าจอหลัก
  - รายการธุรกรรมที่ถูกเลือกจะต้องมีช่องทางการจ่าย และ Request Payment Date เป็นวันเดียวกัน หรือเป็นรายการ Batch Split ที่ไม่ใช่ Batch เดิม
- การกำหนดค่าเริ่มต้นเมื่อเปิดหน้าจอ
  - ระบบจะกำหนดค่า Dropdown List ตามลำดับดังนี้
    1. ประเภทการจ่าย
    2. Services (Format ธนาคาร) เมื่อมีการเลือกประเภทการจ่าย
    3. Bank Account เมื่อมีการเลือก Services (Format ธนาคาร)

### การกระทำกับหน้าจอ (Actions)

- ยกเลิกการสร้าง Batch การเงิน
- ยืนยันการสร้าง Batch การเงิน

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - กรณียกเลิก ระบบจะล้างข้อมูลที่กรอกในหน้าจอนี้ทั้งหมด และกลับไปยังหน้าจอหลัก
  - กรณีบันทึก ระบบจะสร้างรายการ Batch การเงิน
    - ระบบตรวจสอบรายการ Batch ปฎิบัติการ ทุกรายการยังมีสถานะเป็น รอยืนยัน
      - กรณีประเภทการจ่ายเป็น Batch Payment จะส่งข้อมูลไปยังหน้าจอ [PY-002-FC-001 หน้าจอค้นหา Generate Batch Payment](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1267859518)
      - กรณีประเภทการจ่ายเป็น Paper Base Payment จะส่งข้อมูลไปยังหน้าจอ [PY-003-FC-001 หน้าจอค้นหา Paper Base Payment - Maker](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1269858862)
      - กรณีประเภทการจ่ายเป็น API Payment จะส่งข้อมูลไปยังหน้าจอ [PY-010-FC-001 หน้าจอค้นหา API Payment](/pages/viewpage.action?pageId=1279460015) (รอพัฒนาใน Ph2)
  - ส่งอัปเดตสถานะรายการที่ระบบ Cenpay ทุกรายการธุรกรรมย่อยภายใต้ Batch การเงินเป็น รอตรวจสอบ (ฝ่ายการเงิน) เพื่อให้รับทราบสถานะรายการปัจจุบัน

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีระบุ Required File ไม่ครบถ้วน ระบบจะแสดง Popup ข้อความแจ้งเตือน "กรุณาระบุข้อมูลให้ครบถ้วน" และแจ้งเตือน "กรุณาระบุ" ข้อความสีแดงใต้ Text Box
  - กรณียกเลิก ระบบจะแสดง Popup ข้อความแจ้งเตือน "ยกเลิกการสร้าง Batch"
  - กรณีบันทึก ระบบจะแสดง Popup ข้อความแจ้งเตือน "ยืนยันการสร้าง Batch"
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการเพียงรายการใดรายการหนึ่งภายใต้การรวม Batch นั้น ถูกเปลี่ยนแปลงสถานะดำเนินการไม่เป็นสถานะรอยืนยัน ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการทำรายการแล้ว" เมื่อกดปิด ระบบจะปิดหน้าจอ Popup กลับสู่หน้าจอหลักและ Refresh ข้อมูลใหม่
