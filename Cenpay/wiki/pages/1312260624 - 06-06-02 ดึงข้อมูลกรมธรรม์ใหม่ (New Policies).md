ดึงข้อมูลกรมธรรม์ใหม่ (New Policies) จากระบบ AS400 โดยจำแนกตาม ประเภทกรมธรรม์ดังนี้
- ประเภทกรมธรรม์ O : ของสามัญเงื่อนไขการดึงข้อมูล ตัวอย่าง Query การดึงข้อมูล <![CDATA[/*เคสใหม่ จะดึงตาม ช่วงเวลาที่กำหนด Parameter 1. :policyNo = Input policyNo 2. :targetStartDate = Input targetStartDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25680705 3. :targetEndDate = Input targetEndDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25690101 4. :idCard = Input idCard ความหมายข้อมูลที่ดึง POLICY_NO = เลขที่กรมธรรม์ */ -- สามัญ * ต้องแปลงวันที่จาก 6 เป้น 8 หลัก ก่อนใช้งาน SELECT &#39;O&#39; AS POLICY_TYPE, A.POLIC# AS POLICY_NO FROM OLIS.OLPPOLMS A INNER JOIN OLIS.OLPCUSMS B ON A.CUSTM# = B.CUSTM# INNER JOIN ( -- ค้นหาข้อมูลเบี้ยจากข้อมูลใบเสร็จ SELECT RCPOL#,RC# --,(RCPYDT + 25000000) AS RCPYDT --,(RCPOPR+RD13PR+RD24PR+RD24PR+RDHCPR+RDOTPR+RCEXPR) AS SUM_PREMIUM FROM OLIS.OLPRECDT WHERE RCPYY# =&#39;1&#39; -- ชำระปีที่ 1 AND RCPYI# =&#39;1&#39; -- ชำระ งวดที่ 1 ) RECP ON A.POLIC# = RECP.RCPOL# INNER JOIN ( -- ค้นหาข้อมูลค่าคอมมิชชั่น SELECT RCPOL#,RC# -- ,SUM(CMAMTR) AS COMMISSION FROM OLIS.OLPRECIC GROUP BY RCPOL#,RC# ) COMM ON COMM.RCPOL# = A.POLIC# AND RECP.RC# = COMM.RC# WHERE 1 = 1 AND A.POLIC# &lt;&gt; :policyNo AND ((A.POCMDT + 25000000) BETWEEN :targetStartDate AND :targetEndDate) AND B.CUIDNO = :idCard]]>
  1. `OLIS.OLPPOLMS`
  2. `OLIS.OLPCUSMS`
  3. `OLIS.OLPRECDT`
  4. `OLIS.OLPRECIC`
  1. วันที่เริ่มสัญญามูลกรมธรรม์ใหม่ (New Policies) ต้องอยู่ในช่วง targetStartDate ถึง targetEndDate
  2. กรมธรรม์ใหม่ (New Policies) ต้องเป็นของผู้เอาประกันคนเดียวกันเท่านั้น
  3. ผู้เอาประกันภัยของกรมธรรม์ใหม่ (New Policies) ต้องเป็นบุคคลเดียวกันกับผู้เอาประกันภัยของกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืนเท่านั้น
  4. ต้องไม่ใช้กรมธรรม์เดียวกันกับกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืน
- ประเภทกรมธรรม์ I : ของอุตสาหกรรม ปชเงื่อนไขการดึงข้อมูล ตัวอย่าง Query การดึงข้อมูล <![CDATA[/* เคสใหม่ จะดึงตาม ช่วงเวลาที่กำหนด Parameter 1. :policyNo = Input policyNo 2. :targetStartDate = Input targetStartDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25680705 3. :targetEndDate = Input targetEndDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25690101 4. :idCard = Input idCard ความหมายข้อมูลที่ดึง POLICY_NO = เลขที่กรมธรรม์ */ -- อุตสาหกรรม ปช. SELECT &#39;I&#39; AS POLICY_TYPE, A.MBPOL# AS POLICY_NO FROM ILISLIB.POLCYMB0 A INNER JOIN ILISLIB.CUSTMMC0 B ON A.MBCSID = B.MCCSID INNER JOIN ( -- ค้นหาเบี้ยและค่าคอม ของอุตสาหกรรม SELECT policy --,RECPNO,RCACDT,RCMODE,(FSTPRM-FSTDIS) AS SUM_PREMIUM ,RCCOMM FROM ILISLIB.RECEIPTS A WHERE RCSTST=&#39;U&#39; -- U : ใบเสร็จที่ ชำระแล้วของ เคสใหม่ ) RECP ON A.MBPOL# = RECP.POLICY WHERE 1 = 1 AND A.MBPOL# &lt;&gt; :policyNo AND (A.MBCDTE BETWEEN :targetStartDate AND :targetEndDate) AND B.MCIDNO = :idCard ]]>
  1. `ILISLIB.POLCYMB0`
  2. `ILISLIB.CUSTMMC0`
  3. `ILISLIB.RECEIPTS`
  1. วันที่เริ่มสัญญามูลกรมธรรม์ใหม่ (New Policies) ต้องอยู่ในช่วง targetStartDate ถึง targetEndDate
  2. กรมธรรม์ใหม่ (New Policies) ต้องเป็นของผู้เอาประกันคนเดียวกันเท่านั้น
  3. ผู้เอาประกันภัยของกรมธรรม์ใหม่ (New Policies) ต้องเป็นบุคคลเดียวกันกับผู้เอาประกันภัยของกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืนเท่านั้น
  4. ต้องไม่ใช้กรมธรรม์เดียวกันกับกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืน
- `ประเภทกรมธรรม์ P : อุบัติเหตุ``เงื่อนไขการดึงข้อมูล``` ตัวอย่าง Query การดึงข้อมูล <![CDATA[/* เคสใหม่ จะดึงตาม ช่วงเวลาที่กำหนด Parameter 1. :policyNo = Input policyNo 2. :targetStartDate = Input targetStartDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25680705 3. :targetEndDate = Input targetEndDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25690101 4. :idCard = Input idCard ความหมายข้อมูลที่ดึง POLICY_NO = เลขที่กรมธรรม์ */ -- อุบัติเหตุ SELECT &#39;P&#39; AS POLICY_TYPE, A.POLNO AS POLICY_NO FROM PPALIB.TBPOLICY A INNER JOIN PPALIB.TBCUSTOM B ON A.POLCID = B.CUSID INNER JOIN PPALIB.TBRECEIP C ON A.POLNO = C.RECPOL WHERE 1 = 1 AND A.POLNO &lt;&gt; :policyNo AND (A.POLCDT BETWEEN :targetStartDate AND :targetEndDate) AND B.CUSCID = :idCard ]]>
  1. ``PPALIB.TBPOLICY``
  2. ``PPALIB.TBCUSTOM``
  3. ``PPALIB.TBRECEIP``

  2. `กรมธรรม์ใหม่ (New Policies) ต้องเป็นของผู้เอาประกันคนเดียวกันเท่านั้น`
  3. `ผู้เอาประกันภัยของกรมธรรม์ใหม่ (New Policies) ต้องเป็นบุคคลเดียวกันกับผู้เอาประกันภัยของกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืนเท่านั้น`
  4. `ต้องไม่ใช้กรมธรรม์เดียวกันกับกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืน`
