## Overview

ดึงข้อมูลจ่ายเงินคืนทันที จากกระบวนการปิดบัญชีอัตโนมัติ (APU)

## Protocol

Icon
<SOAP,HESSIAN,REST>

## Operation

refer : [ESB WebService Design Pattern](/display/IEA/ESB+WebService+Design+Pattern)
Icon
TYPE : <inquiry>

## Input

| Name | Type | Description | Example | Validation |
|---|---|---|---|---|
| status | Enum | สถานะรายการA=ACTIVE C=COMPLETE(จ่ายแล้ว) D=DELETE/CANCEL R=RETURN(เรียกคืนแล้ว) B=เตรียมจ่าย F=FAIL | A | Required |
| policyList | List<String> | List ของกรมธรรม์ที่กำหนด | ('0252701','0243417') | Not Requiredกำหนด Limit ไม่เกิน 50 |

## Process

**ค้นหาข้อมูลเงินจ่ายคืนทันที DB: AS400**
<![CDATA[-- ปรับแเพิ่มในส่วนของการดึงข้อมูลรายละเอียดใบเสร็จล่าสุดของรายการกรมมธรรม์ที่มีการจ่าย APU แก้โดย ariya.pi เมื่อ 29/01/2569 WITH receive_payment AS (SELECT &quot;RCPOL#&quot;, &quot;RCPYY#&quot;, &quot;RCPYI#&quot;, RCFRDT, RCTODT, RCMODE, SUM(RCPOPR)+SUM(RD13PR)+SUM(RD24PR)+SUM(RDHCPR)+SUM(RDOTPR)+SUM(RCEXPR) AS PREMIUM FROM OLIS.OLPRECDT WHERE &quot;RCPOL#&quot; IN (SELECT &quot;TNPOL#&quot; FROM OLIS.OLPSRPMS WHERE TNSTS@ = :status AND TNAMTC &gt; 0) GROUP BY &quot;RCPOL#&quot;, &quot;RCPYY#&quot;, &quot;RCPYI#&quot;, RCFRDT, RCTODT, RCMODE), last_receive_payment AS (SELECT &quot;RCPOL#&quot;, &quot;RCPYY#&quot;, &quot;RCPYI#&quot;, RCFRDT, RCTODT, RCMODE, PREMIUM, ROW_NUMBER() OVER (PARTITION BY RCPOL# ORDER BY RCPYY# DESC, RCPYI# DESC) as rn FROM receive_payment) SELECT MAPU.POLIC# AS policyNo -- เพิ่มการดึงข้อมูล TagID เพื่อใช้ในกระบวนการอ้างอิงข้อมูลการจ่ายเงินคืนทันที APU ที่ระบบ AS400 แก้โดย ariya.pi เมื่อ 16/12/2568 ,OOL.OLTGID AS tagID ,MR.TNPUDT AS paymentDueDate ,MR.TNPAY AS paymentType ,MR.TNACTI AS payeeTitle ,MR.TNACNM AS payeeName ,MR.TNACSN AS payeeSurname ,MR.TNACNO AS payeeAccount ,MR.TNAMTC AS apuAmount ,&#39;ORD&#39; AS policyType ,POLMS.CUISAG AS insureEntryAge ,POLMS.CRORG# AS channelCode ,SUBSTRING(POLMS.CRORG#,4,7) AS branchCode ,POLMS.&quot;POPLN@&quot; AS productCode ,PLN.PLNAM1 AS productName -- ดึงข้อมูลเงินที่ชำระเบี้ยทั้งหมด โหมดการขำรพ ปีที่งวดที่ชำรพ และชำระตั้งแต่ ชำระถึง แก้โดย ariya.pi เมื่อ 29/01/2569 ,ORC.PREMIUM AS premiumAmount ,ORC.RCMODE AS monthlyMode ,ORC.&quot;RCPYY#&quot; AS premiumPeriodYear ,ORC.&quot;RCPYI#&quot; AS premiumPeriodTerm ,ORC.RCFRDT AS premiumPaidFrom ,ORC.RCTODT AS premiumPaidTo ,POLMS.&quot;POSTS@&quot; AS policyStatusCode ,POLMS.POCMDT AS commencementDate ,POLMS.POMTDT AS maturityDate ,POLMS.POPEDT AS fullyPaidDate ,POLMS.POSMAS AS policyInsure ,MAPU.PPPUDT AS puDate ,MAPU.PPPUSA AS puAmount ,POLMS.&quot;CRAGT#&quot; AS agentCode ,AGM.AGTITL AS agentTitle ,AGM.AGNAME AS agentName ,AGM.AGLSNM AS agentSurName ,MR.TNREFN AS sourceRefNo ,MR.&quot;TNTNO#&quot; AS endorseNo ,PLN.PLCVTM AS policyCoverageTerm ,PLN.PLPMTM AS policyPaymentTerm FROM OLIS.OLPAPUMS MAPU INNER JOIN OLIS.OLPSRPMS MR ON MAPU.POLIC# = MR.&quot;TNPOL#&quot; AND MAPU.PPPUDT = RIGHT (MR.TNPUDT,6) AND MAPU.PPREFN = MR.TNREFN INNER JOIN OLIS.OLPPOLMS POLMS ON MAPU.POLIC# = POLMS.POLIC# INNER JOIN LIPS.PSPSLORG ORG ON ORG.&quot;SLUNT#&quot; = CASE WHEN LEFT(POLMS.CRORG#,3) = 507 THEN 207||right(POLMS.CRORG#,4) ELSE POLMS.CRORG# end INNER JOIN OLIS.OLPPLNTB PLN ON POLMS.POPLN@ = PLN.PLAN@ LEFT JOIN LIPS.PSPAGMT1 AGM ON POLMS.&quot;CRAGT#&quot; = AGM.&quot;AGENT#&quot; -- เพิ่มการ Join ข้อมูลใบเสร็จที่ชำระเงินแล้ว เพื่อคิดเบี้ยรวมที่ชำระล่าสุด แก้โดย ariya.pi เมื่อ 29/01/2569 LEFT JOIN (SELECT * FROM last_receive_payment WHERE rn = 1) ORC ON POLMS.&quot;POLIC#&quot; = ORC.&quot;RCPOL#&quot; -- เพิ่มการ Join ข้อมูล Index เพื่อหาข้อมูล TagID อ้างอืงกับช้อมูลในระบบ AS400 แก้โดย ariya.pi เมื่อ 16/12/2568 INNER JOIN OASYS.OALLINK1 OOL ON OOL.OLEVTY = &#39;APU&#39; AND OOL.OLPOLC = POLMS.POLIC# AND OOL.OLDUDT = MR.TNPUDT AND OOL.OLREFN = MR.TNREFN AND OOL.OLENNO = MR.&quot;TNTNO#&quot; WHERE MR.TNAMTC &gt; 0 AND MR.TNSTS@ = :status -- ถ้ามีข้อมูล :policyList AND MAPU.&quot;POLIC#&quot; IN :policyList;]]>
