## Overview

ดึงเอกสารแนบบนระบบ CIS ของรายการเปลี่ยนแปลงข้อมูลตามที่ระบุ และตามสถานะการเปลี่ยนแปลงที่ระบุ ของลูกค้าและกรมธรรม์ที่ระบุ

## Process

**ค้นหาข้อมูลรายการเปลี่ยนแปลงข้อมูลที่รออนุมัติที่ระบบ CIS DB: CIS**
<![CDATA[select document_id as dmsDocID, file_name as documentName, file_description as documentType, create_date as transactionDate from cis_attach_file where reference_no = (select max(h.id) -- เลือกรายการล่าสุด from cis_update_history h inner join cis_update_history_detail hd on ( hd.reference_no = h.id) where h.customer_id = :customerID and hd.data_group_code in :dataGroupCode and h.last_status in :ChangeStatus and case when hd.policy_no is not null then hd.policy_no = :policyNo else 1=1 end) order by document_id;]]>
