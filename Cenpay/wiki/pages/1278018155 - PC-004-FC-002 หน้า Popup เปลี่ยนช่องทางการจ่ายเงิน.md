### วัตถุประสงค์ (Objective)

- เพื่อใช้ในการเปลี่ยนช่องทางการจ่ายเงินก่อนการยืนยันโอนเงินใหม่สำหรับรายการที่โอนเงินไม่สำเร็จ

### ผู้ใช้งาน (Target Users)

- ฝ่ายปฎิบัติการ (Maker)
- ฝ่ายกิจการสาขา

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- กดปุ่ม เปลี่ยนช่องทางการจ่ายเงิน ที่หน้าจอ [PC-004-FC-001 หน้าจอยืนยันการโอนเงิน](/pages/viewpage.action?pageId=1278017914)

### การกระทำกับหน้าจอ (Actions)

- กดปุ่มยืนยัน เพื่อบันทึกข้อมูลการเปลี่ยนช่องทางการจ่ายเงินที่ต้องการ
- กดปุ่มปิด เพื่อปิดหน้าจอเปลี่ยนช่องทางการจ่ายเงิน

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้เปลี่ยนช่องทางการจ่ายเงินตามเงื่อนไขที่ระบุ สอดคล้องกับข้อมูลการจ่ายที่ระบุบนระบบ CIS

### การจัดการข้อผิดพลาด (Exceptional Handling)

- มีการตรวจสอบข้อมูลการเปลี่ยนช่องทางการจ่ายเงินตามที่ระบุ โดย
  - ตรวจสอบข้อมูลที่จำเป็นต้องระบุ คือ ช่องทางการจ่าย (ใหม่) และหมายเหตุ
  - ตรวจสอบข้อมูลที่ระบุไว้ในระบบ CIS ต้องตรงกับข้อมูลการรับเงินของประเภทเงินที่จ่าย

### รายละเอียดส่วนการแสดงผลข้อมูล

| ส่วนแสดงข้อมูลผลการค้นหา |
|---|
| **ข้อมูลกรมธรรม์** |
| No | Component Type | Component Name | Action / Data Value | Example | Remark |
| 1 | Label | เลขที่กรมธรรม์ | แสดงเลขที่กรมธรรม์ |   |   |
| 2 | Label | ชื่อ-สกุล ผู้รับเงิน | แสดงชื่อและนามสกุลของผู้รับเงิน |   |   |
| 3 | Label | ประเภทการจ่าย | แสดงประเภทการจ่ายเงินของธุรกรรม |   |   |
| 4 | Label | ช่องทางการจ่ายเงิน | แสดงช่องทางการจ่ายเงินเดิมของธุรกรรม |   |   |
| **ข้อมูลช่องทางการจ่ายเงิน** |
| **No** | **Component Type** | **Component Name** | **Action / Data Value** | **Example** | **Remark** |
| 1 | Dropdown List | ระบุช่องทางการจ่ายเงิน (ใหม่) | แสดงข้อมูลจาก [Configuration Data](http://wiki.thaisamut.co.th/display/RDSCPENH/4.+Configuration+Data) ส่วนข้อมูลช่องทางการจ่าย (ปฎิบัติการ)โดยจะแสดง List รายการที่เลือกยกเว้นช่องทางการจ่ายเงินปัจจุบันจำกัดการแสดงผล โดยไม่แสดงช่องทาง "โอนเงิน-ด่วน" |   |   |
| 2 | Dropdown List | หมายเหตุ | แสดงข้อมูลจาก [Configuration Data](http://wiki.thaisamut.co.th/display/RDSCPENH/4.+Configuration+Data) ส่วนข้อมูลหมายเหตุเปลี่ยนช่องทางการจ่ายเงิน |   |   |

### รายละเอียดเงื่อนไขปุ่ม

| No | Component Type | Component Name | Default Value | Validation Rules/Action | Example | Remark |
|---|---|---|---|---|---|---|
| 1 | Button | ปิด | Enable | เมื่อกดปุ่มปิด ระบบจะทำการปิดหน้าจอ Popup ดังกล่าวทิ้ง โดยจะกลับไปแสดงที่หน้าจอหลักเดิมก่อนหน้า และไม่ทำอะไรกับข้อมูลใดๆทั้งสิ้น |   |   |
| 2 | Button | ยืนยัน | Enable | เมื่อกดปุ่มยืนยันระบบจะทำการตรวจสอบข้อมูลที่จำเป็นระบุ ดังนี้ช่องทางการจ่าย ว่ามีการระบุข้อมูลหรือไม่ ถ้าไม่ระบุ ระบบจะขึ้นข้อความแจ้งเตือนว่า "กรุณาระบุช่องทางการจ่าย (ใหม่) ก่อนกดยืนยัน" พร้อมด้วยปุ่ม ปิด ให้ปิดข้อความแจ้งเตือนแล้วกลับมาอยู่ในหน้าจอเดิมหมายเหตุ ว่ามีการระบุข้อมูลหรือไม่ ถ้าไม่ระบุ ระบบจะขึ้นข้อความแจ้งเตือนว่า "กรุณาระบุหมายเหตุ ก่อนกดยืนยัน" พร้อมด้วยปุ่ม ปิด ให้ปิดข้อความแจ้งเตือนแล้วกลับมาอยู่ในหน้าจอเดิมกรณีเลือกช่องทางการจ่ายเงินเป็นโอนเงิน-ปกติ หรือโอนเงิน-พร้อมเพย์ หรือเช็คบริษัท หรือเช็คธนาคาร ต้องมีการตรวจสอบกับระบบ CIS ว่าช่องทางการรับเงิน ตามประเภทเงินที่ระบุ มีการบันทึกในระบบ CIS หรือไม่ ถ้าไม่พบในระบบ CIS ให้ระบบขึ้นข้อความแจ้งเตือนว่า "ช่องทางการรับเงินไม่ตรงกับข้อมูลในระบบ CIS กรุณาเปลี่ยนช่องทางการรับเงินให้สอดคล้องกับช่องทางการจ่ายเงินที่เลือก" พร้อมด้วยปุ่ม ปิด ให้ปิดข้อความแจ้งเตือนแล้วกลับมาอยู่ในหน้าจอเดิมเมือผ่านการตรวจสอบแล้ว ระบบจะทำการบันทึกเปลี่ยนแปลงข้อมูลการจ่ายเงินตามที่ระบุ โดยกรณีที่เปลี่ยนเป็นช่องทาง เช็คบริษัท หรือ เช็คธนาคาร จะทำให้ข้อมูลเลขที่บัญชีเป็นค่าว่าง ส่วนกรณีเปลี่ยนช่องทางเป็น โอนเงิน-พร้อมเพย์ ระบบจะเปลี่ยนเลขบัญชีธนาคารเป็นเลขบัตรประชาชนผู้รับเงินแทน |   |   |
