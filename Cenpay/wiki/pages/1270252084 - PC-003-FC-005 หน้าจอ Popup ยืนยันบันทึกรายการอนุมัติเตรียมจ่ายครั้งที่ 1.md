### วัตถุประสงค์ (Objective)

- เพื่อใช้สำหรับแสดงสรุปรายการ Batch ตรวจสอบที่ทำการอนุมัติลำดับที่ 1 ทั้งหมด

### ผู้ใช้งาน (Target Users)

- ฝ่ายปฎิบัติการ (Checker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- มีการกดปุ่ม อนุมัติ จากหน้าจอ [PC-003-FC-001 หน้าจออนุมัติรายการเตรียมจ่ายครั้งที่ 1](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252076)

### การกระทำกับหน้าจอ (Actions)

- กดปุ่มปิด เพื่อปิดหน้าจอดังกล่าว กลับไปที่หน้าจอก่อนหน้า
- กดปุ่มยืนยัน เพื่อยืนยันอนุมัติรายการจ่ายลำดับที่ 1

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้ทำการอนุมัติรายการจ่ายลำดับที่ 1 เรียบร้อยแล้ว

### การจัดการข้อผิดพลาด (Exceptional Handling)

- ไม่มี เป็นเพียงหน้าจอที่ใช้แสดงข้อมูลรายการ Batch ตรวจสอบที่เลือกอนุมัติลำดับที่ 1 ทั้งหมด

### รายละเอียดเงื่อนไขปุ่ม

| No | Component Type | Component Name | Default Value | Validation Rules/Action | Example | Remark |
|---|---|---|---|---|---|---|
| 1 | Button | ปิด | Enable | เมื่อกดปุ่มปิด ระบบจะทำการปิดหน้าจอ Popup ดังกล่าว และยกเลิกการบันทึกข้อมูลอนุมัติตรวจสอบลำดับที่ 1 |   |   |
| 2 | Button | ยืนยัน | Enable | เมื่อกดปุ่มระบบจะตรวจสอบรายการธุรกรรมทั้งหมดกรณีที่ถูกต้องทั้งหมดทุกธุรกรรมระบบจะทำการยืนยันบันทึกรายการอนุมัติลำดับที่ 1 โดยการปรับสถานะ Batch ตรวจสอบเป็น อนุมัติจากนั้นสร้าง Batch ปฎิบัติการ และบันทึกสถานะ Batch ปฎิบัติการเป็น รออนุมัติจากนั้น Update สถานะรายการของทุกธุรกรรมที่ [หน้าจอรวมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252010) และ [หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) เป็น รออนุมัติเตรียมจ่ายครั้งที่ 2กรณีที่ไม่ถูกต้องทั้งหมดทุกธุรกรรมระบบจะทำการปรับสถานะ Batch ตรวจสอบเป็น ยกเลิกจากนั้นปรับสถานะทุกรายการธุรกรรมที่ [หน้าจอรวมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252010) และ [หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) เป็น ส่งกลับแก้ไข (Oper) เพื่อรอให้ทางทีมปฎิบัติการตรวจสอบและตั้งรายการจ่ายใหม่อีกครั้งกรณีที่มีทั้งรายการที่ถูกต้องและไม่ถูกต้องระบบจะทำการปรับสถานะ Batch ตรวจสอบเป็น ยกเลิกจากนั้นทำการสร้าง Batch ตรวจสอบใหม่สำหรับรายการธุรกรรมที่ถูกต้อง และ Update สถานะ Batch ตรวจสอบเป็น อนุมัติสร้าง Batch ปฎิบัติการให้กับรายการที่ถูกต้อง และบันทึกสถานะ Batch ปฎิบัติการเป็น รออนุมัติปรับสถานะรายการธุรกรรมที่ถูกต้องที่หน้ารวมจ่าย และเตรียมจ่าย เป็น รออนุมัติเตรียมจ่ายครั้งที่ 2สำหรับรายการที่ไม่ถูกต้อง ให้ปรับสถานะทุกรายการธุรกรรมที่ [หน้าจอรวมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252010) และ [หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) เป็น ส่งกลับแก้ไข (Oper) เพื่อรอให้ทางทีมปฎิบัติการตรวจสอบและตั้งรายการจ่ายใหม่อีกครั้งจากนั้นปิดหน้าจอ Popup ดังกล่าวกลับไปที่หน้าจอก่อนหน้า |   |   |
