## Overview

ตรวจสอบผู้เอาประกันเป็นตัวแทน หรือผู้รับผลประโยชน์ว่าเป็นตัวแทน และบุคคล 5 ประเภท หรือไม่
**Repositories**: msa-benefitregister
**Service path**
**POST:** /thaisamut/rs/benefitregister/v1/common/check-agent-relation
Icon
TYPE : <POST>
**อธิบายได้ดังนี้**
GET - Select
POST - Insert
PUT - Update
DELETE - Delete

## Input

| Name | Type | Description | Example | Validation |
|---|---|---|---|---|
| insuredName | String | คำหน้า ชื่อ และนามสกุล ผู้เอาประกัน | นายมานะ บุญมี | Required |
| agentName | String | คำหน้า ชื่อ และนามสกุล ตัวแทน | นายสมใจ ใจดี | Required |
| benefitName | List<String> | คำหน้า ชื่อ และนามสกุล ผู้รับผลประโยชน์ | นางสมหญิง ใจสอาด | Required |
| benefitRelation | List<String> | ความสัมพันธ์ของผู้รับผลประโยชน์ | บิดา | Required |

## Process

1. ตรวจสอบผู้เอาประกันว่าเป็นคนเดียวกับตัวแทนหรือไม่
3. ตรวจสอบผู้รับผลประโยชน์**ทั้งหมด**ว่าเป็นคนเดียวกับตัวแทนหรือไม่
5. ตรวจสอบความสัมพันธ์ของผู้รับผลประโยชน์ที่เป็นตัวแทนว่าเป็นบุคคล 5 ประเภท หรือไม่
  1. ตรวจสอบ benefitRelation ของผู้รับผลประโยชน์จากข้อ 2. กับ config table [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value) ด้วยเงื่อนไข group = 'BENEFIT_RELATION'
    1. กรณี benefitRelation ตรงกับ [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value).name ให้ Output เป็น True
    2. กรณี benefitRelation **ไม่**ตรงกับ [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value).name ให้ Output เป็น False

## Output

<แสดงข้อมูลที่จะได้รับจาก service นี้>

| **Name** | **Type** | **Description** | **Example** |
|---|---|---|---|
| isCase5TypeAgent | boolean | Yes = ผู้เอาประกันเป็นตัวแทน หรือ ผู้รับผลประโยชน์เป็นตัวแทน และบุคคล 5 ประเภทNo = ผู้รับผลประโยชน์ไม่ใช่ตัวแทน | True |
