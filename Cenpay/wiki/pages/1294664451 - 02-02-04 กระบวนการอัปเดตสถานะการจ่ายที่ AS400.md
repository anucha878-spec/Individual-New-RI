# **Input**

| Input | Description | Required |
|---|---|---|
| createdBy | ผู้ส่ง Update สถานะการจ่ายที่ระบบ AS400 | Y |
| createdProgram | โปรแกรมที่ส่ง Update สถานะการจ่ายที่ระบบ AS400 | Y |

# **กระบวนการ**

1. เรียก [03 WS สำหรับ Call Program : OLIS/SPGN031 เพื่อขอ Sequence Id จากระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1289750156) สำหรับข้อมูล Header (Path : "/QSYS.LIB/OLIS.LIB/SPGN031R.PGM") โดยส่ง Parameter ดังต่อไปนี้NameDescriptionValuesystemชื่อระบบFix "CNPAY"tableชื่อไฟล์ที่จะ GenerateFix "BFPPAYHD"yearปีปัจจุบัน (ค.ศ.)systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลขmonthเดือนปัจจุบันsystemDate เอาเฉพาะเดือน เป็นตัวเลขtotalKeyจำนวนรายการที่ต้องการจองเลข PKtotalPaymentTypeจากนั้น อ่านข้อมูล Output ของ WS
  1. ถ้า primaryFlag = "F" ให้เก็บข้อมูลจาก WS ดังนี้
    1. groupStart = seqGroupStart จาก WS
    2. sequenceStart = seqStart จาก WS
    3. groupEnd = seqGroupEnd จาก WS
    4. sequenceEnd = seqEnd จาก WS
  2. ถ้า primaryFlag = "T" ให้เก็บข้อมูล headerID = seqPrimaryKey จาก WS
2. เริ่ม Loop ด้วยข้อมูลใน List<payment> โดยทำที่ละประเภทการจ่าย
  1. กำหนด sumTransaction = 0 และ sumPaymentAmount = 0
  2. สำหรับการกำหนด headerID กรณีที่ List<payment> มากกว่า 1 กำหนด headerID ตาม Format : CNPAYYYYYMMGNNNNNNNN โดย กำหนด headerID **กรณีครั้งแรก (Start Loop)** 1. Fix "CNPAY" 2. YYYY = systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลข 3. MM = systemDate เอาเฉพาะเดือน เป็นตัวเลข เติม 0 เพื่อให้ครบ 2 หลัก 4. G = groupStart 5. NNNNNNNN = LPAD(sequenceStart,0,8) เติม 0 ให้ครบ 8 หลัก **กรณีครั้งถัดไป** 1. Fix "CNPAY" 2. YYYY = systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลข 3. MM = systemDate เอาเฉพาะเดือน เป็นตัวเลข เติม 0 เพื่อให้ครบ 2 หลัก 4. ตรวจ transactionID 8 หลักสุดท้าย 4.1 ถ้า transactionID 8 หลักสุดท้าย <> 99999999 : G = groupStart 4.2 ถ้า transactionID 8 หลักสุดท้าย = 99999999 : G = groupEnd 4.3 ถ้า transactionID 8 หลักสุดท้าย <> 99999999 : NNNNNNNN = transactionID 8 หลักสุดท้าย + 1 4.4 ถ้า transactionID 8 หลักสุดท้าย = 99999999 : NNNNNNNN = 00000001
  3. เรียก [03 WS สำหรับ Call Program : OLIS/SPGN031 เพื่อขอ Sequence Id จากระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1289750156) สำหรับข้อมูล Transaction (Path : "/QSYS.LIB/OLIS.LIB/SPGN031R.PGM") โดยส่ง Parameter ดังต่อไปนี้NameDescriptionValuesystemชื่อระบบpaymentType+"TR"tableชื่อไฟล์ที่จะ GenerateFix "BFPPAYTR"yearปีปัจจุบัน (ค.ศ.)systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลขmonthเดือนปัจจุบันsystemDate เอาเฉพาะเดือน เป็นตัวเลขtotalKeyจำนวนรายการที่ต้องการจองเลข PKtotalPaymentจากนั้น อ่านข้อมูล Output ของ WS
    1. ถ้า primaryFlag = "F" ให้เก็บข้อมูลจาก WS ดังนี้
      1. groupStart = seqGroupStart จาก WS
      2. sequenceStart = seqStart จาก WS
      3. groupEnd = seqGroupEnd จาก WS
      4. sequenceEnd = seqEnd จาก WS
    2. ถ้า primaryFlag = "T" ให้เก็บข้อมูล transactionID = seqPrimaryKey จาก WS
  4. เริ่ม Loop ด้วยข้อมูลใน List<paymentDetail> ภายใต้ประเภทการจ่าย โดยทำที่ละรายการจ่าย
    1. สำหรับการกำหนด transactionID กรณีที่ List<paymentDetail> มากกว่า 1 กำหนด transactionID ตาม Format : {paymentType}TRYYYYMMGNNNNNNNN โดย กำหนด transactionID **กรณีครั้งแรก (Start Loop)** 1. Fix paymentType+"TR" 2. YYYY = systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลข 3. MM = systemDate เอาเฉพาะเดือน เป็นตัวเลข เติม 0 เพื่อให้ครบ 2 หลัก 4. G = groupStart 5. NNNNNNNN = LPAD(sequenceStart,0,8) เติม 0 ให้ครบ 8 หลัก **กรณีครั้งถัดไป** 1. Fix paymentType+"TR" 2. YYYY = systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลข 3. MM = systemDate เอาเฉพาะเดือน เป็นตัวเลข เติม 0 เพื่อให้ครบ 2 หลัก 4. ตรวจ transactionID 8 หลักสุดท้าย 4.1 ถ้า transactionID 8 หลักสุดท้าย <> 99999999 : G = groupStart 4.2 ถ้า transactionID 8 หลักสุดท้าย = 99999999 : G = groupEnd 4.3 ถ้า transactionID 8 หลักสุดท้าย <> 99999999 : NNNNNNNN = transactionID 8 หลักสุดท้าย + 1 4.4 ถ้า transactionID 8 หลักสุดท้าย = 99999999 : NNNNNNNN = 00000001
    2. ดึงข้อมูล [tx_payment](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment) จาก paymentID
    3. sumTransaction = sumTransaction + 1
    4. sumPaymentAmount = sumPaymentAmount + [tx_payment](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment).total_net_amount
    5. เตรียมข้อมูล Mapping เพื่อบันทึกลง Transaction ดังนี้FieldDescriptionTypeMappingheaderIDHeader IDStringheaderID transactionIDTransaction IDStringtransactionID tagIDTag
