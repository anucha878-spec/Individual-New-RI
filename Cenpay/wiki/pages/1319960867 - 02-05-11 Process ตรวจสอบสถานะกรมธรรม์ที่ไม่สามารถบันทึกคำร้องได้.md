## Overview

ตรวจสอบสถานะกรมธรรม์ที่ไม่สามารถบันทึกคำร้องได้
**Repositories**: msa-benefitregister
**Service path**
**POST:** /thaisamut/rs/benefitregister/v1/common/check-policy-status-blocked
Icon
TYPE : <POST>
**อธิบายได้ดังนี้**
GET - Select
POST - Insert
PUT - Update
DELETE - Delete

## Input

| Name | Type | Description | Example | Validation |
|---|---|---|---|---|
| policyStatus | String | สถานะกรมธรรม์ | A | Required |
| policyType | String | ประเภทกรมธรรม์ | I | Required |
| requestType | String | ประเภทคำร้อง | F | Required |

## Process

1. ตรวจสอบสถานะกรมธรรม์ที่ไม่สามารถบันทึกคำร้องได้สถานะกรมธรรม์

## Output

<แสดงข้อมูลที่จะได้รับจาก service นี้>

| **Name** | **Type** | **Description** | **Example** |
|---|---|---|---|
| policyStatusBlocked | boolean | Yes = สถานะกรมธรรม์ไม่สามารถบันทึกคำร้องได้No = สถานะกรมธรรม์สามารถบันทึกคำร้องได้ | True |
