# Objectives

- `เพื่อสร้าง Voucher ล้างค้างจ่ายค่าธรรมเนียมของรายการที่ตั้งค้างจ่ายไว้`

# Process Overview

- `Batch Process นี้จะทำงานทุกวันเวลา 01:00 น.`
- นำ Transaction ของค่าธรรมเนียมที่ค้างจ่ายของเดือนก่อนหน้า ส่งเข้า EDW โดยจัดกลุ่มตามธนาคาร อ้างอิง[เงื่อนไขบันทึกบัญชี ค่าธรรมเนียมธนาคาร](https://docs.google.com/spreadsheets/d/1pib9noHmrFmCdxqP2698HORO_mmF69HT/edit?gid=1811908193#gid=1811908193)

# Pre-conditions

- `ต้องมีรายการ Transaction ที่สถานะส่งเข้า edw เป็นบัญชีพัก`
- `Batch สามารถเชื่อมต่อกับฐานข้อมูลของระบบ Payment Management และสามารถเรียกใช้งาน Web Service ของ EDW ได้`

# Process Description

1. ตรวจสอบ Target Date ของเดือน
  1. ตรวจสอบ Target Date เป็นวันที่ 7 ของเดือนและไม่ตรงกับวันหยุด
    1. โดยใช้**MSA Service :** GET:/thaisamut/rs/mastersetting/v1/holiday/{year}/{type}
    2. โดยส่งพารามิเตอร์ ปี (ค.ศ.) (YYYY) และ ประเภทของวันหยุด (Fix "HQ") โดยผลลัพธ์จะ return รายการวันหยุดมาให้
    3. เทียบวันต้องไม่ตรงกับวันหยุดและวันหยุดเสาร์และอาทิตย์
    4. ถ้าวันที่ 7 ตรงกับวันหยุดให้ Target Date +1 วันและตรวจสอบไม่ตรงกับวันหยุดจนกว่าจะเจอ Target Date
  2. ถ้าวันปัจจุบันเป็น Target Date ให้ Batch ทำงานต่อ
  3. ถ้าวันปัจจุบันไม่เป็น Target Date ให้ Batch จะหยุดทำงาน
  4. กรณีมีการซ่อมข้อมูล วันที่ Input จะรับวันที่ประมวลผล ให้ตรวจสอบแทนวันที่ปัจจุบัน
2. `ตรวจสอบข้อมูล Transaction ที่มีการตั้งค้างจ่ายค่าธรรมเนียม โดยมีสถานะส่งเข้า edw เป็นบัญชีพัก และอยู่ในช่วงเดือนก่อนหน้า และประเภทการจ่ายเป็น Batch Payment หรือ Paperbase Payment – updated by patcha.vo 09/06/69`

# Post-conditions & Error Handling

- `Post-conditions (Success):`
- `Post-conditions (Failure) & Error Handling:`
  - กรณีเรียก`Web Service ไม่สำเร็จ (e.g., HTTP 5xx, Timeout):`
    - `Action`: ระบบจะบันทึก `Log` ข้อผิดพลาดของทั้งกลุ่ม (chunk) ที่เรียกไม่สำเร็จ และข้ามไปทำงานกลุ่มถัดไป
  - `กรณี Database Update ไม่สำเร็จ:`
    - `Action: ระบบจะพยายาม Rollback การเปลี่ยนแปลงสำหรับรายการนั้น และบันทึก Log ข้อผิดพลาดร้ายแรง`
