# **Input**

| Input | Description | Required |
|---|---|---|
| sourceRefNo | รหัสอ้างอิงรายการคำร้อง | Y |
| paymentId | รหัสตาราง [tx_payment](/display/RDSCPENH/tx_payment).id | Y |
| statusCode | สถานะดำเนินการ | Y |
| remark | สาเหตุการเปลี่ยนสถานะ | N |

# **กระบวนการ**

1. ค้นหา [tx_request](/display/RDSCPENH/03_01+tx_request).id ด้วยเงื่อนไข
- [tx_payment](/display/RDSCPENH/tx_payment).id = input.paymentId
- [tx_request](/display/RDSCPENH/03_01+tx_request).id = input.sourceRefNo
2. Update data table : [tx_request](/display/RDSCPENH/03_01+tx_request) (benefitregister)

| field | description | mapping data |
|---|---|---|
| status_code | สถานะรายการ | input.statusCode |
| updated_by | ผู้แก้ไขข้อมูลล่าสุด | Fix : 'System' |
| updated_date | วันที่และเวลาแก้ไขข้อมูลล่าสุด | SystemDate |

3. Insert data table : [lg_request_process](/display/RDSCPENH/03_08+lg_request_process) (benefitregister)

| field | description | mapping data |
|---|---|---|
| tx_request_id | รหัสตาราง [tx_request](/display/RDSCPENH/03_01+tx_request).id | [tx_request](/display/RDSCPENH/03_01+tx_request).id |
| status_code | สถานะรายการ | input.statusCode |
| remark | หมายเหตุ | input.remark |
| created_by | ผู้สร้างข้อมูล | Fix : 'System' |
| created_date | วันที่และเวลาสร้างข้อมูล | SystemDate |
