# AM_PM-02 Voucher มีสถานะเป็น ข้อมูลบัญชีไม่ถูกต้อง

- **Page ID:** 1331560931
- **URL:** http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1331560931
- **Path:** Home > Admin Manual > PayM > AM_PM-02 Voucher มีสถานะเป็น ข้อมูลบัญชีไม่ถูกต้อง
- **Depth:** 3

---

**Step 1 ตรวจสอบคู่บัญชี**
ดำเนินการตรวจสอบข้อมูลคู่บัญชีผ่าน [WS สำหรับดึงข้อมูลคู่บัญชี](/pages/viewpage.action?pageId=1288503885) โดยอ้างอิง Input จาก [หน้าจอ Popup รายละเอียดการบันทึกบัญชี (คู่บัญชี)](/pages/viewpage.action?pageId=1275560859)
**Step 2 ซ่อมข้อมูลคู่บัญชีที่ไม่ถูกต้อง**
- กรณีรายการจากระบบ Payment ครบถ้วน แต่จำนวนเงิน Dr. / Cr. ไม่ถูกต้อง ให้ดำเนินการ Update ข้อมูลที่ไม่ถูกต้องในฝั่ง EDW อ้างอิง[Process การนำเข้าและบันทึกข้อมูลลงระบบ EDW รายการธุรกรรม จ่ายเงิน, รายการไม่ผ่านตรวจสอบ และค่าธรรมเนียมธนาคาร](/pages/viewpage.action?pageId=1284571785)
- กรณีรายการจากระบบ Payment ไม่ครบถ้วน หรือไม่พบรายการ แต่มีการสร้าง referenceNumber เรียบร้อยแล้ว ให้ดำเนินการ Insert ข้อมูลใหม่ในฝั่ง EDW อ้างอิง[Process การนำเข้าและบันทึกข้อมูลลงระบบ EDW รายการธุรกรรม จ่ายเงิน, รายการไม่ผ่านตรวจสอบ และค่าธรรมเนียมธนาคาร](/pages/viewpage.action?pageId=1284571785)
- กรณีไม่พบรายการ และยังไม่มีการสร้าง referenceNumber ในฝั่ง EDW ให้ดำเนินการส่งข้อมูลใหม่ทั้งชุด โดยการปรับสถานะของ Voucher ตามเงื่อนไขของ Step 3
**Step 3 Update Status**
ดำเนินการอัปเดตสถานะของ Voucher เงื่อนไขดังนี้
- อัปเดตข้อมูลที่ตาราง [tx_payment_dashboard](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_dashboard)fielddescriptionmapping databatch_payment_idรหัสอ้างอิงข้อมูลการจ่ายระดับ Batch ฝ่ายการเงิน[tx_batch_payment](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_batch_payment).idapproved_typeประเภทการอนุมัติตรวจสอบ event_codeกรณี event_code = 'PM_FIN_01' หรือ 'PM_FIN_03'บันทึก APAR - อนุมัติและบันทึกบัญชีกรณี event_code = 'PM_FIN_02'บันทึก APAC - อนุมัติจ่ายและบันทึกบัญชีposting_dateวันที่บันทึกบัญชีบันทึกวันที่ทำรายการvoucher_statusสถานะดำเนินการบันทึก EDP - EDW Processingupdated_dateผู้แก้ไขบันทึกวันและเวลาปัจจุบันupdated_byวันที่แก้ไขบันทึก username ที่ทำรายการ <![CDATA[UPDATE public.tx_payment_dashboard SET batch_payment_id=&#39;@batch_payment_id ที่ทำรายการ&#39;, voucher_status=&#39;EDP&#39;,updated_date=&#39;@datetime&#39;, updated_by=&#39;@Username&#39; WHERE id=&#39;@id ที่ทำรายการ&#39;;]]>
