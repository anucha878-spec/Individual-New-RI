# BATCH-PY002 Batch บันทึกผลการขึ้นเงินรหัสรับเงิน BBL (พัฒนาใน Ph2)

- **Depth:** 4

#### Description

| **No.** | **Topic** | **Description** |
|---|---|---|
| 1 | ชื่อและวัตถุประสงค์(Name and Objective) | Batch บันทึกผลการขึ้นเงินรหัสรับเงิน BBL |
| 2 | สัมพันธ์กับกระบวนการ(Link to process) | การตรวจสอบสถานะการโอนเงินกับธนาคารโดยตรง สำหรับรายการจ่ายที่มีประเภท Service เป็น BBL และมีสถานะรหัสรับเงิน BBL เป็น รอขึ้นเงิน จะถูกดำเนินการตรวจสอบสถานะการขึ้นเงินโดยเชื่อมต่อผ่าน API Gateway ไปยัง Service ธนาคาร BBL เพื่อรับผลการขึ้นเงินรหัสรับเงิน และกลับมาอัปเดตสถานะของ รหัสรับเงิน BBL ของรายการ Transaction การจ่ายกระบวนการอัปเดตข้อมูลสถานะการขึ้นเงินรหัสรับเงิน BBL กลับไประบบ Cenpay Module [ตรวจสอบและอนุมัติรายการเตรียมจ่ายผลประโยชน์](/pages/viewpage.action?pageId=1255703317) |
| 3 | เวลาประมวลผลโดยประมาณ (Time) | ทุกๆ X ชั่วโมง หรือ ตามรอบเวลาที่กำหนด |
| 4 | ข้อมูลตั้งต้น(Input) | รายการจ่ายที่ รหัสรับเงิน BBL มีสถานะการขึ้นเงินเป็น รอขึ้นเงิน |
| 5 | ข้อมูลที่ได้จากระบบ(Output) | สถานะการขึ้นเงินของรหัสรับเงิน BBL เปลี่ยนเป็น ขึ้นเงินแล้ว, ยกเลิก หรือหมดอายุ |
| 6 | อธิบายรายละเอียด(Description) | **Pre-condition (เงื่อนไขก่อนการทำงาน)**รายการที่ประเภท Service เป็น BBL ที่ถูกอนุมัติจ่ายเงินจากหน้าจอ [PY-005-FC-001 หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1271234731) โดยมีสถานะรหัสรับเงิน BBL เป็น รอขึ้นเงิน**Process Description (กระบวนการ)**ตรวจสอบเงื่อนไข :ระบบจะทำการคัดกรองรายการจ่ายที่มีคุณสมบัติตรงตามที่กำหนดคือ:สถานะการขึ้นเงินของรหัสรับเงิน BBL: รอขึ้นเงินส่งคำขอตรวจสอบสถานะ :****ส่งรายการไปตรวจสอบสถานะการขึ้นเงิน โดยระบบจะเชื่อมต่อผ่าน API Gateway เพื่อส่งคำขอไปยังระบบของธนาคาร BBLรับผลการจ่ายเงิน ระบบจะรอรับผลลัพธ์สถานะของรหัสรับเงิน BBL และข้อมูลการขึ้นเงิน จากธนาคารผ่าน APIอัปเดตสถานะ Transaction เมื่อได้รับผลจากธนาคาร BBL ระบบจะนำข้อมูลมาอัปเดตสถานะของรหัสรับเงิน BBL และข้อมูลการขึ้นเงิน เช่นวันที่ขึ้นเงินกระบวนการอัปเดตข้อมูลสถานะการจ่ายกลับไประบบ Cenpay ดำเนินการอัปเดตสถานะการขึ้นเงินรหัสรับเงิน BBL ที่หน้าจอ [PC-001-FC-001 หน้าจอรวมจ่าย](/pages/viewpage.action?pageId=1270252010) และหน้าจอ [PC-002-FC-001 หน้าจอตรวจสอบรายการเตรียมจ่าย](/pages/viewpage.action?pageId=1270252058)กระบวนการประมวลผลข้อมูลบัญชีผังXXXไปแสดงที่หน้าจอ [PY-005-FC-001 หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1271234731) เพื่อบันทึกบัญชี กรณีที่สถานะรหัสรับเงินเป็น หมดอายุ หรือ ยกเลิกตั้งรายการที่ระบบ CCC เพื่อทำจ่ายใหม่**Post-condition (เงื่อนไขหลังการทำงาน)**ระบบ Cenpay รับรู้สถานะการขึ้นเงินรหัสรับเงิน BBL จากทีมการเงินมีการตั้งรายการเพื่อรอแก้ไขข้อมูลและทำจ่ายใหม่ที่ระบบ Cenpayระบบ EDW บันทึกบัญชีผัง XXX |
