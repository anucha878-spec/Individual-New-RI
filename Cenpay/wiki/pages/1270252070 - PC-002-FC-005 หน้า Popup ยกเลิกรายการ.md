### วัตถุประสงค์ (Objective)

- เพื่อใช้ในการยกเลิกรายการธรุกรรมจ่าย

### ผู้ใช้งาน (Target Users)

- ฝ่ายปฎิบัติการ (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- กดปุ่ม ยกเลิกรายากร ที่หน้าจอ [PC-002-FC-001 หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) บนรายการที่มีสถานะรายการเป็น รอเตรียมจ่าย เท่านั้น

### การกระทำกับหน้าจอ (Actions)

- กดปุ่มปิด เพื่อปิดหน้าจอยกเลิกรายการ
- กดปุ่มยืนยัน เพื่อบันทึกข้อมูลยกเลิกรายการจ่ายที่ต้องการได้

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้ยกเลิกรายการจ่าย ตามรายการที่ต้องการได้

### การจัดการข้อผิดพลาด (Exceptional Handling)

- มีการตรวจสอบข้อมูลการเปลี่ยนช่องทางการจ่ายเงินตามที่ระบุ โดย
  - ตรวจสอบข้อมูลที่จำเป็นต้องระบุ คือ สาเหตุยกเลิก

### รายละเอียดเงื่อนไขปุ่ม

| No | Component Type | Component Name | Default Value | Validation Rules/Action | Example | Remark |
|---|---|---|---|---|---|---|
| 1 | Button | ปิด | Enable | เมื่อกดปุ่มปิด ระบบจะทำการปิดหน้าจอ Popup ดังกล่าวทิ้ง โดยจะกลับไปแสดงที่หน้าจอหลักเดิมก่อนหน้า และไม่ทำอะไรกับข้อมูลใดๆทั้งสิ้น |   |   |
| 2 | Button | ยืนยัน | Enable | เมื่อกดปุ่มยืนยัน ระบบจะทำการตรวจสอบข้อมูล ระบุสาเหตุยกเลิก ว่ามีการระบุข้อมูลหรือไม่ถ้าไม่ระบุ ระบบจะขึ้นข้อความแจ้งเตือนว่า "กรุณาระบุสาเหตุยกเลิก ก่อนกดยืนยัน" --> "กรุณาระบุสาเหตุยกเลิก" พร้อมด้วยปุ่ม ปิด ให้ปิดข้อความแจ้งเตือนแล้วกลับมาอยู่ในหน้าจอเดิมถ้าระบุ ระบบจะทำการยกเลิกรายการจ่ายเดิม และเก็บข้อมูลสาเหตุที่ขอยกเลิกไว้ และบันทึกสถานะรายการที่ [หน้าจอรวมจ่าย](/pages/viewpage.action?pageId=1270252010) และ [หน้าจอตรวจสอบรายการเตรียมจ่าย](/pages/viewpage.action?pageId=1270252058) เป็น ยกเลิกรายการจ่าย กรณี "ประเภทการจ่าย" เท่ากับ กู้ใหม่ หรือ กู้เพิ่ม ให้ระบบบันทึกสถานะรายการ กลับไปที่หน้าจอค้นหาคำร้องขอกู้เงินของระบบ New Loan ว่า ยกเลิกสัญญาเงินกู้ |   | New Loan Ph1 |
