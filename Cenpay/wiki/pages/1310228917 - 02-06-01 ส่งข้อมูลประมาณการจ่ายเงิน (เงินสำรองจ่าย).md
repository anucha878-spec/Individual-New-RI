## Objectives

- นำเข้าข้อมูล Transaction ข้อมูลประมาณการจ่ายเงิน (เงินสำรองจ่าย) จากระบบ Centralized Tax ส่งเข้าระบบ Centralized Payment

## Process Overview

- ระบบ Centralize Tax ส่งข้อมูล Transaction ข้อมูลประมาณการจ่ายเงิน (เงินสำรองจ่าย) ให้ระบบ Centralize Payment
- ข้อมูลรายการบัญชีส่งมา Centralized Payment แสดงที่หน้าจอ [[Menu PM0601 : รายงานประมาณการเงิน] FS-08-01 หน้าจอรายงานประมาณการเงิน](/pages/viewpage.action?pageId=1287946695)

## Preconditions

- ฝ่ายบัญชี ส่งข้อมูลจากระบบ Centralized Tax เมนู ประมวลผลปิด/เปิดงวด โดยคลิกที่ปุ่ม "ปิดงวด" ในคอลัมน์อนุมัติปิดงวดเดือน อ้างอิง [3.4.1 หน้าจอประมวลผลปิดงวดสิ้นเดือน](/pages/viewpage.action?pageId=865206606)

## Process Description

1. ค้นหาขอมูลการประมวลผลปิด/เปิดงวด อนุมัติปิดงวดเดือน รายละเอียด รับค่า Input Parameter : Period และ Round สำหรับค้นหาข้อมูล จากหน้าจอ [3.4.1 หน้าจอประมวลผลปิดงวดสิ้นเดือน](/pages/viewpage.action?pageId=865206606) ปุ่มกด "อนุมัติประมวลผลปิดงวดเดือน" ค้นหาข้อมูลจาก Table : [CT_CLOSE_MONTH](/display/RDSCTAX/CT_CLOSE_MONTH) ฟิลด์ PERIOD, ROUND, UPDATED_DATE, UPDATED_BY และ [CT_DATA_REPORT](/display/RDSCTAX/CT_DATA_REPORT) ฟิลด์ ผลรวม(WHT_AMOUNT) ด้วยเงื่อนไข ดังนี้- ฟิลด์ [CT_DATA_REPORT](/display/RDSCTAX/CT_DATA_REPORT).PERIOD = ปิดงวดเดือน (ที่อนุมัติประมวลจากหน้าจอ) - ฟิลด์ [CT_DATA_REPORT](/display/RDSCTAX/CT_DATA_REPORT).ROUND = ครั้งที่ปิดงวดเดือน (ที่อนุมัติประมวลจากหน้าจอ) - ฟิลด์ [CT_DATA_REPORT](/display/RDSCTAX/CT_DATA_REPORT).WHT_AMOUNT > 0 (ต้องมียอด Withholding Tax) - ฟิลด์ [CT_DATA_REPORT](/display/RDSCTAX/CT_DATA_REPORT).ACTIVE_FLAG = TRUE (สถานะรายการ ต้องมีสถานะที่ใช้งาน) - ฟิลด์ [CT_CLOSE_MONTH](/display/RDSCTAX/CT_CLOSE_MONTH).STATUS = S หรือ D (สถานะปิดงวดเดือน ต้องผ่านการอนุมัติประมวลผลปิดงวดเดือนแล้ว) - ฟิลด์ [CT_CLOSE_MONTH](/display/RDSCTAX/CT_CLOSE_MONTH).SEND_REIM_STATUS <> SUC (สถานะการส่งข้อมูลประมาณการจ่าย ต้องยังไม่ผ่านการการส่งข้อมูลประมาณการจ่าย) - ฟิลด์ [CT_CLOSE_MONTH](/display/RDSCTAX/CT_CLOSE_MONTH).MONTH <> 13 (ไม่เอาปิดงวดปี) จัดกลุ่มข้อมูล [CT_CLOSE_MONTH](/display/RDSCTAX/CT_CLOSE_MONTH) ฟิลด์ PERIOD, ROUND, UPDATED_DATE, UPDATED_BY กรณี **พบ** ข้อมูล ดำเนินการ (*ข้อที่ 2*) ต่อกรณี **ไม่พบ** ข้อมูล เรียก [02-06-02 ส่งข้อมูลการอนุมัติตรวจจ่ายเงิน](/pages/viewpage.action?pageId=1310228919)**หมายเหตุ** กรณี Manual Support [3.10.2 Resend ส่งข้อมูลประมวลผลปิดงวดเดือน ไปที่ Cenpay](/pages/viewpage.action?pageId=1313145497) ไม่ต้องใช้เงื่อนไข send_reim_status <> 'SUC' *เนื่องด้วยเป็นการ Resend ส่งข้อมูลประมวลผลปิดงวดเดือน เพื่อส่งให้ฝ่ายการเงินทำจ่าย กรมสรรพากรใหม่
