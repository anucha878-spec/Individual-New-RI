### วัตถุประสงค์ (Objective)

- เพื่อใช้ในการอนุมัติรายการคำร้อง

### ผู้ใช้งาน (Target Users)

- สนญ ([benefitregister:menu:pc0101](http://benefitregistermenupc0101/), [benefitregister:menu:pc0102](http://benefitregistermenupc0102/) และ [benefitregister:role:approvemanager](http://benefitregisterroleapprovemanager/))

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- กดไอคอน อนุมัติรายการ หน้ารายการคำร้องที่ต้องการอนุมัติ ที่หน้าจอ [LS-001-FC-001 : หน้าจอค้นหารายการคำร้องเวนคืนกรมบังคับคดี](/pages/viewpage.action?pageId=1327431993)

### การกระทำกับหน้าจอ (Actions)

- กดปุ่มยกเลิก เพื่อปิดหน้าจอยกเลิกรายการ
- กดปุ่มยืนยัน เพื่ออนุมัติรายการคำร้อง

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้อนุมัติรายการคำร้อง ตามรายการที่ต้องการได้ และส่งรายการไปที่หน้าจอรวมการจ่ายของฝ่ายปฏิบัติการ

### การจัดการข้อผิดพลาด (Exceptional Handling)

- ไม่มี เป็นเพียงหน้าจอที่ใช้ยืนยันการอนุมัติรายการคำร้องเท่านั้น

| 3 | Label | เลขที่รับเรื่อง |   | L2568/1500/00001 |   |

|---|---|---|---|---|---|---|
| 1 | Button | ยกเลิก | Enable | เมื่อกดปุ่มยกเลิก ระบบจะทำการปิดหน้าจอ Popup ดังกล่าว |   |   |
| 2 | Button | ยืนยัน | Enable | เมื่อกดปุ่ม ระบบจะทำการอนุมัติรายการคำร้อง โดยการปรับสถานะรายการเป็น "รอเตรียมจ่าย (ปฏิบัติการ)" |   |   |
