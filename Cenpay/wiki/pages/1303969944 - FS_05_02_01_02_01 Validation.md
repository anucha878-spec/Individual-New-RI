1. Validation :
  1. ตรวจสอบข้อมูลที่จำเป็นต้องระบุดังนี้
      - ข้อมูลทั่วไป
        - ประเภทคำร้อง
        - เลขที่กรมธรรม์
      - ข้อมูลผู้เอาประกัน
        - วันบัตรหมดอายุ **----- Centralize Payment Enhance Phase 2 Add by thidarat.lu 08/04/2026 ----**
        - เบอร์โทรศัพท์ลูกค้าที่ประสงค์ รับผลการพิจารณา
      - ข้อมูลผู้ยื่นเอกสาร
        - กรณี เลือกข้อมูลความสัมพันธ์ เป็น นิติบุคคล/สถาบัน/สาธารณกุศล
          - ชื่อ
          - ความสัมพันธ์
          - เบอร์โทรศัพท์ผู้ยื่นเอกสาร
          - เลขประจำตัวประชาชนผู้ยื่นเอกสาร
          - วันบัตรหมดอายุ
        - กรณี อื่นๆ
          - คำนำหน้า
          - ชื่อ
          - นามสกุล
          - ความสัมพันธ์
          - เบอร์โทรศัพท์ผู้ยื่นเอกสาร
          - เลขประจำตัวประชาชนผู้ยื่นเอกสาร
          - วันบัตรหมดอายุ
      - เอกสารประกอบคำร้อง **----- Centralize Payment Enhance Phase 2 Add by thidarat.lu 08/04/2026 ----**
        - เอกสารแนบ **----- Centralize Payment Enhance Phase 2 Add by kanawoot.ou 22/06/2026 ----**
        - กรณี กด button บันทึกร่าง **ไม่ต้องตรวจสอบเอกสารแนบ**
        - กรณี กด button บันทึก **ต้องตรวจสอบเอกสารแนบ**
      - Checkbox เอกสาร 'สำเนาบัตรประจำตัวประชาชน/หนังสือเดินทาง/สูติบัตร/บัตรข้าราชการ/ใบขับขี่'
  3. ตรวจสอบข้อมูลยอดเงินจ่ายสุทธิ : ยอดเงินผลประโยชน์สุทธิ รวมทั้งสิ้น ([tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).total_benefit_amount) กรณีน้อยกว่าเท่ากับ 0.00 ให้ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้Alert CodeReplace Value[err_pr_011](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
  4. ตรวจสอบข้อมูลผู้รับเงิน **(เฉพาะกรณีประเภทคำร้องเป็นขอ Free Look หรือขอเวนคืนกรมธรรม์ประกันภัย ('S','F'))** **และประเภทคำร้องขอรับเงินผลประโยชน์จากทะเบียนรอจ่ายใหม่ ('R') ----- Centralize Payment Enhance Phase 2 Add by thidarat.lu 27/05/2026 ----**
    1. ตรวจสอบช่องทางการรับเงิน กรณี**ไม่ใช่**โอนเงิน ('TP','TB','TE') ให้ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้ Alert CodeReplace Value[err_pr_002](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
    2. ตรวจสอบเลขที่บัญชี และ ID Card โดยมี 2 กรณี ดังนี้
        - กรณีช่องทางการรับเงินเป็นโอนเงิน-ปกติ หรือ โอนเงิน-ด่วน ('TB','TE') แต่**ไม่**มีข้อมูลเลขที่บัญชี
        - กรณีช่องทางการรับเงินเป็นโอนเงิน-พร้อมเพย์ ('TP') แต่**ไม่**มีข้อมูล ID Card
      - หากเข้าเงื่อนไขอย่างใดอย่างหนึ่ง ให้ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้ Alert CodeReplace Value[err_pr_003](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
    3. หากไม่เข้าเงื่อนไข ให้ระบบทำการตรวจสอบข้อ c. ต่อไป
  5. ตรวจสอบการบันทึกข้อมูลสำหรับขอ Free Look **(เฉพาะกรณีประเภทคำร้องเป็นขอ Free Look ('F'))** ****----- Centralize Payment Enhance Phase 2 Add by kanawoot.ou 02/07/2026 ----****
      - กรณีเป็น e-policy และ**ไม่**ได้ออกเล่มกรมธรรม์
        - **ไม่**ได้ระบุ วันที่ลูกค้าได้รับอีเมล
      - กรณีเป็น e-policy และออกเล่มกรมธรรม์
        - **ไม่**ได้ระบุ วันที่ลูกค้าได้รับอีเมล
        - **ไม่**ได้เลือก Check Box ได้รับเล่มกรมธรรม์ หรือ Check Box ไม่ได้รับเล่มกรมธรรม์
      - กรณีเป็น e-policy แต่**ไม่**ได้ระบุ วันที่ลูกค้าได้รับอีเมล
      - กรณีไม่ใช่ e-policy และ**ไม่**ได้เลือก Check Box ได้รับเล่มกรมธรรม์ หรือ Check Box ไม่ได้รับเล่มกรมธรรม์
    1. หากเข้าเงื่อนไขอย่างใดอย่างหนึ่ง ให้ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้ ****Alert CodeReplace Value[wrn_pr_001](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-และทำการ auto focus ที่ปุ่ม "ข้อมูลสำหรับขอ Free Look" ด้วย
    2. หากไม่เข้าเงื่อนไข ให้ระบบทำการตรวจสอบข้อ e. ต่อไป
  6. ตรวจสอบว่ามีการยื่นคำร้องซ้ำหรือไม่ **(หน้าแก้ไขคำร้องไม่ต้องตรวจสอบ)**
