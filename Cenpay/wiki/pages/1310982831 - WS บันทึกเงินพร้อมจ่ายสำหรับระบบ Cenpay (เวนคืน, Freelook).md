## Process

### จัดกลุ่มข้อมูลนำเข้า ตาม paymentType แล้ววนทำทีละ paymentType

1. (ทำเฉพาะ paymentType not in ('NLN','NLO')) ค้นหารายการ TagID อ้างอิงการจ่ายที่ระบบ AS400 ดังนี้
  1. เก็บ Input เป็น List<Array> โดยการวนเก็บข้อมูลตาม List รายการที่ได้รับเข้ามา ดังนี้NameDescriptionValuepaymentTypeประเภทการจ่ายpaymentType จากรายการนำเข้าpolicyNoเลขที่กรมธรรม์policyNo จากรายการนำเข้าtargetDateวันที่มีผลหรอวันที่คำร้องrequestDate จากรายการนำเข้า
  2. เรียก WS : [09 WS ดึงข้อมูลอ้างอิงรายการจ่ายจากระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1325564017) (ข้อมูล AS400) โดยใช้ข้อมูลจาก List<Array>
2. (ทำเฉพาะ paymentType not in ('NLN','NLO')) ตรวจสอบข้อมูลตาม paymentType เทียบกับข้อมูลเดิมที่มีอยู่ในระบบ Cenpay ที่ไม่ใช่สถานะยกเลิกการจ่าย ด้วย Query ตามด้านล่าง SQL select tp.tag_id,tp.oper_ref_nofrom tx_payment_benefit_master tpbminner join tx_payment tpon tpbm.payment_id = tp.idwheretp.payment_type = :paymentTypeand tp.payment_status_code <> 'CCP' -- ข้อมูลไม่ใช่สถานะยกเลิกรายการand tp.tag_id in :listTagID; -- List ของ TagID ที่ดึงได้จาก AS400
3. ใช้ Process : [CP-PC-00 01 การเรียกกำหนดเลขธุรกรรม](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1282507844) โดยดูเงื่อนไขตาม paymentType ที่ได้จากข้อมูลที่รับเข้ามา ดังนี้
  1. paymentType = 'NLN' ใช้ Prefix : CPNLNYYMMDD เมื่อ YY คือปี คศ. 2 หลักสุดท้าย โดย YYMMDD อ้างอิงตามวันที่ปัจจุบัน เพื่อให้ได้ชุดของเลขธรุกรรมมาใช้ในการบันทึกข้อมูล --> ปรับออกข้อมูล NLN
  2. paymentType = 'NLO' ใช้ Prefix : CPNLNYYMMDD เมื่อ YY คือปี คศ. 2 หลักสุดท้าย โดย YYMMDD อ้างอิงตามวันที่ปัจจุบัน เพื่อให้ได้ชุดของเลขธรุกรรมมาใช้ในการบันทึกข้อมูล --> ปรับออกข้อมูล NLO
  3. paymentType = 'PSP' ใช้ Prefix : CPPSPYYMMDD เมื่อ YY คือปี คศ. 2 หลักสุดท้าย โดย YYMMDD อ้างอิงตามวันที่ปัจจุบัน เพื่อให้ได้ชุดของเลขธรุกรรมมาใช้ในการบันทึกข้อมูล
  4. paymentType = 'FLP' ใช้ Prefix : CPFLPYYMMDD เมื่อ YY คือปี คศ. 2 หลักสุดท้าย โดย YYMMDD อ้างอิงตามวันที่ปัจจุบัน เพื่อให้ได้ชุดของเลขธรุกรรมมาใช้ในการบันทึกข้อมูล
  5. paymentType = 'LEP' ใช้ Prefix : CPLEPYYMMDD เมื่อ YY คือปี คศ. 2 หลักสุดท้าย โดย YYMMDD อ้างอิงตามวันที่ปัจจุบัน เพื่อให้ได้ชุดของเลขธรุกรรมมาใช้ในการบันทึกข้อมูล --> ปรับเพิ่มกรณี LEP โดย ariya.pi เมื่อ 29/04/2569
4. (ทำเฉพาะ paymentType not in ('NLN','NLO')) กำหนด totalPaymentType = จำนวนของประเภทรายการจ่ายที่แตกต่างกัน และสร้าง List<payment>
5. วนข้อมูลตาม List รายการที่รับเข้ามา ที่แยกตามประเภทการจ่ายแล้ว ทีละรายการ
  1. (ทำเฉพาะ paymentType not in ('NLN','NLO')) **เริ่มต้นกระบวนการครั้งแรก** กำหนด totalTransaction = 0 และสร้าง List<paymentDetail>
  2. (ทำเฉพาะ paymentType not in ('NLN','NLO')) ตรวจสอบข้อมูลของ Tag ID ของรายการนำเข้า (ที่ได้จากข้อ 1) เทียบกับข้อมูล (ที่ได้จากข้อ 2)
    1. ถ้าพบว่ามีข้อมูลอยู่ในข้อ 2
      1. กรณีที่มาจาก WS ให้ Return : statusCode = 409 และ statusMessage = Confilct และหยุดรายการ
      2. กรณีที่มาจาก Batch ให้ลง Log : logBatchTrans จากนั้นวนข้อมูลรายการใหม่
    2. ถ้าไม่พบ ทำกระบวนการถัดไป
  3. (ทำเฉพาะ paymentType not in ('NLN','NLO')) totalTransaction = totalTransaction + 1
  4. **กำหนดเลขธุรกรรมที่ได้จากข้อ 1** โดยจะทำการเพิ่ม Sequence ขึ้นที่ละ 1 ต่อจากข้อมูลก่อนหน้า
  5. **เรียกข้อมูลที่ต้องการใช้จากระบบ CIS** โดยใช้ [01 WS สำหรับดึงข้อมูลผู้เอาประกันภัย ข้อมูลบัญชีรับผลประโยชน์ ข้อมูลที่อยู่ติดต่อระดับกรมธรรม์ เบอร์ติดต่อ และข้อมูลผู้รับผลประโยชน์ ที่ระบบ CIS](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1282507270) (ข้อมูล CIS) และส่งค่า Input ดังนี้NameDescriptionValuepolicyNoเลขกรมธรรม์policyNo จากรายการนำเข้าtransactionTypeข้อมูลประเภทบัญชีFix "BNF"addressTypeข้อมูลประเภทที่อยู่Fix "CON"
  6.
