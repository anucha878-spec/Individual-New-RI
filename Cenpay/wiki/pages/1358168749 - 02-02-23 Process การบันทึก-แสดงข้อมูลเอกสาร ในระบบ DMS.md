**2.Return**
รายละเอียด

- กรณีบันทึกข้อมูลเข้าสู่ระบบ New DMS สำเร็จ ให้ดำเนินการบันทึกข้อมูลเข้าสู่ระบบ Centralized Payment : enhancement & integration ตามขั้นตอนที่ 3 และ Return Data ดังนี้NameTypeDescriptionExampleresponse_typevarcharsuccess dmsDocumentIdLong id ของเอกสาร1

**View Document**
**การอัปโหลดไฟล์เข้าสู่ระบบ DMS มีขั้นตอนดำเนินการดังนี้**
**1.Input :**
รายละเอียด
**Step 1:**เตรียมข้อมูล Input Parameter ที่ส่งให้ Service ดังนี้

| Input Parameter | Mapping | Example |
|---|---|---|
| documentId | [tx_document](/display/RDSCPENH/tx_document).dms_doc_id | 6416914 |
| source_type | [tx_document](/display/RDSCPENH/tx_document).source_type | CENPAY*PAYMENTMG* |

**Step 2: **ค้นหาและแสดงรายละเอียดของเอกสารในระบบ DMS ตาม source_type****
- กรณี source_type = 'CENPAY' นำข้อมูล **documentId**ที่ทำรายการมาค้นหาและแสดงรายละเอียดของเอกสารในระบบ DMS (เวอร์ชั่นล่าสุดของเอกสารนั้น) โดยเรียกผ่าน [findLatestDocumentByDocumentId](/display/RDSDCMSPH1/findLatestDocumentByDocumentId)
- กรณี source_type = 'PAYMENTMG'**********นำข้อมูล****documentId ที่ทำรายการมาค้นหาและแสดงรายละเอียดของเอกสารในระบบ DMS**โดยเรียกผ่าน [07-04. การดูเอกสารจากระบบอื่น โดยเปิดลิ้งค์มาที่ระบบ DMS](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=983630572) ตัวอย่างลิ้งค์ + documentId /thaisamut/web/dms/index.html?documentId=${ file . 6416914}#SearchDocument
**2.Return**
รายละเอียด
Service Return ค่ากลับให้ระบบที่เรียกใช้
- กรณีไม่พบข้อมูลหรือดึงข้อมูลไม่สำเร็จ ให้แสดงข้อความแจ้งเตือนไปยังหน้าจอหลักที่ดำเนินการNameTypeDescriptionExampleresponse_typevarcharfail response_messagevarchar[01. Error Message](/display/RDSCPENH/01.+Error+Message) Alert Code = err_com_009ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ
