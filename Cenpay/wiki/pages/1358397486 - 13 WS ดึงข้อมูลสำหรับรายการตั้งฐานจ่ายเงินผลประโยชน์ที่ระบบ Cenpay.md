## Overview

ดึงข้อมูลสำหรับรายการตั้งฐานจ่ายเงินผลประโยชน์ที่ระบบ Cenpay

## Input

| Name | Type | Description | Example | Validation |
|---|---|---|---|---|
| moveDateFrom | String | วันที่เริ่ม | 2026-09-01 | Required |
| moveDateTo | String | วันที่ถึง | 2026-09-02 | Required |
| benefitType | Enum | ประเภทผลประโยชน์MAP = เงินครบสัญญาSBP = เงินทรงชีพPPY = เงินบำนาญ | MAP | Not Required |
| policyList | List<String> | List ของกรมธรรม์ที่กำหนด | ('0252701','0243417') | Not Requiredกำหนด Limit ไม่เกิน 500 |
| status | Enum | สถานะรายการA = Active สร้างข้อมูลสำเร็จ พร้อมสร้างจดหมายL = Letter สร้างข้อมูลจดหมายP = สร้างรายการใน Payment Master / Benefit Master แล้วH= Hold (จะ update จังหวะ T-4)M = Merged with existing payment entries | A | Not Required |

## Process

**ค้นหาข้อมูลเงินจ่ายคืนทันที DB: AS400**
1. ดึงข้อมูล Header ของผลประโยชน์จ่ายแต่ละประเภท <![CDATA[SELECT TRTGID AS tagId, TRPOLC AS policyNo, TRPOTY AS policyType, TRBFTY AS benefitType, TRSBTY AS subType, TRPERD AS benefitPeriodNo, TRYEAR AS benefitYear, TRDUDT AS paymentDueDate, TRBFAM AS grossAmount, TRBFNT AS netAmount, TRSTAS AS sourceStatus, TRCNFG AS centralizeFlag, TRHOLD AS holdReason, TRHDDT AS holdDate, TRCRDT AS sourceCreatedDate, TRUPDT AS sourceUpdatedDate FROM MBFLIB.BFPBTRHD WHERE (to_char(TRCRDT,&#39;yyyy-mm-dd&#39;) IN (:moveDateFrom,:moveDateTo) OR to_char(TRUPDT,&#39;yyyy-mm-dd&#39;) IN (:moveDateFrom,:moveDateTo)) -- ถ้ามีข้อมูล :benefitType AND TRBFTY = :benefitType -- ถ้ามีข้อมูล :policyList AND TRPOLC IN :policyList -- ถ้ามีข้อมูล :status AND TRSTAS = :status;]]>
2. ดึงข้อมูล Detail รายละเอียดของผลประโยชน์จ่ายแต่ละประเภท <![CDATA[SELECT TDTGID AS tagId, TDPOLC AS policyNo, TDPYTY AS payType, TDPYAM AS payAmount FROM MBFLIB.BFPBTRDT WHERE TDTGID IN (SELECT TRTGID AS tagId FROM MBFLIB.BFPBTRHD WHERE (to_char(TRCRDT,&#39;yyyy-mm-dd&#39;) IN (:moveDateFrom,:moveDateTo) OR to_char(TRUPDT,&#39;yyyy-mm-dd&#39;) IN (:moveDateFrom,:moveDateTo)) -- ถ้ามีข้อมูล :benefitType AND TRBFTY = :benefitType -- ถ้ามีข้อมูล :policyList AND TRPOLC IN :policyList -- ถ้ามีข้อมูล :status AND TRSTAS = :status);]]>
3. นำ Output ที่ได้จากข้อ 1 และ 2 ลงใน Output Object โดยข้อมูล Detail ให้ Group ตาม tagID
