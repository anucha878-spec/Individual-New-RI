3. ดำเนินการส่วนอื่นๆ
1. ส่งเอกสารเข้าระบบ DMS โดยอ้างอิงรายละเอียด [02-05-05 Process การบันทึก/แสดงข้อมูลเอกสาร ในระบบ DMS](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1307115563)Input ParameterMapping Field@documentTypeนำ [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).request_code ไปดึงข้อมูลจาก [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value)โดยเงื่อนไข group = 'DOCUMENT_TYPE' และ active_flag = 'A'ข้อมูลที่นำมาใช้ namedocumentTypeMappingPAYMENT_REQUEST_SURRENDER_LED[tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).request_code = 'L'@mapIndexIndex_codeMappingREQUEST_NO[tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).request_noPOLICY_NO[tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).policy_no@fileNameชื่อไฟล์ตามจริง@updateByUserName@Username ที่ทำรายการ@updateBySourceSystem Data Config = 'CENPAY'@branchCodeสาขาของ user ที่ทำรายการ@documentStatusData Config = 'APPROVE' **หมายเหตุ:** กรณีส่งข้อมูลคำร้องให้ระบบ DMS ไม่สำเร็จให้ดำเนินการดังนี้
  1. ระบบทำการแสดง pop-up แจ้งเตือนด้วย Alert Code ดังนี้Alert CodeReplace Value[err_pr_008](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message)-
  2. ระบบทำการ Rollback การบันทึกข้อมูลคำร้องทั้งหมด
2. ส่ง Auto Email แจ้งรับเรื่องให้สาขาต้นสังกัด โดยอ้างอิงรายละเอียด [02-05-04_01 Email แจ้งรับเรื่องให้สาขาต้นสังกัด](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1306854201)
3. ส่งข้อมูลเข้าระบบ AS400 โดยอ้างอิงรายละเอียด [02-05-08 Process ส่งข้อมูลคำร้องไปยังระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1316094367)Input ParameterMapping FieldrequestId[tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).id**หมายเหตุ:** กรณีส่งข้อมูลคำร้องให้ระบบ AS400 ไม่สำเร็จให้ดำเนินการดังนี้
  1. บันทึกข้อมูล Request Problem Tracking โดยใช้ Process [02-05-10_01 บันทึกข้อมูล Problem Tracking](/pages/viewpage.action?pageId=1319601299) และส่ง Input ดังนี้InputvalueDesciptionrequestId[tx_request](#FS-07-02-01_02_03ดำเนินการส่วนอื่นๆ-A_No2).idPK table [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request)processCodeFix "AS"รหัสอ้างอิง process ที่ดำเนินการไม่สำเร็จcreatedByผู้สร้างข้อมูล (เก็บ User ที่ใช้ Login เข้าระบบ เช่น Ocean.co)ผู้สร้างข้อมูล (เก็บ User ที่ใช้ Login เข้าระบบ เช่น Ocean.co)
