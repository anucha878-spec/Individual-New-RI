# 02-06-06 Notification แจ้งลูกค้ากรณีปฎิเสธหรือยกเลิกรายการ

- **Page ID:** 1304592551
- **URL:** http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1304592551
- **Path:** Home > Functional Specification > 02. Process Specification. > Centralized Payment > 02-02-02 กระบวนการส่ง Line/SMS Notification > 02-06-06 Notification แจ้งลูกค้ากรณีปฎิเสธหรือยกเลิกรายการ
- **Depth:** 5

---

1. ตรวจสอบรายการที่ต้องส่งข้อความแจ้งลูกค้ากรณีปฎิเสธหรือยกเลิกรายการ
- ตรวจสอบธุรกรรมเวนคืนกรมธรรม์ หรือ Freelook ([tx_payment](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment).payment_type in ('PSP','FLP')
- ตรวจสอบสถานะการจ่ายเป็น Format ไม่ผ่าน [tx_payment](/display/RDSCPENH/tx_payment).payment_status_code = 'CCP' - ยกเลิกรายการ
2.ดึงข้อความจาก [cf_notification](/display/RDSCPENH/cf_notification).sms_message และ [cf_notification](/display/RDSCPENH/cf_notification).line_message ด้วยเงื่อนไข [cf_notification](/display/RDSCPENH/cf_notification).noti_code = 'CP_CANCEL'
และประกอบข้อความกับ variable ดังนี้

| variable | description | mapping data |
|---|---|---|
| $(var1) | รายการธุรกรรมเวนคืนกรมธรรม์ยกเลิกกรมธรรม์ | [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/Table+%3A+cf_list_of_value).descriptionwhere [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/Table+%3A+cf_list_of_value).value = [tx_payment](/display/RDSCPENH/tx_payment).payment_typeand [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/Table+%3A+cf_list_of_value).group = 'CPH_PAYMENT_TYPE**'** |
| $(var2) | เลขกรมธรรม์ | [tx_payment_policy](/display/RDSCPENH/tx_payment_policy).policy_nowhere [tx_payment_policy](/display/RDSCPENH/tx_payment_policy).payment_id = [tx_payment](/display/RDSCPENH/tx_payment).idMasking โดยอ้างอิงเงื่อนไขข้อ 5 เลขกรมธรรม์ ใน [IT Development Common Validation](/display/RnD/IT+Development+Common+Validation) |
| $(var3) | จำนวนเงิน | [tx_payment](/display/RDSCPENH/tx_payment).total_net_amount |
