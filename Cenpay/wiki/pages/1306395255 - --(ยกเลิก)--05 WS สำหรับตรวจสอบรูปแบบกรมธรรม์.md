## Overview

ตรวจสอบรูปแบบกรมธรรม์ว่าเป็น e-Policy หรือรูปเล่ม (เฉพาะกรมธรรม์สามัญ และ PA)

## Protocol

Icon
<SOAP,HESSIAN,REST>

## Operation

refer : [ESB WebService Design Pattern](/display/IEA/ESB+WebService+Design+Pattern)
Icon
TYPE : <inquiry>

## Input

| Name | Type | Description | Example | Validation |
|---|---|---|---|---|
| policyNo | String | เลขที่กรมธรรม์ | 0252701 | Required |

## Process

**1. สามัญ**
<![CDATA[SELECT POLNO AS policyNo , POLFMT AS policyFormat FROM OLIS.OLPPOLEP a WHERE POLNO = :policyNo;]]>
**2. PA**
<![CDATA[ SELECT POLNO AS policyNo , POLFMT AS policyFormat FROM PPALIB.TBEPOLIC a WHERE POLNO = :policyNo;]]>
