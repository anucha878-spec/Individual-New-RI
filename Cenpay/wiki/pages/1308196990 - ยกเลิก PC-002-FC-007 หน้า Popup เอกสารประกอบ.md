### วัตถุประสงค์ (Objective)

- เพื่อใช้ในการเรียกดูเอกสารประกอบ

### ผู้ใช้งาน (Target Users)

- ฝ่ายปฎิบัติการ (Maker)
- ฝ่ายปฎิบัติการ (Checker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- กดปุ่ม ดูเอกสารประกอบ ที่หน้าจอ [PC-002-FC-001 หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) , [PC-003-FC-002 หน้าจออนุมัติรายการเตรียมจ่ายครั้งที่ 2](/pages/viewpage.action?pageId=1270252078) บนรายการที่มีสถานะรายการเป็น รอเตรียมจ่าย เท่านั้น

### การกระทำกับหน้าจอ (Actions)

- กดปุ่มปิด เพื่อปิดหน้าจอดูเอกสารประกอบ

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานเรียกดูเอกสารประกอบต่างๆ ตามรายการที่ต้องการได้

### การจัดการข้อผิดพลาด (Exceptional Handling)

- N/A

### รายละเอียดส่วนการแสดงผลข้อมูล

|---|
| **เอกสารประกอบ** |
| No | Component Type | Component Name | Action / Data Value | Example | Remark |

### รายละเอียดเงื่อนไขปุ่ม

| No | Component Type | Component Name | Default Value | Validation Rules/Action | Example | Remark |
|---|---|---|---|---|---|---|
| 1 | Button | ปิด | Enable | เมื่อกดปุ่มปิด ระบบจะทำการปิดหน้าจอ Popup ดังกล่าวทิ้ง โดยจะกลับไปแสดงที่หน้าจอหลักเดิมก่อนหน้า และไม่ทำอะไรกับข้อมูลใดๆทั้งสิ้น |   |   |
