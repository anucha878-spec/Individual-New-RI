# 02-04-05 Process บันทึกค่าธรรมเนียมธนาคาร

- **Page ID:** 1286668709
- **URL:** http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1286668709
- **Path:** Home > Functional Specification > 02. Process Specification. > Payment Management > 02-04-05 Process บันทึกค่าธรรมเนียมธนาคาร
- **Depth:** 4

---

1. ตรวจสอบรายการ [tx_payment_detail](/display/RDSCPENH/tx_payment_detail) ที่คิดค่าธรรมเนียม ต้องไม่เป็นรายการที่สถานะปฎิเสธหรือยกเลิก ([tx_payment_detail](/display/RDSCPENH/tx_payment_detail).status not in (REJ,CAN))
2. ตรวจสอบค่าธรรมเนียมจาก service ธนาคาร ที่ตาราง [cf_service_fee](/display/RDSCPENH/cf_service_fee).service = [tx_batch_payment](/display/RDSCPENH/tx_batch_payment).service_code
ตรวจสอบมีค่าคิดค่าธรรมเนียมต่างธนาคารหรือไม่
- กรณีมีการคิดค่าธรรมเนียมต่างธนาคาร ([cf_service_fee](/display/RDSCPENH/cf_service_fee).other_bank_fee = true)
  - ตรวจสอบรหัสธนาคารของ service จาก [cf_lookup_catalog](/display/RDSCPENH/cf_lookup_catalog).config where [cf_lookup_catalog](/display/RDSCPENH/cf_lookup_catalog).lookup_key [tx_batch_payment](/display/RDSCPENH/tx_batch_payment).bank_account_code
  - และเปรียบเทียบ [cf_lookup_catalog](/display/RDSCPENH/cf_lookup_catalog).config กับ [tx_payment_detail](/display/RDSCPENH/tx_payment_detail).bank_abbr_name
    - กรณีเป็นธนาคารเดียวกัน [cf_service_fee](/display/RDSCPENH/cf_service_fee).fee
    - กรณีไม่ใช่ธนาคารเดียวกัน [cf_service_fee](/display/RDSCPENH/cf_service_fee).other_bank_fee
- กรณีไม่มีการคิดค่าธรรมเนียมต่างธนาคาร
  - [cf_service_fee](/display/RDSCPENH/cf_service_fee).fee

|   | [cf_service_fee](/display/RDSCPENH/cf_service_fee).other_bank_flag | เงื่อนไข | ค่าธรรมเนียม |
|---|---|---|---|
| มีค่าธรรมเนียมต่างธนาคาร | True | กรณีเป็นธนาคารเดียวกัน | [cf_service_fee](/display/RDSCPENH/cf_service_fee).fee |
|   |   | กรณีต่างธนาคาร | [cf_service_fee](/display/RDSCPENH/cf_service_fee).other_bank_fee |
| ไม่มีค่าธรรมเนียมต่างธนาคาร | False | กรณีเป็นธนาคารเดียวกันหรือต่างธนาคาร | [cf_service_fee](/display/RDSCPENH/cf_service_fee).fee |

ตัวอย่างเช่น

| Service | มีค่าธรรมเนียมต่างธนาคารother_bank_flag | รหัสธนาคารของ Service[cf_lookup_catalog](/display/RDSCPENH/cf_lookup_catalog).config | tx_payment_detail.id | รหัสธนาคารtx_payment_detail.bank_abbr_name | ค่าธรรมเนียม |
|---|---|---|---|---|---|
| BBL_MCL | True | BBL | 1 | BBL | [cf_service_fee](/display/RDSCPENH/cf_service_fee).fee |
|   |   |   | 2 | SCB | [cf_service_fee](/display/RDSCPENH/cf_service_fee).other_bank_fee |
| KB_Payroll | False | KBANK | 3 | KBANK | [cf_service_fee](/display/RDSCPENH/cf_service_fee).fee |
|   |   |   | 4 | SCB | [cf_service_fee](/display/RDSCPENH/cf_service_fee).fee |

3. บันทึกค่าธรรมเนียมที่ตาราง [tx_payment_detail](/display/RDSCPENH/tx_payment_detail).id

| field | description | mapping data |
|---|---|---|
| fee_amount | ค่าธรรมเนียมธนาคาร | ตรวจสอบ [tx_payment_detail](/display/RDSCPENH/tx_payment_detail).flag_splitกรณี flag_split = Nบันทึก เงื่อนไขตามข้อ 2กรณี flag_split =Yบันทึกจำนวนรายการรวมที่ถูก Split Sum([tx_payment_detail_split](/display/RDSCPENH/tx_payment_detail_split)) x จำนวนค่าธรรรมเนียมเงื่อนไขตามข้อ 2updated by patcha.vo 21/07/69 |
| edw_fee_flag | ตั้งบัญชี real time | ตรวจสอบ [cf_service_fee](/display/RDSCPENH/cf_service_fee).real_time_edwกรณ๊ true บันทึก Yกรณี false บันทึก N |
| updated_date | วันและเวลาที่แก้ไข | บันทึกวันและเวลาปัจจุบัน |
| updated_by | ผู้แก้ไข | บันทึก username ที่ทำรายการ |
