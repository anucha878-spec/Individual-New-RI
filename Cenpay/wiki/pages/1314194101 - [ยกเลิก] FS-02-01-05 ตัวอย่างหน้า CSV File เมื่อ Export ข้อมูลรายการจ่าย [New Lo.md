# Screen Overview

### วัตถุประสงค์ (Objective)

- ใช้สำหรับออกเป็น Report CSV ในการติดตามข้อมูลรายการจ่ายที่ต้องการ

### ผู้ใช้งาน (Target Users)

- ฝ่ายปฎิบัติการ (Maker)
- ฝ่ายปฎิบัติการ (Checker)
- ฝ่ายปฎิบัติการ (Approver)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เข้าสู่หน้าจอ [PC-001-FC-001 หน้าจอรวมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252010) และเลือกกดปุ่ม Export CSV

### การกระทำกับหน้าจอ (Actions)

- ดูข้อมูลรายการจ่ายตามเงื่อนไขที่ระบุไว้ ในไฟล์ CSV

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้รับเอกสาร CSV เพื่อติดตามรายการจ่าย ตามเงื่อนไชที่ระบุไว้ในหน้าจอก่อนออกรายงาน CSV

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีที่ระบุเงื่อนไขในการออก CSV ไม่ถูกต้องตามรูปแบบที่กำหนด ระบบจะมีการแจ้งเตือนให้ทราบหลังจากการกดปุ่มค้นหา โดยเงื่อนไขการค้นหาที่จะมีการระบุรูปแบบไว้มีดังนี้
    - เลขที่กรมธรรม์ ต้องระบุตามรูปแบบของเลขที่กรมธรรม์ที่กำหนดไว้
    - ชื่อ ผู้เอาประกันภัย ต้องระบุอย่างน้อย 2 ตัวอักษร
    - นามสกุล ผู้เอาประกันภัย ต้องระบุอย่างน้อย 2 ตัวอักษร
  - กรณีค้นหาข้อมูลตามช่วงวันที่ ระบบจะมีการแจ้งเตือนพื้นฐานในการระบุช่วงวันที่ในการค้นหาให้ถูดต้อง โดยจะแสดงการแจ้งเตือนให้ทราบหลังจากการกดปุ่ม Export CSV ซึ่งจะมีเงื่อนไขพื้นฐานต่อไปนี้
    - ระบุวันที่ตั้งแต่ จะต้องระบุวันที่ถึงด้วย หรือ ระบุวันที่ถึง ต้องระบุวันที่ตั้งแต่ด้วย
    - การระบุวันวันที่ตั้งแต่ ห้ามเป็นวันที่หลังจากวันที่ที่ระบุในวันที่ถึง
  - กรณีค้นหาข้อมูลถ้าไม่ได้ระบุข้อมูลเลขที่กรมธรรม์ หรือ ชื่อ ผู้เอาประกันภัย หรือ นามสกุล ผู้เอาประกันภัย ระบบจะบังคับให้ระบุข้อมูล วันที่ครบกำหนดชำระเงินตั้งแต่ - ชำระถึง หรือ วันที่จ่ายเงินตั้งแต่ - ถึงวันที่
