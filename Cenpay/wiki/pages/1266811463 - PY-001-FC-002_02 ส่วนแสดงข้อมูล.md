| **ส่วนแสดงปุ่ม** |
| No | Component Type | Component Name | Action / Data Value | Example | Remark |
| 1 | Button | ยกเลิก | Enable : เสมอกรณีมีการเลือกข้อมูล ประเภทการจ่าย หรือ Service (Format ธนาคาร) หรือ Bank Account หรือ Request Payment Date ให้แสดงแจ้งเตือน "ยกเลิกการสร้าง Batch"เมื่อกดยกเลิกให้แสดงหน้าจอเดิมเมื่อกดตกลงให้กลับสู่หน้าจอ [PY-001-FC-001 หน้าจอค้นหาข้อมูลและรวมแบทช์การเงิน](/pages/viewpage.action?pageId=1266811400) โดยค้างรายการ Checkbox ที่เลือกไว้ และค้างเงื่อนไขค้นหาข้อมูลที่เลือกไว้ |   |   |
| 2 | Button | บันทึก | Enable : เสมอกรณีระบุ Required Field ไม่ครบทุกรายการให้แสดงแจ้งเตือน "กรุณาระบุข้อมูลให้ครบถ้วน"เมื่อกดตกลงให้แสดงหน้าจอเดิมกรณีระบุ Required Field ครบทุกรายการให้แสดงแจ้งเตือน "ยืนยันการสร้าง Batch"เมื่อกดยกเลิกให้แสดงหน้าจอเดิมเมื่อกดตกลงให้สร้างรายการ Batch การเงิน และ Reference Number ฝ่ายการเงิน ปรับสถานะดำเนินการเป็น กำลังดำเนินการกรณีประเภทการจ่ายเป็น Batch Payment จะส่งข้อมูลไปยังหน้าจอ [PY-002-FC-001 หน้าจอค้นหา Generate Batch Payment](/pages/viewpage.action?pageId=1267859518)กรณีประเภทการจ่ายเป็น Paper Base Payment จะส่งข้อมูลไปยังหน้าจอ [PY-003-FC-001 หน้าจอค้นหา Paper Base Payment - Maker](/pages/viewpage.action?pageId=1269858862)กรณีประเภทการจ่ายเป็น API Payment จะส่งข้อมูลไปยังหน้าจอ [PY-010-FC-001 หน้าจอค้นหา API Payment](/pages/viewpage.action?pageId=1279460015) (รอพัฒนาใน Ph2)ส่งอัปเดตสถานะรายการที่ระบบ Cenpay หน้าจอ [PC-001-FC-001 หน้าจอรวมจ่าย](/pages/viewpage.action?pageId=1270252010) และ [หน้าจอตรวจสอบรายการเตรียมจ่าย](/pages/viewpage.action?pageId=1270252003) ทุกรายการธุรกรรมย่อยภายใต้ Batch การเงินเป็น รอตรวจสอบ (ฝ่ายการเงิน)และกลับสู่หน้าจอ [PY-001-FC-001 หน้าจอค้นหาข้อมูลและรวมแบทช์การเงิน](/pages/viewpage.action?pageId=1266811400) โดยล้างรายการ Checkbox ที่เลือกไว้ และค้างเงื่อนไขค้นหาข้อมูลที่เลือกไว้ |   |   |
