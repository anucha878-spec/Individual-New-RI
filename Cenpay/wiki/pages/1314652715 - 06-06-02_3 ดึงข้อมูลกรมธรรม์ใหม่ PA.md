<![CDATA[/* เคสใหม่ จะดึงตาม ช่วงเวลาที่กำหนด Parameter 1. :policyNo = Input policyNo 2. :targetStartDate = Input targetStartDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25680705 3. :targetEndDate = Input targetEndDate แปลงเป็น number และใช้ format YYYYMMDD โดย YYYY คือปี พ.ศ. เช่น 25690101 4. :idCard = Input idCard ความหมายข้อมูลที่ดึง POLICY_NO = เลขที่กรมธรรม์ */ -- อุบัติเหตุ SELECT &#39;P&#39; AS POLICY_TYPE, A.POLNO AS POLICY_NO FROM PPALIB.TBPOLICY A INNER JOIN PPALIB.TBCUSTOM B ON A.POLCID = B.CUSID INNER JOIN PPALIB.TBRECEIP C ON A.POLNO = C.RECPOL WHERE 1 = 1 AND A.POLNO &lt;&gt; :policyNo AND (A.POLCDT BETWEEN :targetStartDate AND :targetEndDate) AND B.CUSCID = :idCard ]]>
