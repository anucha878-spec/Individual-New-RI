| **ส่วนการแสดงข้อมูล** |
|---|
| No | Component Name | **Type** | **Event** | Action / Data Value | **Data Source** |
| 1 | ข้อความแจ้งเตือน | Label | On Initial | Default Value : "กรุณายืนยันการส่งจดหมายติดตาม" |   |
| 2 | จำนวนรายการทั้งหมด | Label | On Initial | แสดงข้อมูลตาม Input ที่ส่งมาจากหน้าจอ [FS-06-02-03 หน้าจอค้นหารายงานทะเบียนคงเหลือเงินผลประโยชน์ค้างรับ](/pages/viewpage.action?pageId=1325859072) | จำนวนรายการ Check Box ที่เลือกจากหน้าจอ |
| 3 | เลือกวิธีการส่งจดหมาย | Dropdown List | On Initial | Default Value : ค่าว่าง | ดึงข้อมูลจาก [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value)โดยเงื่อนไข group = 'LETTER_DELIVERY_METHOD' และ active_flag = 'A'ให้ sort ข้อมูลตาม seqข้อมูลที่แสดงใช้ nameข้อมูลที่นำมาใช้ ใช้ valueเงื่อนไขเพิ่มเติมให้ตรวจสอบจำนวนรายการทั้งหมด และ Limit Print (ดึงข้อมูลจาก [cf_list_of_value](http://wiki.thaisamut.co.th/display/RDSCP/cf_list_of_value).valueโดยเงื่อนไข group = 'LETTER_FORM' และ name = 'Limit' และ active_flag = 'A')]กรณี ตรวจสอบจำนวนรายการทั้งหมด > Limit Print .**ไม่ต้องแสดงข้อมูล** ส่งด้วยตนเอง กรณี ตรวจสอบจำนวนรายการทั้งหมด <= Limit Print**แสดงข้อมูล**ส่งด้วยตนเอง |
