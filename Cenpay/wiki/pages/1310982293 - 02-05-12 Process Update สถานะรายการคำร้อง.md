## Input

| Name | Type | Description | Example | Mandatory (Y/N) | Validation |
|---|---|---|---|---|---|
| requestNo | varchar(20) | เลขที่รับเรื่อง | F2568-02/1500/000001 | Y | ต้องมี request_no ที่ตาราง [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request) |
| statusCode | varchar(10) | สถานะรายการ | PMS | Y | ต้องมี Config บนตาราง [cf_list_of_value](/display/RDSCP/cf_list_of_value) where group = 'REQUEST_STATUS' |
| remark | varchar(255) | หมายเหตุกำกับรายการ | Format ไม่ถูกต้อง | N | ต้องมีขนาดตัวอักษรไม่เกิน 255 ตัวอักษร |
| createdBy | varchar(50) | ผู้สร้างข้อมูล (เก็บ User ที่ใช้ Login เข้าระบบ เช่น Ocean.co) | Ocean.co | Y | ต้องมีขนาดตัวอักษรไม่เกิน 50 ตัวอักษร |
| createdByFullname | varchar(150) | ผู้สร้างข้อมูล (เก็บ fullname ที่ใช้ Login เข้าระบบ เช่น สมชาย ใจดี) | สมชาย ใจดี | Y | ต้องมีขนาดตัวอักษรไม่เกิน 150 ตัวอักษร |
| createdDate | timestamp | วันที่และเวลาสร้างข้อมูล | 2026-03-21 09:32:06.512 +0700 | Y |   |

## Process

1. Update สถานะรายการคำร้องที่ตาราง [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request) ที่ DB: [benefitregister](http://wiki.thaisamut.co.th/display/RDSCPENH/03.+DB+%3A+benefitregister) ดังนี้**Update** <![CDATA[update tx_request set status_code = :statusCode , updated_by = :createdBy , updated_by_fullname = :createdByFullname , updated_date = :createdDate where request_no = :requestNo;]]>
2. Insert Log Process ข้อมูลคำร้องที่ตาราง [lg_request_process](http://wiki.thaisamut.co.th/display/RDSCPENH/03_08+lg_request_process) ที่ DB: [benefitregister](http://wiki.thaisamut.co.th/display/RDSCPENH/03.+DB+%3A+benefitregister) ดังนี้Field NameBusiness RuleidAuto Running จากระบบtx_request_idค้นหาข้อมูลที่ตาราง [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).request_no = Input Entity Name : *requestNo* แล้วนำค่า [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).id มาจัดเก็บstatus_codeInput Entity Name*: statusCode*remarkInput Entity Name*: remark*created_byInput Entity Name*: createdBy*created_by_fullnameInput Entity Name*: createdByFullname*created_dateInput Entity Name*: createdDate*
3. ส่งข้อมูลเข้าระบบ AS400 ตามเงื่อนไขดังนี้
  1. ตรวจสอบ [Input.statusCode](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1347388024#id-02-05-19ProcessUpdate%E0%B8%AA%E0%B8%96%E0%B8%B2%E0%B8%99%E0%B8%B0%E0%B8%A3%E0%B8%B2%E0%B8%A2%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%84%E0%B8%B3%E0%B8%A3%E0%B9%89%E0%B8%AD%E0%B8%87%E0%B9%81%E0%B8%A5%E0%B8%B0%E0%B8%AA%E0%B9%88%E0%B8%87%E0%B8%82%E0%B9%89%E0%B8%AD%E0%B8%A1%E0%B8%B9%E0%B8%A5%E0%B9%80%E0%B8%82%E0%B9%89%E0%B8%B2%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9ACaseManagement%E0%B8%AA%E0%B8%B3%E0%B8%AB%E0%B8%A3%E0%B8%B1%E0%B8%9A%E0%B8%81%E0%B8%A3%E0%B8%A1%E0%B8%98%E0%B8%A3%E0%B8%A3%E0%B8%A1%E0%B9%8C%E0%B8%AA%E0%B8%B2%E0%B8%A1%E0%B8%B1%E0%B8%8D,%E0%B8%AD%E0%B8%B8%E0%B8%95%E0%B8%AA%E0%B8%B2%E0%B8%AB%E0%B8%81%E0%B8%A3%E0%B8%A3%E0%B8%A1%E0%B8%9B%E0%B8%8A,%E0%B8%AD%E0%B8%B8%E0%B8%95%E0%B8%AA%E0%B8%B2%E0%B8%AB%E0%B8%81%E0%B8%A3%E0%B8%A3%E0%B8%A1%E0%B8%82%E0%B8%9E,%E0%B9%81%E0%B8%A5%E0%B8%B0%E0%B8%AD%E0%B8%B8%E0%B8%9A%E0%B8%B1%E0%B8%95%E0%B8%B4%E0%B9%80%E0%B8%AB%E0%B8%95%E0%B8%B8-statusCode) กรณีที่เป็น **SPP : ยกเลิกรายการจ่าย** และ ตรวจสอบประเภทคำร้องต้องเป็น **คำร้องเวนคืนกรมบังคับคดี** ([tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).request_code = 'L' Where request_no = Input.requestNo)
    1. ให้ดำเนินการเรียกใช้ [FS-05-01-06_02_01-3 ยกเลิกคำร้องระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1318125633) หมายเหตุ การหาข้อมูล tx_request.id สามารถค้นหาด้วยเงื่อนไข [tx_request](http://wiki.thaisamut.co.th/display/RDSCPENH/03_01+tx_request).requestNo = Input.requestNo
