### วัตถุประสงค์ (Objective)

- เพื่อแสดงข้อมูลรายการผลการจ่ายตามช่องทางต่างๆ
- เพื่อให้ผู้ใช้งานสามารถค้นหาและดูข้อมูลการบันทึกผลการจ่ายได้ตามเงื่อนไขที่กำหนด

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่การเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ระบบจะต้องสามารถเชื่อมต่อกับฐานข้อมูลเพื่อดึงข้อมูลรายการ Voucher ที่ถูกอนุมัติจ่ายมาจากหน้าจอ [PY-005-FC-001 หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1271234731)

### การกระทำกับหน้าจอ (Actions)

- กดปุ่ม "ล้างเงื่อนไข" เพื่อล้างเงื่อนไขการค้นหา
- กดปุ่ม "ค้นหา" เพื่อค้นหาข้อมูลตามเงื่อนไข
- กดปุ่ม "บันทึกผลจ่ายเช็ค" เพื่อบันทึกผลการจ่ายเช็ค
- กดปุ่ม "อัปโหลดผลการจ่าย" เพื่ออัปโหลดไฟล์ผลการจ่ายเงินจากธนาคาร
- กดปุ่ม "บันทึก Manual" เพื่อบันทึกผลการจ่ายรายรายการแบบ Manual
- กด Icon ![img](http://wiki.thaisamut.co.th/download/attachments/1271234731/2025-08-04_101001.png?version=1&modificationDate=1754277018380&api=v2) "รายละเอียด" เพื่อแสดงรายละเอียด Support Booking
- กด Icon ![img](http://wiki.thaisamut.co.th/download/thumbnails/1271234731/2022-10-12_132317.png?version=1&modificationDate=1754276911478&api=v2) "เอกสารแนบ" เพื่อแสดงรายการเอกสารของ Batch Number ฝ่ายการเงิน

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - เมื่อผู้ใช้งานกดปุ่ม ค้นหา หน้าจอจะแสดงรายการระดับ Batch การเงินที่ตรงตามเงื่อนไขการค้นหา และจัดเรียงตาม Batch Number ฝ่ายการเงิน, ช่องทางการจ่ายเงิน, Request Payment Date
  - เมื่อผู้ใช้งานกดปุ่ม ล้างเงื่อนไข เงื่อนไขการค้นหาทั้งหมดจะถูก Reset เป็นค่าเริ่มต้น
  - เมื่อผู้ใช้งานกดปุ่ม อัปโหลดผลการจ่าย ระบบจะแสดงหน้าจอ Pop-up ให้อัปโหลดไฟล์ผลการจ่ายเงินจากธนาคาร เพื่อบันทึกผลการจ่ายเงิน โดยระบบจะทำการ Match สถานะการจ่ายจากรายการในไฟล์ให้อัตโนมัติ
  - เมื่อผู้ใช้งานกดปุ่ม บันทึก Manual ระบบจะแสดงหน้าจอ Popup บันทึกผลโอนเงิน Manual เพื่อให้บันทึกผลการจ่ายเงินเป็นรายรายการแบบ Manual
  - เมื่อผู้ใช้งานกดปุ่ม บันทึกผลจ่ายเช็ค ระบบจะแสดงหน้าจอบันทึกผลจ่ายเช็ค Manual เพื่อให้บันทึกผลการจ่ายเช็ค

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานไม่ระบุเงื่อนไขการค้นหาอย่างน้อยหนึ่งอย่าง เมื่อกดปุ่มค้นหาระบบจะแสดง Popup ข้อความแจ้งเตือน "กรุณาระบุเงื่อนไขการค้นหาข้อมูล" – Added By Patcha.vo 22/04/69
  - กรณีผู้ใช้งานไม่ระบุเงื่อนไขการค้นหา สถานะดำเนินการ เมื่อกดปุ่มค้นหาระบบจะแสดงข้อความแจ้งเตือนสีแดงใต้ Dropdown สถานะดำเนินการ "กรุณาระบุ"
  - กรณีระบุวันที่ในเงื่อนไขการค้นหาไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือน "ระบุช่วงวันที่ได้ไม่เกิน 120 วัน" ใต้ Text Box
  - กรณีไม่มีข้อมูลตามเงื่อนไขการค้นหา ระบบจะแสดงตารางผลลัพธ์ว่างเปล่า และแสดงข้อความที่ตาราง "ไม่พบข้อมูล"
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการที่ถูกเปลี่ยนแปลงสถานะดำเนินการ ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการเปลี่ยนแปลงข้อมูล" และ Refresh หน้าจอและดึงข้อมูลมาแสดงผลใหม่อีกครั้ง
  - กรณีผู้ใช้งานกดปุ่ม อัปโหลดผลการจ่าย ที่สถานะดำเนินการไม่ใช่ อนุมัติจ่ายเงิน หรือ บันทึกร่าง ระบบจะแสดงแจ้งเตือน "เนื่องจากสถานะดำเนินการเปลี่ยนเป็น จ่ายสำเร็จ หรือ จ่ายสำเร็จบางส่วน กรุณาตรวจสอบข้อมูลใหม่อีกครั้ง"
  - กรณีเกิดปัญหาในการเชื่อมต่อกับฐานข้อมูลเมื่อผู้ใช้งานกดปุ่มค้นหา ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถเชื่อมต่อฐานข้อมูลได้ กรุณาลองใหม่อีกครั้ง"
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
