## Overview

Select ข้อมูลอ้างอิงรายการจ่ายจากระบบ AS400

## Protocol

Icon
<SOAP,HESSIAN,REST>

## Operation

refer : [ESB WebService Design Pattern](/display/IEA/ESB+WebService+Design+Pattern)
Icon
TYPE : <inquiry>

## Input

|   | Name | Type | Description | Example | Validation | Null (Y/N) |
|---|---|---|---|---|---|---|
| List<Array> ไม่เกิน 50 Transactions |
|   | paymentType | Enum | ประเภทการจ่าย | NLN**ตัวอย่าง**APU("เงินจ่ายคืนทันที APL/APU"),RPU("เงินจ่ายคืนทันที RPU"),PSP("เวนคืนกรมธรรม์"),FLP("Freelook"),PPY("เงินบำนาญ"),SBP("เงินทรงชีพ"),FRP("เงินสมนาคุณ"),MAP("ครบกำหนดสัญญา"),UWC("บอกล้าง Underwrite"),LEP("เวนคืนกรมบังคับคดี"),TFP("โอนเงินเข้ากองทุน (10 ปี)"),RBP("เงินผลประโยชน์จากทะเบียนรอจ่ายใหม่"),NLN("กู้ใหม่"),NLO("กู้เพิ่ม"); | Required | N |
|   | policyNo | String | เลขกรมธรรม์ |   | Required | N |
|   | targetDate | Date | วันที่มีผลหรอวันที่คำร้อง |   | Required | N |

## Process

**DB: AS400**
1. ตรวจสอบ**Validation Input**
  1. กรณี Validation Input**ไม่ผ่าน** ให้ดำเนินการดังนี้
    1. [Output](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1321599472#id-07WS%E0%B8%AA%E0%B9%88%E0%B8%87%E0%B8%82%E0%B9%89%E0%B8%AD%E0%B8%A1%E0%B8%B9%E0%B8%A5%E0%B8%84%E0%B8%B3%E0%B8%A3%E0%B9%89%E0%B8%AD%E0%B8%87%E0%B9%80%E0%B8%82%E0%B9%89%E0%B8%B2Temporarytable%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9AAS400-A_Output).status = **FALSE**
    2. [Output](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1321599472#id-07WS%E0%B8%AA%E0%B9%88%E0%B8%87%E0%B8%82%E0%B9%89%E0%B8%AD%E0%B8%A1%E0%B8%B9%E0%B8%A5%E0%B8%84%E0%B8%B3%E0%B8%A3%E0%B9%89%E0%B8%AD%E0%B8%87%E0%B9%80%E0%B8%82%E0%B9%89%E0%B8%B2Temporarytable%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9AAS400-A_Output).remark = "ข้อมูลสำหรับการค้นหาไม่ถูกต้อง"
    3. กรณี Validation Input**ผ่าน** ให้ดำเนินการข้อถัดไป
2. วน Query ข้อมูลตาม List Array โดยแปลง targetDate ให้เป็น String รูปแบบ YYYYMMDD เมื่อ YYYY คือปีพศ. ดังนี้ <![CDATA[SELECT OLTGID as tagID, OLREFN as refNo, OLENNO as enNo, OLEVTY as paymentType, OLPOLC as policyNo, OLDUDT as dueDate FROM OASYS.OAPLINKY WHERE OLEVTY = :paymentType AND TRIM(OLPOLC) = :policyNo AND OLDUDT = :targetDate;]]> กรณีที่ดึงข้อมูลไม่สำเร็จ ให้ Return Output ดังนี้กรณีที่ดึงข้อมูลสำเร็จ ให้เก็บข้อมูลที่ได้ ตาม Output **Result (List <Array>)**
  1. [Output](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1321599472#id-07WS%E0%B8%AA%E0%B9%88%E0%B8%87%E0%B8%82%E0%B9%89%E0%B8%AD%E0%B8%A1%E0%B8%B9%E0%B8%A5%E0%B8%84%E0%B8%B3%E0%B8%A3%E0%B9%89%E0%B8%AD%E0%B8%87%E0%B9%80%E0%B8%82%E0%B9%89%E0%B8%B2Temporarytable%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9AAS400-A_Output).status = **FALSE**
  2. [Output](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1321599472#id-07WS%E0%B8%AA%E0%B9%88%E0%B8%87%E0%B8%82%E0%B9%89%E0%B8%AD%E0%B8%A1%E0%B8%B9%E0%B8%A5%E0%B8%84%E0%B8%B3%E0%B8%A3%E0%B9%89%E0%B8%AD%E0%B8%87%E0%B9%80%E0%B8%82%E0%B9%89%E0%B8%B2Temporarytable%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9AAS400-A_Output).remark = ข้อความตาม Alert Code****[err_com_009](http://wiki.thaisamut.co.th/display/RDSCPENH/01.+Error+Message) (ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ)
3. เมื่อทำข้อ 2 สำเร็จ ให้ Return Output ดังนี้
  1. [Output](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1321599472#id-07WS%E0%B8%AA%E0%B9%88%E0%B8%87%E0%B8%82%E0%B9%89%E0%B8%AD%E0%B8%A1%E0%B8%B9%E0%B8%A5%E0%B8%84%E0%B8%B3%E0%B8%A3%E0%B9%89%E0%B8%AD%E0%B8%87%E0%B9%80%E0%B8%82%E0%B9%89%E0%B8%B2Temporarytable%E0%B8%A3%E0%B8%B0%E0%B8%9A%E0%B8%9AAS400-A_Output).status = **TRUE**
  2. Return ข้อมูลที่ได้กลับไป

## Output

<แสดงข้อมูลที่จะได้รับจาก service นี้>

| **Name** | **Type** | **Description** | **Example** |
|---|---|---|---|
| status | Boolean | สถานะการทำรายการหากบันทึกสำเร็จ = **TRUE**หากบันทึกไม่สำเร็จ = **FALSE** | TRUE |
| remark | String | หมายเหตุ หรือ Error Message กรณีทำรายการไม่สำเร็จ | บันทึกข้อมูลสำเร็จ |

| **Result (List <Array>) ไม่เกิน 50 Transactions** |
|---|
| **Name** | **Type** | **Description** | **Example** |
| tagID | String | ข้อมูล TagID (Unique Key ของรายการจ่ายที่ทาง AS400 ใช้อ้างอิงในการ Update ข้อมูล) |   |
| refNo | String | ข้อมูลเลข Reference No อ้างอิงรายการจ่ายระบบ AS400 |   |
| enNo | String | ข้อมูล Endorse No อ้างอิงรายการจ่ายของระบบ AS400 |   |
| paymentType | enum | ประเภทรายการจ่าย | NLN, NLO |
| policyNo | String | เลขที่กรมธรรม์ |   |
| dueDate | Date | วันที่มีผลหรอวันที่คำร้อง |   |
