# Screen Overview

### วัตถุประสงค์ (Objective)

- เพื่อให้ผู้ใช้งานสามารถระบุผู้รับเงินที่ไม่ผ่านการตรวจสอบที่ได้จากธนาคาร กรณีไม่มีไฟล์ผลการตรวจสอบ

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ฝ่ายการเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ผู้ใช้งานจะต้องกดปุ่ม ระบุผู้รับเงิน ที่หน้าจอ Popup บันทึกรายการไม่ผ่านตรวจสอบ
- การกำหนดค่าเริ่มต้นเมื่อเปิดหน้าจอ
  - ระบบจะตั้งค่าข้อมูลผู้รับเงินทั้งหมดภายใต้ Batch การเงินที่เลือกที่ Auto Complete ชื่อ-สกุลผู้รับเงินและเลขที่บัญชี

### การกระทำกับหน้าจอ (Actions)

- อัปโหลดไฟล์เอกสารแนบจากธนาคาร
- เพิ่มผู้รับเงินที่ไม่ผ่านการตรวจสอบ
- ยกเลิกระบุผู้รับเงินที่ไม่ผ่านการตรวจสอบ
- ยืนยันระบุผู้รับเงินที่ไม่ผ่านการตรวจสอบ
- ลบข้อมูลผู้รับเงินที่ไม่ผ่านการตรวจสอบ

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - กรณีเพิ่มข้อมูล ระบบจะแสดงข้อมูลผู้รับเงินที่ไม่ผ่านตรวจสอบที่ตารางการแสดงผลข้อมูล
  - กรณีลบข้อมูล ระบบจะล้างข้อมูลผู้รับเงินที่ไม่ผ่านตรวจสอบที่ตารางการแสดงผลข้อมูล
  - กรณียกเลิก ระบบจะล้างข้อมูลที่กรอกในหน้าจอนี้ทั้งหมด และกลับไปยังหน้าจอ Popup บันทึกรายการไม่ผ่านตรวจสอบ
  - กรณียืนยัน ระบบจะนำข้อมูลผู้รับเงินที่ระบุไปแสดงที่หน้าจอ Popup บันทึกรายการไม่ผ่านตรวจสอบ

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการที่ถูกเปลี่ยนแปลงสถานะดำเนินการ ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการเปลี่ยนแปลงข้อมูล" และกลับสู่หน้าจอหลัก
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
