| 1 |   | การเรียงลำดับข้อมูล | หลังจากกดปุ่มค้นหา ให้ระบบจัดเรียงข้อมูลตามเงื่อนไขต่อไปนี้ตามลำดับเรียงจากข้อมูล ประเภทกรมธรรม์ จากน้อยไปมากเรียงจากข้อมูล ประเภทการจ่าย จากน้อยไปมากเรียงจากข้อมูล เลขที่กรมธรรม์ จากน้อยไปมากเรียงจากข้อมูล วันที่ครบกำหนดรับเงิน จากวันที่เก่าสุดไปใหม่สุดเรียงจากข้อมูล สถานะรายการ (รอดำเนินการ, รอยืนยัน, ยืนยัน, จ่ายสำเร็จ ตามลำดับ) |   |   |
| 2 |   | Sort Column | ระบบอนุญาตให้กด Sorting ที่ Column ดังต่อไปนี้ประเภทกรมธรรม์ประเภทการจ่ายเลขที่รับเรื่องสาขารับเรื่องเลขที่ธุรกรรมอ้างอิงสถานะรายการเลขที่กรมธรรม์วันที่ครบกำหนดรับเงินจำนวนเงินสุทธิช่องทางการจ่ายวันที่จ่ายเงิน |   |   |
| 3 |   | เงื่อนไขการค้นหาข้อมูล | เงื่อนไขการค้นหาข้อมูลตามวันที่ตั้งทะเบียนเช็คคืน มีดังนี้กรณีเลือกเป็น กำหนดช่วงวันที่ : ค้นหารายการที่วันที่ตั้งทะเบียนเช็คคืนอยู่ระหว่างช่วงวันที่ที่ระบุกรณีเลือกเป็น ทั้งหมด ณ วันที่ : ค้นหารายการที่วันที่ตั้งทะเบียนเช็คคืนน้อยกว่าเท่ากับวันที่ที่ระบุกรณีเลือกเป็น คงเหลือ ณ วันที่ : ค้นหารายการที่วันที่ตั้งทะเบียนเช็คคืนน้อยกว่าเท่ากับวันที่ที่ระบุ และสถานะรายการเป็น "รอดำเนินการ" |   |   |
| 4 |   | เงื่อนไขการแสดงข้อมูล | วันที่ แสดงรูปแบบ Format : DD/MM/YYYY (ปีพศ.)จำนวนเงิน ทศนิยม 2 ตำแหน่ง มีการคั่นด้วย "," กรณีมากกว่า 1,000.00กรณีไม่พบข้อมูล ระบุ "-" |   |   |
