### วัตถุประสงค์ (Objective)

- เพื่อใช้ในการตั้งรายการจ่ายใหม่ สำหรับรายการที่มีสถานะรายการเป็น ส่งกลับแก้ไข (Oper), ตรวจจ่ายไม่ผ่าน และทำจ่ายไม่สำเร็จ

### ผู้ใช้งาน (Target Users)

- ฝ่ายปฎิบัติการ (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เลือกรายการที่ต้องการตั้งรายการจ่ายใหม่ ที่หน้าจอ [PC-002-FC-001 หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) บนรายการที่มีสถานะรายการเป็น ส่งกลับแก้ไข (Oper), ตรวจจ่ายไม่ผ่าน เท่านั้น จากนั้นกดปุ่ม ตั้งรายการจ่ายใหม่

### การกระทำกับหน้าจอ (Actions)

- กดปุ่มปิด เพื่อปิดหน้าจอยืนยันการตั้งรายการจ่ายใหม่
- กดปุ่มยืนยัน เพื่อยืนยันข้อมูลรายการที่ต้องการตั้งรายการจ่ายใหม่

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้ยืนยันรายการตั้งจ่ายใหม่ ตามรายการที่ต้องการได้

### การจัดการข้อผิดพลาด (Exceptional Handling)

- ไม่มี เป็นเพียงหน้าจอที่ใช้แสดงรายการข้อมูลเพื่อยืนยันการบันทึกตั้งรายการจ่ายใหม่เท่านั้น

### รายละเอียดส่วนการแสดงผลข้อมูล

| ส่วนแสดงข้อมูลผลการค้นหา |
|---|
| 1 |   | การเรียงลำดับข้อมูล | จะเรียงลำดับข้อมูลจาก เลขธุรกรรม น้อย ไป มาก |   |   |
| 2 | Label | ทั้งหมด | แสดงจำนวนรายการจ่ายที่เลือกทั้งหมด สำหรับยืนยันการตั้งจ่ายใหม่ |   | หน่วยเป็น รายการ |
| **ส่วนการแสดงข้อมูล (Table Display)** |
| No | Component Type | Component Name | Action / Data Value | Example | Remark |
| 1 | Label | เลขธุรกรรม | แสดงเลขธุรกรรมของรายการจ่าย |   |   |
| 2 | Label | เลขที่กรมธรรม์ | แสดงเลขที่กรมธรรม์ของรายการจ่าย |   |   |
| 3 | Label | ประเภทกรมธรรม์ | แสดงประเภทกรมธรรม์ของรายการจ่าย |   |   |

### รายละเอียดเงื่อนไขปุ่ม

| No | Component Type | Component Name | Default Value | Validation Rules/Action | Example | Remark |
|---|---|---|---|---|---|---|
| 1 | Button | ปิด | Enable | เมื่อกดปุ่มปิด ระบบจะทำการปิดหน้าจอ Popup ดังกล่าวทิ้ง โดยจะกลับไปแสดงที่หน้าจอหลักเดิมก่อนหน้า และไม่ทำอะไรกับข้อมูลใดๆทั้งสิ้น |   |   |
| 2 | Button | ยืนยัน | Enable | เมื่อกดปุ่มยืนยัน ระบบจะทำการยกเลิกรายการธุรกรรมเดิม โดยการลงสถานะรายการเป็น แก้ไขเรียบร้อย จากนั้นจะทำการเรียกตั้งรายการธรุกรรมที่เลือกทั้งหมดอีกครั้ง เป็นรอบถัดไปตามเงื่อนไขต่อไปนี้สถานะรายการ "ส่งกลับแก้ไข (ฝ่ายปฎิบัติการ)" จะทำการตั้งรายการจ่ายใหม่ โดยนับ เตรียมจ่ายครั้งที่ + 1สถานะรายการ "ตรวจจ่ายไม่ผ่าน (ฝ่ายบัญชี)" จะทำการตั้งรายการจ่ายใหม่ โดยนับ ตรวจจ่ายครั้งที่ + 1โดยมีข้อมูลรายการจ่าย Update ตามข้อมูลล่าสุด และมีสถานะรายการเป็น "รอเตรียมจ่าย" |   |   |
