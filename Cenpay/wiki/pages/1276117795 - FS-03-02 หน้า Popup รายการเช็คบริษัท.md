# Screen Overview

### วัตถุประสงค์ (Objective)

- เพื่อแสดงข้อมูลรายการเช็คบริษัท
- เพื่อให้ผู้ใช้งานสามารถแก้ไขข้อมูลเช็ค และระบุเหตุผลการแก้ไข
- เพื่อให้ผู้ใช้งานสามารถสั่งพิมพ์เช็ค
- เพื่อให้ผู้ใช้งานสามารถยกเลิกเช็ค และระบุเหตุผลการยกเลิก
- เพื่อให้ผู้ใช้งานสามารถดูประวัติสถานะเช็ค

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ฝ่ายการเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ผู้ใช้งานจะต้องกดปุ่ม แก้ไข ที่หน้าจอหลัก
  - รายการ Batch ที่เลือกจะต้องมีช่องทางการจ่ายเป็น เช็คบริษัท และสถานะดำเนินการเป็น กำลังดำเนินการ หรือ รอดำเนินการใหม่
  - รายการเช็คธนาคารจะมีสถานะเป็น รอพิมพ์เช็ค

### การกระทำกับหน้าจอ (Actions)

- แก้ไขข้อมูลเช็ค
- พิมพ์เช็ค
- ยกเลิกเช็ค
- ดูประวัติสถานะ
- ปิดหน้าจอรายการเช็ค

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ระบบสามารถแสดงข้อมูลรายการเช็คบริษัท ภายใต้ Batch การเงินได้อย่างถูกต้อง
  - เมื่อกดปุ่มแก้ไข
    - กรณีสถานะเป็นรอพิมพ์เช็ค ระบบจะเปิดหน้าจอระบุเลขที่เช็ค
    - กรณีสถานะเป็นรอการแก้ไข ระบบจะเปิดหน้าจอแก้ไขข้อมูลเช็ค
  - เมื่อกดปุ่มพิมพ์ ระบบจะสั่งพิมพ์ข้อมูลเช็ค ตามตำแหน่งที่ระบุเป็นค่าเริ่มต้น และเพิ่มจำนวนครั้งที่พิมพ์ และปรับสถานะเป็นพิมพ์สำเร็จ
  - เมื่อกดปุ่มยกเลิก ระบบจะเปิดหน้าจอยกเลิกเช็ค เพื่อให้ระบุสาเหตุการยกเลิกเช็ค
  - เมื่อกดปุ่มประวัติสถานะ ระบบจะเปิดหน้าจอประวัติสถานะที่มีการเปลี่ยนแปลง
  - หลังจากระบุเลขที่เช็คและสั่งพิมพ์เช็คครบถ้วนทุกรายการ ระบบจะปรับสถานะดำเนินการเป็นบันทึกสำเร็จ และส่งข้อมูลไปยังหน้าจอ [PY-004-FC-001 หน้าจอค้นหา Paper Base Payment - Checker](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1269858922)

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการที่ถูกเปลี่ยนแปลงสถานะดำเนินการ หรือสถานะเช็ค ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการเปลี่ยนแปลงข้อมูล" และกลับสู่หน้าจอหลัก
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
