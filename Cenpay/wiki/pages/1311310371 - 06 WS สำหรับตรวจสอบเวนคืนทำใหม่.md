## Overview

API นี้จัดทำขึ้นเพื่อตรวจจับกรณี **การเวนคืนกรมธรรม์เดิมเพื่อทำประกันใหม่** (Suspicious Replacement Cases) ซึ่งเป็นกรณีที่อาจส่งผลต่อการปรับการจ่ายค่าบำเหน็จของกรมธรรม์ใหม่
การพิจารณาจะอ้างอิงจากเกณฑ์หลัก ได้แก่
1. **หลักเกณฑ์ด้านระยะเวลา** กำหนดให้มีการเวนคืนกรมธรรม์ภายหลังจากวันที่เริ่มมีผลบังคับของกรมธรรม์ใหม่ ภายในระยะเวลาไม่เกิน 180 วัน
2. **ประเภทของกรมธรรม์ที่อยู่ในขอบเขตการพิจารณา** ครอบคลุมกรมธรรม์ประเภทสามัญ กรมธรรม์อุตสาหกรรม กรมธรรม์ ปช. และกรมธรรม์ประกันอุบัติเหตุส่วนบุคคล (PA)
3. **ข้อจำกัดเกี่ยวกับผู้เอาประกันภัย** ผู้เอาประกันภัยของกรมธรรม์ใหม่ (New Policies) ต้องเป็นบุคคลเดียวกันกับผู้เอาประกันภัยของกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืนเท่านั้น
****
**ผลกระทบด้านค่าบำเหน็จ (Commission Adjustment Rules)**
หากกรมธรรม์ใหม่ที่ขายถูกจัดอยู่ในเงื่อนไข **การเวนคืนทำใหม่** ตามที่กำหนดไว้ จะมีผลต่อการจ่ายค่าบำเหน็จดังนี้
- **ปีแรก** จ่ายค่าบำเหน็จเพียง **50% ของอัตราปกติ** และนำเฉพาะค่าบำเหน็จในส่วน 50% นี้ไปใช้ในการคำนวณผลงานและรายได้
- **ปีที่ 2 เป็นต้นไป** การจ่ายค่าบำเหน็จจะเป็นไปตามระเบียบและหลักเกณฑ์ของบริษัทที่กำหนดไว้

## Process

ดึงข้อมูลต่างๆ จากระบบ AS400 เพื่อใช้สำหรับตรวจสอบการเวนคืนทำใหม่ดังนี้
**1. ข้อมูลกรมธรรม์ใหม่ (New Policies)**

**เงื่อนไขการตรวจสอบ**
**เงื่อนไขการตรวจจับเคสเวนคืนเพื่อทำประกันใหม่ (Suspicious Replacement Cases)**
1. **หลักเกณฑ์ด้านระยะเวลา** กำหนดให้มีการเวนคืนกรมธรรม์ภายหลังจากวันที่เริ่มมีผลบังคับของกรมธรรม์ใหม่ ภายในระยะเวลาที่กำหนด (ไม่เกิน 180 วัน)
2. **ประเภทของกรมธรรม์ที่อยู่ในขอบเขตการพิจารณา** ครอบคลุมกรมธรรม์ประเภทสามัญ กรมธรรม์อุตสาหกรรม กรมธรรม์ ปช. และกรมธรรม์ประกันอุบัติเหตุส่วนบุคคล (PA)
3. **ข้อจำกัดเกี่ยวกับผู้เอาประกันภัย** ผู้เอาประกันภัยของกรมธรรม์ใหม่ (New Policies) ต้องเป็นบุคคลเดียวกันกับผู้เอาประกันภัยของกรมธรรม์ที่อยู่ระหว่างดำเนินการเวนคืนเท่านั้น
**เงื่อนไขการ Return Output**
- กรณีผลการค้นหาข้อมูลจาก ขั้นตอน ดึงข้อมูลกรมธรรม์ใหม่ (New Policies) **ตรงตามเงื่อนไขข้อ 1–3** → ถือว่าเข้าข่ายการเวนคืนทำใหม่
  1. ให้ Set Output.isSwitchPolicy = **true**
  2. ให้ Set Output.listOfNewPolicies ดังนี้
    1. **newPolicies**.policyType = policy_type จากขั้นตอน [ดึงข้อมูลกรมธรรม์ใหม่ (New Policies) จากระบบ AS400](#id-06WSสำหรับตรวจสอบเวนคืนทำใหม่-A_NewPolicies)
    2. **newPolicies**.policyType = policy_no จากขั้นตอน [ดึงข้อมูลกรมธรรม์ใหม่ (New Policies) จากระบบ AS400](#id-06WSสำหรับตรวจสอบเวนคืนทำใหม่-A_NewPolicies)
- กรณีผลการค้นหาข้อมูลจาก ขั้นตอน ดึงข้อมูลกรมธรรม์ใหม่ (New Policies) **ไม่****ตรงตามเงื่อนไขข้อ 1–3**→ ถือว่าไม่เข้าข่ายการเวนคืนทำใหม่
  1. ให้ Set Output.isSwitchPolicy = **false**
  2. ให้ Set Output.**listOfNewPolicies = null******
