"อนุมัติบันทึกบัญชี" จากสถานะ รออนุมัติ (Pending Approval) เปลี่ยนเป็น อนุมัติ (Approved)ปรับสถานะดำเนินการระดับ Transaction ดังนี้กรณีเงินโอน จากสถานะ รออนุมัติ (Pending Approval) เปลี่ยนเป็น (Approved)ดำเนินการอัปเดตข้อมูลกลับที่ระบบ Cenpay ดังนี้อัปเดตสถานะรายการธุรกรรมย่อยระดับ Transaction ที่ Module เตรียมจ่าย ปฏิบัติการ : [PC-001-FC-001 กรณีวิธีการจ่ายเป็น Batch Payment อัปเดตสถานะเป็น รอบันทึกผลการจ่าย (ฝ่ายการเงิน) หากรายการผ่านการตรวจสอบ Format พร้อมทั้งระบุ วันที่จ่ายเงิน (วันที่ลูกค้าได้รับเงิน) จริงกลับไปให้ อัปเดตสถานะเป็น Format ไม่ผ่าน หากรายการไม่ผ่านการตรวจสอบ Format หรือถูกยกเลิกรายการจากกระบวนการตรวจสอบ Format พร้อมทั้งสร้างรายการที่หน้าจอ [หน้าจอยืนยันการโอนเงิน](/pages/viewpage.action?pageId=1278017914) โดยระบุสถานะเป็นFormat ไม่ผ่าน หากรายการทำจ่ายไม่สำเร็จ จากการไม่ผ่านการตรวจสอบ Formatโอนเงินไม่สำเร็จ หากรายการทำจ่ายไม่สำเร็จ จากการโอนเงินไม่สำเร็จกรณีช่องทางการจ่ายเป็นเช็คธนาคาร ให้อัปเดต เลขที่เช็ค กลับไปให้เพิ่มเติมด้วย (หากมี) กรณีวิธีการจ่ายเป็น Paper-based Payment อัปเดตสถานะเป็น จ่ายสำเร็จ หากรายการผ่านการตรวจสอบจาก Checker พร้อมทั้งระบุ เลขที่เช็ค, สถานะเช็ค (เป็น เช็ครอขึ้นเงิน) และวันที่จ่ายเงิน (วันที่ลูกค้าได้รับเงิน) จริง กลับไปให้อัปเดตสถานะเป็น ระงับการจ่าย หากรายการถูกยกเลิกจาก [Pหน้า Popup รายการเช็คบริษัท](/pages/viewpage.action?pageId=1269858870) พร้อมทั้งระบุสถานะเช็ค เป็น เช็คยกเลิก หากมีอัปเดตสถานะรายการธุรกรรมย่อยระดับ Transaction ที่ Module ตรวจจ่าย บัญชี : [หน้าจอรายละเอียด Support Booking](/pages/viewpage.action?pageId=1272906268) กรณีวิธีการจ่ายเป็น Paper-based Paymentอัปเดตสถานะเป็น จ่ายเงินสำเร็จ หากรายการผ่านการตรวจสอบจาก Checkerอัปเดตสถานะเป็น ระงับการจ่าย หากรายการถูกยกเลิก
