| transactionType | String | รายการธุรกรรม | เงินจ่ายคืนทันที | Y |   |

| requestPaymentDate | Date | วันที่ Request จ่ายเงิน | 20250801 | Y |   |

## Process

**เงื่อนไข**
1. บันทึกข้อมูลตาราง [tx_payment_report](/display/RDSCPENH/tx_payment_report)
- ตรวจสอบ [tx_payment_report](/display/RDSCPENH/tx_payment_report).oper_ref_no = input.operRefNoยังไม่มีข้อมูล
- Insert ข้อมูลจาก Input ที่ตาราง [tx_payment_report](/display/RDSCPENH/tx_payment_report)
