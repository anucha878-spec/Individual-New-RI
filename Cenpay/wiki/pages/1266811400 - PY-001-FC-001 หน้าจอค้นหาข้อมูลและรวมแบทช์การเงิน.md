### วัตถุประสงค์ (Objective)

- เพื่อจัดการรายการธุรกรรมการจ่ายที่ผ่านการตรวจจ่ายจากหน้าจอตรวจจ่าย บัญชี ที่ Module ตรวจจ่ายบัญชี ระบบ Cenpay และเลือกวิธีจ่าย, Service ธนาคารเพื่อทำจ่าย
- เพื่อแสดงข้อมูลการจ่ายทุกธุรกรรมและทุกช่องทาง
- เพื่อให้ผู้ใช้งานสามารถรวมธุรกรรมจากข้อมูลต้นทางตามช่องทางการจ่ายและวันที่ Request Payment Date และยืนยันรายการรวม Batch การเงิน
- เพื่อให้ผู้ใช้งานสามารถค้นหาและดูข้อมูลการจ่ายได้ตามเงื่อนไขที่กำหนด
- เพื่อให้ผู้ใช้งาน Split Batch ปฎิบัติการตามธนาคารปลายทางที่ต้องการ

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่ฝ่ายการเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ระบบจะต้องสามารถเชื่อมต่อกับฐานข้อมูลเพื่อดึงข้อมูลรายการธุรกรรมการจ่ายที่เข้าระบบ Payment Management
  - ระบบรับรายการที่ผ่านการยืนยันตรวจจ่ายจาก Module ตรวจจ่ายบัญชี ระบบ Cenpay เป็นราย Batch ปฏิบัติการ
  - ตรวจสอบ Transaction ภายใต้ Batch ปฎิบัติการ หากมี Transaction เกิน 2 ล้านให้ Split แยกเป็นอีก 1 Batch ปฎิบัติการ

### การกระทำกับหน้าจอ (Actions)

- ล้างเงื่อนไขการค้นหาข้อมูล
- ค้นหาข้อมูล Batch ปฎิบัติการ
- ดูรายละเอียด Support Booking
- Split Batch ปฎิบัติการ
- Check Box รายการเพื่อรวม Batch ปฎิบัติการ
- ยืนยันสร้าง Batch การเงิน

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - เมื่อผู้ใช้งานกดปุ่ม ค้นหา หน้าจอจะแสดงรายการธุรกรรมการจ่ายจากข้อมูลต้นทาง ตามเงื่อนไขการค้นหา และจัดเรียงตามกลุ่มธุรกรรม รายการธุรกรรม ช่องทางการจ่ายเงิน และ Request Payment Date
  - เมื่อผู้ใช้งานกดปุ่ม ล้างเงื่อนไข เงื่อนไขการค้นหาทั้งหมดจะถูก Reset เป็นค่าเริ่มต้น
  - เมื่อผู้ใช้งานกดปุ่ม รายละเอียด, Split Batch, ยืนยันสร้าง Batch ระบบจะนำผู้ใช้งานไปยังหน้าจอที่เกี่ยวข้องได้อย่างถูกต้อง

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานไม่ระบุเงื่อนไขการค้นหาอย่างน้อยหนึ่งอย่าง เมื่อกดปุ่มค้นหาระบบจะแสดง Popup ข้อความแจ้งเตือน "กรุณาระบุเงื่อนไขการค้นหาข้อมูล"
  - กรณีระบุวันที่ในเงื่อนไขการค้นหาไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือน "ระบุช่วงวันที่ได้ไม่เกิน 120 วัน" ใต้ Text Box
  - กรณีไม่มีข้อมูลตามเงื่อนไขการค้นหา ระบบจะแสดงตารางผลลัพธ์ว่างเปล่า และแสดงข้อความที่ตาราง "ไม่พบข้อมูล"
  - กรณีผู้ใช้งานเลือกรายการธุรกรรม ที่ไม่ใช่ ช่องทางการจ่าย และ Request Payment Date เดียวกัน ระบบจะแสดง Popup ข้อความแจ้งเตือน "กรุณาเลือกรายการที่ ช่องทางการจ่าย และ Request Payment Date ให้ตรงกัน"
  - กรณีผู้ใช้งานเลือกรายการธุกรรม ที่เป็น Batch Split จาก Batch เดิม เพื่อรวม Batch ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถรวม Batch ที่เคย Split ได้"
  - กรณีเกิดปัญหาในการเชื่อมต่อกับฐานข้อมูลเมื่อผู้ใช้งานกดปุ่มค้นหา ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถเชื่อมต่อฐานข้อมูลได้ กรุณาลองใหม่อีกครั้ง"
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
