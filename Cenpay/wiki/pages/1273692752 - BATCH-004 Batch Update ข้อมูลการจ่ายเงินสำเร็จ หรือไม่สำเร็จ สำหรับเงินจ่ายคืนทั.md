#### Description

| **No.** | **Topic** | **Description** |
|---|---|---|
| 1 | ชื่อและวัตถุประสงค์(Name and Objective) | Batch Update ข้อมูลการจ่ายเงินสำเร็จ หรือไม่สำเร็จ สำหรับเงินจ่ายคืนทันที APU ไปยังระบบ AS400 |
| 2 | สัมพันธ์กับกระบวนการ(Link to process) | กรณีที่สถานะรายการเป็น ส่งกลับยืนยัน (ฝ่ายการเงิน) หรือ จ่ายเงินไม่สำเร็จ ใช้เพื่อ Update ข้อมูลที่ฐานข้อมูลระบบ AS400 เพื่อให้จัดการในการส่ง Email แจ้งกรณีจ่ายไม่สำเร็จ และเพื่อใช้เป็นข้อมูลสำหรับจัดการตั้งรายการจ่ายใหม่ บนหน้าจอ [PC-002-FC-001 หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058)กรณีที่สถานะรายการเป็น จ่ายเงินสำเร็จ ใช้เพื่อ Update ข้อมูลที่ฐานข้อมูลระบบ AS400 เพื่อให้จัดการในการส่ง Email แจ้งกรณีจ่ายเงินสำเร็จ และออกจดหมายแจ้งให้กับลูกค้ารับเรื่องรายการเงินจ่ายคืนทันที APU บนระบบ AS400 |
| 3 | เวลาประมวลผลโดยประมาณ (Time) | ทุกๆ X นาที หรือ ตามรอบเวลาที่กำหนด |
| 4 | ข้อมูลตั้งต้น(Input) | ข้อมูลรายการจ่ายเงินคืนทันที APU ที่มีการ Update สถานะการจ่ายเงินเป็น จ่ายเงินสำเร็จ หรือ จ่ายเงินไม่สำเร็จเรียบร้อยแล้ว |
| 5 | ข้อมูลที่ได้จากระบบ(Output) | ข้อมูลรายการจ่ายเงินคืนทันที APU ที่มีการ Update สถานะการจ่ายเงินเป็น จ่ายเงินสำเร็จ และจ่ายเงินไม่สำเร็จ ที่ถูก Update ข้อมูลที่ระบบ AS400 แล้วแจ้งเตือนการจ่ายเงินสำเร็จของเงินจ่ายคืนทันที APU ให้ลูกค้ารับทราบผ่านทางจดหมายEmail แจ้งเตือนกรณีการจ่ายเงินไม่สำเร็จหรือจ่ายเงินสำเร็จ กรณีจ่ายเงินคืนทันที APU ให้กับทางสาขาต้นสังกัดและสาขาสำนักงานใหญ่รับทราบแจ้งเตือนการจ่ายเงินไม่สำเร็จของเงินจ่ายคืนทันที่ APU ให้ลูกค้ารับทราบผ่าน SMS หรือ Line Noti |
| 6 | อธิบายรายละเอียด(Description) | **Pre-condition (เงื่อนไขก่อนการทำงาน)**ระบบการเงินจะทำการ Update ข้อมูลรายการจ่ายเงินคืนทันที APU ตามสถานะการจ่ายที่ได้จากการจ่ายเงินเป็น จ่ายเงินสำเร็จ หรือ จ่ายเงินไม่สำเร็จ**Process Description (กระบวนการ)**ระบบจะทำการ Update สถานะการจ่ายเงิน ไปยังฐานข้อมูล AS400 อ้างอิงตามกระบวนการเดิมที่ระบบ AS400สถานะรายการเป็น จ่ายเงินสำเร็จ อ้างอิง [03-01-04 Pop Up หน้าจอบันทึกผลการจ่ายสำเร็จ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1149600125)สถานะรายการเป็น Format ไม่ผ่าน หรือ โอนเงินไม่สำเร็จ อ้างอิง [03-01-05 หน้าจอบันทึกผลการจ่ายไม่สำเร็จ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1149600131)ตามกระบวนการ [03-01-04 Pop Up หน้าจอบันทึกผลการจ่ายสำเร็จ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1149600125) ระบบจะมีการสร้างจดหมายการนำส่งลูกค้ากรณีจ่ายเงินสำเร็จตามกระบวนการเดิมของระบบ AS400 [P-15-Batch Process ส่ง Email แจ้งผลการโอนเงินจ่ายคืนทันที เนื่องจากกรมธรรม์ปิดบัญชีอัตโนมัติ ( Auto Paid Up ) ทั้งกรณีโอนเงินผ่าน และโอนเงินไม่ผ่าน](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1213202713) ทำการส่ง Email แจ้งสาขาต้นสังกัดและสาขาปฎิบัติการ (สำนักงานใหญ่) รับทราบกรณีโอนเงินสำเร็จหรือไม่สำเร็จ ในทุกๆเช้า เวลา 08:00 น.กรณีที่จ่ายเงินไม่สำเร็จ ระบบจะมีการแจ้งเตือนให้ลูกค้าได้รับทราบในตอนเช้า เวลา 08:00 น. ผ่านช่องทาง SMS หรือ Line Noti อ้างอิงตามSMS : [BATCH-001_SMS_001 Template แจ้งให้ลูกค้าทราบเรื่องการจ่ายเงินคืนทันที APU จ่ายเงินไม่สำเร็จ ผ่าน SMS](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1276117957)Line Noti : [BATCH-001_LIN_001 Template แจ้งให้ลูกค้าทราบเรื่องการจ่ายเงินคืนทันที APU จ่ายเงินไม่สำเร็จ ผ่าน Line Noti](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1276117962)**Post-condition (เงื่อนไขหลังการทำงาน)**ข้อมูลรายการจ่ายที่ทำจ่ายไม่สำเร็จ พร้อมให้ตั้งรายการจ่ายใหม่อีกครั้ง |
