# Screen Overview

### วัตถุประสงค์ (Objective)

- เพื่อแสดงข้อมูลรายการจ่ายเช็คและบันทึกผลการจ่ายเช็คระดับรายการธุรกรรม

### ผู้ใช้งาน (Target Users)

- เจ้าหน้าที่การเงิน (Maker)

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เงื่อนไขที่ต้องเป็นจริงก่อนที่ผู้ใช้งานจะสามารถเข้าถึงและใช้งานหน้าจอ
  - ผู้ใช้งานจะต้องเข้าสู่ระบบ (Login) ด้วยบัญชีที่มีสิทธิ์เป็นเจ้าหน้าที่ฝ่ายการเงิน (Maker)
  - ระบบจะต้องสามารถเชื่อมต่อกับฐานข้อมูลเพื่อดึงข้อมูลรายการธุรกรรมที่ช่องทางการจ่ายเป็น เช็ค ที่ถูกอนุมัติจ่ายมาจากหน้าจอ [PY-005-FC-001 หน้าจออนุมัติจ่ายและบันทึกบัญชี](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1271234731)

### การกระทำกับหน้าจอ (Actions)

- กดปุ่ม "ล้างเงื่อนไข" เพื่อล้างเงื่อนไขการค้นหา
- กดปุ่ม "ค้นหา" เพื่อค้นหาข้อมูลตามเงื่อนไข
- กด Icon ![img](http://wiki.thaisamut.co.th/download/thumbnails/1271234731/2022-10-12_132317.png?version=1&modificationDate=1754276911478&api=v2) "เอกสารแนบ" เพื่อแสดงรายการเอกสารของ Transaction

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - เมื่อผู้ใช้งานกดปุ่ม ค้นหา หน้าจอจะแสดงข้อมูลรายการธุรกรรมที่ช่องทางการจ่ายเป็น เช็ค ที่ตรงตามเงื่อนไขการค้นหา และจัดเรียงตาม Batch Number ฝ่ายการเงิน, เลขที่เช็ค, วันและเวลาที่บันทึก
  - เมื่อผู้ใช้งานกดปุ่ม ล้างเงื่อนไข เงื่อนไขการค้นหาทั้งหมดจะถูก Reset เป็นค่าเริ่มต้น

### การจัดการข้อผิดพลาด (Exceptional Handling)

- สถานการณ์ที่ผิดปกติหรือข้อผิดพลาดที่อาจเกิดขึ้นและวิธีการที่ระบบควรจัดการกับสถานการณ์เหล่านั้น
  - กรณีผู้ใช้งานไม่ระบุเงื่อนไขการค้นหา Bank Account เมื่อกดปุ่มค้นหาระบบจะแสดงข้อความแจ้งเตือนสีแดงใต้ Dropdown Bank Account เป็น "กรุณาระบุ"
  - กรณีระบุวันที่ในเงื่อนไขการค้นหาไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือน "ระบุช่วงวันที่ได้ไม่เกิน 200 วัน" ใต้ Text Box
  - กรณีไม่มีข้อมูลตามเงื่อนไขการค้นหา ระบบจะแสดงตารางผลลัพธ์ว่างเปล่า และแสดงข้อความที่ตาราง "ไม่พบข้อมูล"
  - กรณีผู้ใช้งานเข้าทำงานพร้อมกัน และมีรายการที่ถูกเปลี่ยนแปลงสถานะดำเนินการ ระบบจะแสดงแจ้งเตือน "ไม่สามารถทำรายการได้ เนื่องจากมีการเปลี่ยนแปลงข้อมูล" และ Refresh หน้าจอและดึงข้อมูลมาแสดงผลใหม่อีกครั้ง
  - กรณีผู้ใช้งานกดปุ่ม ยกเลิกเช็ค ที่สถานะดำเนินการไม่ใช่ เช็ครอขึ้นเงิน ระบบจะแสดงแจ้งเตือน "เนื่องจากสถานะบางรายการเปลี่ยนเป็น เช็คขึ้นเงินแล้ว หรือ ยกเลิกเช็ค เรียบร้อยแล้ว กรุณาตรวจสอบข้อมูลและทำรายการใหม่อีกครั้ง"
  - กรณีผู้ใช้งานกดปุ่ม เช็คขึ้นเงินแล้ว ที่สถานะดำเนินการไม่ใช่ เช็ครอขึ้นเงิน ระบบจะแสดงแจ้งเตือน "เนื่องจากสถานะบางรายการเปลี่ยนเป็น เช็คขึ้นเงินแล้ว หรือ ยกเลิกเช็ค เรียบร้อยแล้ว กรุณาตรวจสอบข้อมูลและทำรายการใหม่อีกครั้ง"
  - กรณีเกิดปัญหาในการเชื่อมต่อกับฐานข้อมูลเมื่อผู้ใช้งานกดปุ่มค้นหา ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถเชื่อมต่อฐานข้อมูลได้ กรุณาลองใหม่อีกครั้ง"
  - กรณีเกิดปัญหาทางเทคนิคอื่นๆ ระบบจะแสดง Popup ข้อความแจ้งเตือน "ไม่สามารถทำรายการได้ กรุณาติดต่อผู้ดูแลระบบ"
