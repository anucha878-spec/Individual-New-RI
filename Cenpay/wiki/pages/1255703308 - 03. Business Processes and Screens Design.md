## Module List

| Module ID | Module Name | Module Description |
|---|---|---|
| PR | Payment Request | กระบวนการบันทึกคำร้อง |
| PC | Pre-Payment Control | กระบวนการเตรียมจ่าย โดยฝ่ายปฏิบัติการ |
| AC | Accounting Control | กระบวนการตรวจจ่าย โดยฝ่ายบัญชี |
