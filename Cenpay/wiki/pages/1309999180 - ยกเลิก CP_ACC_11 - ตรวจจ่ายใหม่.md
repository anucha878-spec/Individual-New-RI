1. บันทึกข้อมูล Transaction เข้าผังบัญชี โดยส่งข้อมูลจากระบบ Cenpay Mapping เข้าผังบัญชี ไปลงที่ระบบ EDW
  1. อ้างอิงการทำงานจาก [LANDING : Mapping Table Landing from ระบบ CENPAY](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=882606277)ข้อ 2.8 Event: CP_ACC_11 ตรวจจ่ายใหม่ ในส่วนของ Mapping Field ตาม Model
    1. ข้อมูลต้นทางจากระบบ Cenpay ดูที่ Column Cenpay System
    2. ข้อมูลปลายทางที่มาลง Table Landing ดูที่ Column Cenpay Landing
2. ข้อมูลรายละเอียดในบันทึก Process log การนำเข้าข้อมูลไปยัง EDW
  1. อ้างอิงตาม [LANDING : Mapping Table Landing from ระบบ CENPAY](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=882606277) ข้อ 3 event code : CP_ACC_11 ตรวจจ่ายใหม่ข้อมูลที่บันทึก tx_adwpc_process_logรายละเอียดaccounting_dateinput.accountingDatebranch_noFix : 0001event_codeFix : CP_ACC_11 (ตรวจจ่ายใหม่)event_typeFix : PAYMENTmapping_begin_date[tx_payment_approve.](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_approve)approve_dateoperation_approved_date[tx_payment_approve.](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_approve)approve_dateoperation_approved_fullname[tx_payment_approve](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_approve).approve_nameoperation_approved_username[tx_payment_approve](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_approve).approve_bysystemFix : CENPAY
