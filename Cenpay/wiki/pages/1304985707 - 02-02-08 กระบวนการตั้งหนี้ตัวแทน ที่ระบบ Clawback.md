# Input

| Field | Description |
|---|---|
| policyClawbacks []สูงสุด 20 รายการ |
| paymentID | เลข ID อ้างอิงรายการจ่าย |
| policyNo | เลขที่กรมธรรม์ |
| policyType | ประเภทกรมธรรม์ |
| branchCode | สาขาของกรมธรรม์(4 หลัก) |
| clawbackType | ประเภทของข้อมูล |
| docNo | เลขที่หนังสือ (ถ้ามี) |
| systemSource | ชื่อระบบต้นทาง |
| systemKey | รหัสอ้างอิงระบบต้นทาง |
| transactionDate | วันที่ทำรายการ |

# กระบวนการ

1.ส่งข้อมูลไปตั้งหนี้ตัวแทนที่ระบบ Clawback เรียก Process [WS อัพโหลดข้อมูลกรมธรรม์ตามธุรกรรมที่ต้องการเรียกคืนรายได้](/pages/viewpage.action?pageId=1303740716) โดยใช้ข้อมูลตาม Input ที่ระบุ
2. กรณี success บันทึก output ที่ตาราง [tx_payment](/display/RDSCPENH/tx_payment) โดยอ้างอิงจาก [tx_payment](/display/RDSCPENH/tx_payment).id = paymentID

| field | mapping output |
|---|---|
| clawback_id | tx_debt_landing_id |
