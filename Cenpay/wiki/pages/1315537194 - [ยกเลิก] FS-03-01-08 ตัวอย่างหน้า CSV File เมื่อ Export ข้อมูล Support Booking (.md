# Screen Overview

### วัตถุประสงค์ (Objective)

- ใช้สำหรับออกเป็น Report CSV ของรายละเอียด Support Booking ของรายการจ่ายทั้งหมดภายใต้ Batch ปฎิบัติการที่เลือก

### ผู้ใช้งาน (Target Users)

- ฝ่ายบัญชี

### เงื่อนไขก่อนการทำงาน (Pre-Condition)

- เข้าสู่หน้าจอ [FS-03-01-07 หน้าจอรายละเอียด Support Booking (New Loan)](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1315537190) และเลือกกดปุ่ม Export CSV

### การกระทำกับหน้าจอ (Actions)

- ดูข้อมูลของรายละเอียด Support Booking ของ**รายการจ่ายที่เกี่ยวข้องกับการกู้ใหม่หรือกู้เพิ่ม**ภายใต้ Batch ปฎิบัติการ ในไฟล์ CSV

### เงื่อนไขหลังการทำงาน (Post-Condition)

- ผลลัพธ์ที่คาดหวังว่าจะเกิดขึ้นหลังจากผู้ใช้งานดำเนินการเสร็จสิ้นบนหน้าจอนี้
  - ผู้ใช้งานได้รับเอกสาร CSV เพื่อใช้ติดตามรายละเอียด Support Booking ของ**รายการจ่ายที่เกี่ยวข้องกับการกู้ใหม่หรือกู้เพิ่ม**ภายใต้ Batch ปฎิบัติการ

### การจัดการข้อผิดพลาด (Exceptional Handling)

- ไม่มี เป็นเพียงการกดปุ่มเพื่อออกรายงาน CSV ตามรูปแบบข้อมูลบนหน้าจอ
