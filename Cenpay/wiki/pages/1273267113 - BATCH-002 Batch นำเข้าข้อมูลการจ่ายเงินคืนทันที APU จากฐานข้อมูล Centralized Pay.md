# BATCH-002 Batch นำเข้าข้อมูลการจ่ายเงินคืนทันที APU จากฐานข้อมูล Centralized Payment เข้าสู่กระบวนการเตรียมจ่าย

#### Description

| **No.** | **Topic** | **Description** |
|---|---|---|
| 1 | ชื่อและวัตถุประสงค์(Name and Objective) | Batch นำเข้าข้อมูลการจ่ายเงินคืนทันที APU จากฐานข้อมูล Centralized Payment ในส่วนของข้อมูลส่วนกลาง เข้าสู่กระบวนการเตรียมจ่าย |
| 2 | สัมพันธ์กับกระบวนการ(Link to process) | เพื่อใช้เป็นข้อมูลสำหรับค้นหาและจัดการรายการเตรียมจ่าย บนหน้าจอ [PC-002-FC-001 หน้าจอตรวจสอบรายการเตรียมจ่าย](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1270252058) |
| 3 | เวลาประมวลผลโดยประมาณ (Time) | ทุกวันเวลา ช่วงเช้า (05.00 น.) |
| 4 | ข้อมูลตั้งต้น(Input) | ข้อมูลการจ่ายเงินคืนทันที APU จากฐานข้อมูล Centralized Payment ในส่วนของข้อมูลส่วนกลางข้อมูลตรวจสอบ AML/CFTข้อมูลการเปลี่ยนแปลงแก้ไขข้อมูลจากระบบ CIS |
| 5 | ข้อมูลที่ได้จากระบบ(Output) | ข้อมูลการจ่ายเงินคืนทันที APU สำหรับใช้ในกระบวนการเตรียมจ่าย โดยแยกเป็นกรณี Clean Case, AML/CFT และ CIS |
| 6 | อธิบายรายละเอียด(Description) | **Pre-condition (เงื่อนไขก่อนการทำงาน)**ระบบประมวลผล Batch : [BATCH-001 Batch นำเข้าข้อมูลการจ่ายเงินคืนทันที APU จากระบบ APL Improvement เข้าสู่ระบบ Centralized Payment](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1255703321) ก่อน**Process Description (กระบวนการ)**ระบบจะประมวลผลรายการ ข้อมูลการจ่ายเงินคืนทันที APU จากฐานข้อมูล Centralized Payment ในส่วนของข้อมูลส่วนกลาง มาตั้งเป็นรายการรอเตรียมจ่าย โดยการดูจากวันที่จ่าย (T-2) นับเฉพาะวันทำการตรวจสอบข้อมูล AML/CFT ของการจ่ายเงินคืนทันที APUกรณีที่ติด AML/CFT ไม่ว่าจะเป็นแบบ Freeze หรือ Non-Freeze ต้องมีการส่ง **[Email แจ้งรายการข้อมูลการจ่ายเงินคืนทันที่ APU ที่ติด AML/CFT ให้กับทางทีมสำนักกำกับ, สำนักกฎหมาย และฝ่ายปฎิบัติการให้ทราบ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1275823275)**ตรวจสอบข้อมูลการจ่ายเงินคืนทันที่ APU ที่ไม่ได้ติด Freeze กับระบบ CIS เพื่อคัดกรองกรณีที่ข้อมูลกรมธรรม์ที่ต้องจ่ายเงินคืนทันที APU ติดการเปลี่ยนแปลงข้อมูลที่มีผลต่อข้อมูลการจ่ายอยู่ในระบบ CIS (ข้อมูลส่วนตัว, ข้อมูลที่อยู่ หรือข้อมูลบัญชีธนาคารหรือบัญชีพร้อมเพย์) และส่ง **[Email แจ้งรายการขออนุมัติข้อมูลระบบ CIS ประจำวัน](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1277132843)**ระบบจะทำการ Update ข้อมูลกลับไปยังฐานข้อมูล AS400 ที่เกี่ยวกับข้อมูลการจ่ายเงินคืนทันที APU ให้เป็นสถานะ B (เตรียมจ่าย) เพือเป็นการบอกระบบ AS400 ว่ารายการดังกล่าวได้ถูกตั้งไว้รอทำการเตรียมจ่ายแล้ว**Post-condition (เงื่อนไขหลังการทำงาน)**ได้ข้อมูลการจ่ายเงินคืนทันที APU สำหรับใช้ในกระบวนการเตรียมจ่ายระบบมีการแจ้ง **Email แจ้งรายการข้อมูลการจ่ายเงินคืนทันที่ APU ที่ติด AML/CFT** ให้ทางทีมสำนักกำกับ, สำนักกฎหมาย และฝ่ายปฎิบัติการรับทราบระบบมีการแจ้ง **Email แจ้งรายการข้อมูลจ่ายเงินคืนทันที APU ที่ติด CIS** ให้ทางฝ่ายปฎิบัติการรับทราบ |
