**Step 1 :** เตรียมข้อมูลรายการเช็คหมดอายุ
- ค้นหาข้อมูลเช็คหมดอายุ ภายใต้ Voucher ด้วยเงื่อนไขดังนี้ [tx_payment_detail](/display/RDSCPENH/tx_payment_detail).fin_reference_no = '@ที่ทำรายการ'[tx_paperbase_status](/display/RDSCPENH/tx_paperbase_status).status = 'CEX'[tx_paperbase_status](/display/RDSCPENH/tx_paperbase_status).cheque_no = [tx_payment_detail](/display/RDSCPENH/tx_payment_detail).cheque_no[tx_payment_detail](/display/RDSCPENH/tx_payment_detail).Id = [tx_payment_detail_mapping_etl](/display/RDSCPENH/tx_payment_detail_mapping_etl).payment_detail_id *('CEX' = เช็คหมดอายุ || parent_id = '11000')*
- หรือ ค้นหาข้อมูลเช็คหมดอายุ ภายใต้ Batch ฝ่ายการเงิน ด้วยเงื่อนไขดังนี้ [tx_paperbase_status](/display/RDSCPENH/tx_paperbase_status).cheque_no = [tx_payment_detail](/display/RDSCPENH/tx_payment_detail).cheque_no where [tx_paperbase_status](/display/RDSCPENH/tx_paperbase_status).status = 'CEX' . *('CEX' = เช็คหมดอายุ || parent_id = '11000')*
สำหรับเช็คหมดอายุ ระบบจะส่งข้อมูลเข้า EDW
b.1.1 ตรวจสอบและจัดกลุ่มรายการตาม Event Code ภายใต้ Batch (อ้างอิง Event Code จาก [Initial Data page 2](/display/RDSADW/Initial+Data+page+2))

| event_code | เงื่อนไข |
|---|---|
| PM_FIN_06 | `รับคืนเช็คหมดอายุ` |

b.1.2 สร้าง System Key โดย Format ของ System_key คือ eventCode_{batch_payment_no}_{วันที่เวลาส่งข้อมูลyyyyMMddHHmmss}
ตัวอย่างเช่น PM_FIN_01_B25680901001_20250915140159
