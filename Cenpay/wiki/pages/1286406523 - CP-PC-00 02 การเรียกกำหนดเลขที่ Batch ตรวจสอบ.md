# CP-PC-00 02 การเรียกกำหนดเลขที่ Batch ตรวจสอบ

ดำเนินการ Generate ข้อมูลเลขที่ Batch ตรวจสอบ เงื่อนไขดังนี้

| ตำแหน่ง | ข้อมูล | เงื่อนไข | ตัวอย่าง |
|---|---|---|---|
| 1-3 | ชื่อระบบงาน | Fix "CP" ย่อมาจาก Centralized Payment ตามด้วย "-" | CP- |
| 4-6 | ช่องทางการจ่ายเงิน | ขึ้นตามช่องทางการจ่ายเงินTP : โอนเงิน - พร้อมเพย์TB : โอนเงิน - ปกติTE : โอนเงิน - ด่วนCB : เช็คธนาคารตามด้วย "-" | TB- |
| 7-10 | ประเภทรายการ | อ้างอิงจากประเภทรายการที่เลือกCLN : Clean CaseAML : AML/CFTCIS : CISตามด้วย "- | CLN- |
| 11-18 | วันที่ทำการสร้างข้อมูล | Format: YYYYMMDD เป็น ค.ศ. ตามด้วยเลขเดือน [01 - 12] ตามด้วยเลขวัน [01 - 31]ตามด้วย "- | 20250923- |
| 18-22 | Sequence number | ตรวจสอบเลข Running ล่าสุดจากตาราง [tx_paymet_running_no](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_running_no) ด้วย prefix_key = ข้อมูลในตำแหน่งที่ 1-18ถ้าพบข้อมูลให้ใช้ข้อมูล running_no ต่อจากข้อมูลที่พบถ้าไม่พบข้อมูลให้เริ่มต้นข้อมูลตั้งแต่ 1 | 00001 |

**ผลลัพธ์** CP-TB-CLN-20250923-00001
**หมายเหตุ** กรณีที่ใช้ เลขที่ Batch ตรวจสอบ แยกตามกรณี
- กรณีที่ใช้ข้อมูลจากตาราง [tx_paymet_running_no](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_running_no) ในการสร้างเลขที่ Batch ตรวจสอบ ให้ Update ข้อมูลที่ prefix_key = ข้อมูล prefix_key ที่หยิบไปใช้ โดย update ค่า running_no = เลขล่าสุดที่ใช้ในการ Generate ข้อมูลเลขที่ Batch ตรวจสอบ
- กรณีที่ไม่ใด้ใช้ข้อมูลจากตาราง [tx_paymet_running_no](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment_running_no) ในการสร้างเลขที่ Batch ตรวจสอบ ให้ Insert ข้อมูล prefix_key ที่ใช้ และ running_no ที่ใช้ล่าสุดในการ Generate เลขที่ Batch ตรวจสอบ ลงบนฐานข้อมูล
