## Process

1. ใช้ Process : [CP-PC-00 01 การเรียกกำหนดเลขธุรกรรม](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1282507844) โดยดูเงื่อนไขตาม paymentType ที่ได้จากข้อมูลที่รับเข้ามา ดังนี้
  1. paymentType = 'RBP' ใช้ Prefix : CPRBPYYMMDD เมื่อ YY คือปี คศ. 2 หลักสุดท้าย โดย YYMMDD อ้างอิงตามวันที่ปัจจุบัน เพื่อให้ได้ชุดของเลขธรุกรรมมาใช้ในการบันทึกข้อมูล
2. วนข้อมูลตาม List รายการที่รับเข้ามา ที่แยกตามประเภทการจ่ายแล้ว ทีละรายการ
  1. **กำหนดเลขธุรกรรมที่ได้จากข้อ 1** โดยจะทำการเพิ่ม Sequence ขึ้นที่ละ 1 ต่อจากข้อมูลก่อนหน้า
  2. **เรียกข้อมูลที่ต้องการใช้จากระบบ CIS** โดยใช้ [01 WS สำหรับดึงข้อมูลผู้เอาประกันภัย ข้อมูลบัญชีรับผลประโยชน์ ข้อมูลที่อยู่ติดต่อระดับกรมธรรม์ เบอร์ติดต่อ และข้อมูลผู้รับผลประโยชน์ ที่ระบบ CIS](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1282507270) (ข้อมูล CIS) และส่งค่า Input ดังนี้NameDescriptionValuepolicyNoเลขกรมธรรม์policyNo จากรายการนำเข้าtransactionTypeข้อมูลประเภทบัญชีFix "BNF"addressTypeข้อมูลประเภทที่อยู่Fix "CON"
  3. **เรียกตรวจสอบข้อมูล AML/CFT** จาก WS : [04. ตรวจสอบข้อมูล AMLO](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=552075538) (ข้อมูล AML/CFT) และส่งค่า Input ดังนี้ (โดยให้ทำทั้งกรณีของผู้เอาประกันภัย และผู้รับเงินผลประโยชน์ ในกรณีที่ ข้อมูล CIS accountRelationName <> 'ผู้เอาประกัน')NameDescriptionValuecardIdเลขบัตรประชาชน/เลขที่หนังสือเดินทางกรณีผู้เอาประกันภัยและผู้รับประโยชน์ ข้อมูล CIS cardNo (ที่ได้จาก b.)clientNameชื่อภาษาไทย/ชื่ออังกฤษ/ชื่อเดิมกรณีผู้เอาประกันภัย ข้อมูล CIS name กรณีผู้รับผลประโยชน์ ข้อมูล CIS payeeFirstName (ที่ได้จาก b.)clientSurnameนามสกุลภาษาไทย/นามสกุลอังกฤษ/นามสกุลเดิมกรณีผู้เอาประกันภัย ข้อมูล CIS surname กรณีผู้รับผลประโยชน์ ข้อมูล CIS payeeLastName (ที่ได้จาก b.)
  4. **เรียกตรวจสอบข้อมูลที่ยังรอการอนุมัติจากระบบ CIS** จาก WS : [02 WS สำหรับดึงประเภทข้อมูลบนระบบ CIS ที่อยู่ในระหว่างการแก้ไข ตามรหัสลูกค้าและกรมธรรม์ที่กำหนด](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1283391679) (ข้อมูล Update CIS) และส่งค่า Input ดังนี้ NameDescriptionValuedataGroupCodeชุดข้อมูลที่ต้องการตรวจสอบ**ตัวอย่าง**1800500 : (Customer)ข้อมูล Profile ลูกค้า 1800502 : (Customer)ข้อมูลติดต่อระดับลูกค้า 1800503 : (Customer)ที่อยู่ติดต่อระดับลูกค้า 1800505 : (Customer)สถานที่ทำงาน/สถานที่ศึกษาระดับลูกค้า 1800602 : (Policy)ข้อมูลติดต่อระดับกรมธรรม์ 1800603 : (Policy)ที่อยู่ติดต่อระดับกรมธรรม์ 1800606 : (Policy)ข้อมูลบัญชีธนาคาร/พร้อมเพย์ระดับกรมธรรม์ 1800609 : (Policy)สถานที่ทำงาน/สถานที่ศึกษาระดับกรมธรรม์Fix "(1800500,1800603,1800606)"customerIDรหัสลูกค้าบนระบบ CISข้อมูล CIS customerID (ที่ได้จาก b.)policyNoเลขที่กรมธรรม์policyNo จากรายการนำเข้า
