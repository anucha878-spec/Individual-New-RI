# รายละเอียดการทำงานของปุ่ม

| Component Name | Type | Event | Action/ Validation/ Default Value | Data Source | Remarks |
|---|---|---|---|---|---|
| บันทึกตรวจสอบ | Button | On Initial | แสดงปุ่ม บันทึกตรวจสอบ |   |   |
| On Click | เมื่อกดปุ่ม ระบบจะทำการ Validate ข้อมูลรายการที่เลือกจะต้องเป็นข้อมูลที่มีสถานะเป็น "รอเตรียมจ่าย" เหมือนกันทั้งหมดกรณีที่มีสถานะอื่นร่วมด้วย ให้ระบบแสดงข้อความ Popup แจ้งเตือนว่า "ไม่สามารถบันทึกตรวจสอบได้ เนื่องจากมีรายการที่มีสถานะรายการอื่นที่ไม่ใช่ รอเตรียมจ่าย ร่วมอยู่ด้วย" พร้อมด้วยปุ่มปิด (เพิ่มกดแล้วปิด Popup กลับสู่หน้าจอเดิม)***Ph1R2 + New Loan Ph1**ตรวจสอบรายการทั้งหมดว่า วันที่จ่ายเงิน ต้องมากกว่าหรือเท่ากับวันปัจจุบัน ทุกรายการกรณีที่มีรายการใดรายการหนึ่ง วันที่จ่ายเงิน น้อกว่าวันปัจจุบัน ห้ระบบแสดงข้อความ Popup แจ้งเตือนว่า "ไม่สามารถบันทึกตรวจสอบได้ เนื่องจากมีรายการที่วันที่จ่ายเงิน น้อยกว่าวันปัจจุบัน" พร้อมด้วยปุ่มปิด (เพิ่มกดแล้วปิด Popup กลับสู่หน้าจอเดิม)กรณีที่สามารถบันทึกตรวจสอบได้ระบบ จะนำเข้าสู่หน้าจอ [FS-02-02-02 หน้า Popup ยืนยันรายการบันทึกตรวจสอบ](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1282507694) เพื่อยืนยันรายการที่จะบันทึกตรวจสอบ |   |   |
| Visible | แสดงเฉพาะ Tab : Clean Case และ AML/CFT |   |   |
| Enable | ก็ต่อเมื่อมีรายการอย่างน้อย 1 รายการถูกเลือกบนหน้าจอ |   |   |
| Disable | ก็ต่อเมื่อไม่มีรายการที่ถูกเลือกบนหน้าจอ |   |   |
| ตั้งรายการจ่ายใหม่ | Button | On Initial | แสดงปุ่ม ตั้งรายการจ่ายใหม่ |   |   |
| On Click | เมื่อกดปุ่ม ระบบจะทำการ Validate ข้อมูลรายการที่เลือกจะต้องเป็นข้อมูลที่มีสถานะเป็น "ส่งกลับแก้ไข (ฝ่ายปฎิบัติการ)" และ "ตรวจจ่ายไม่ผ่าน (ฝ่ายบัญชี)" เท่านั้นกรณีที่มีสถานะอื่นร่วมด้วย ให้ระบบแสดงข้อความ Popup แจ้งเตือนว่า "ไม่สามารถบันทึกตรวจสอบได้ เนื่องจากมีรายการที่มีสถานะรายการอื่นที่ไม่ใช่ ส่งกลับแก้ไข (ฝ่ายปฎิบัติการ) หรือ ตรวจจ่ายไม่ผ่าน (ฝ่ายบัญชี) ร่วมอยู่ด้วย" พร้อมด้วยปุ่มปิด (เพิ่มกดแล้วปิด Popup กลับสู่หน้าจอเดิม)กรณีที่สามารถบันทึกตรวจสอบได้ระบบ จะนำเข้าสู่หน้าจอ [FS-02-02-06 หน้า Popup ยืนยันการตั้งรายการจ่ายใหม่](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1282507768) เพื่อยืนยันรายการที่จะตั้งรายการจ่ายใหม่อีกรอบ |   |   |
| Visible | แสดงเฉพาะ Tab : Clean Case และ AML/CFT |   |   |
| Enable | ก็ต่อเมื่อมีรายการอย่างน้อย 1 รายการถูกเลือกบนหน้าจอ |   |   |
| Disable | ก็ต่อเมื่อไม่มีรายการที่ถูกเลือกบนหน้าจอ |   |   |
