## Input

<แสดงข้อมูล Parameter ที่ต้องการ>

| Name | Type | Description | Example | Validation | Mandatory |
|---|---|---|---|---|---|
| dateFrom | Date | วันที่ Cut off ดึงข้อมูลเช็ค | 2026-07-17 | Required | N |
| dateTo | Date | วันที่ Cut off ดึงข้อมูลเช็ค | 2026-07-17 | Required | Y |

## Process

รอบการ Migrate ข้อมูล

| รอบที่ | dateFrom | dateTo | Run Date |
|---|---|---|---|
| 1 | - | 2026-07-20 | 2026-07-22 |
| 2 | 2024-01-21 | 2026-07-24 | 2026-07-24 |

1. Query ข้อมูลดังนี้
Step 1 ข้อมูลสินไหมที่มีการจ่ายด้วยเช็ค สถานะเป็นรอขึ้นเงิน ที่ DB : **claimtx**
**Query ดึงข้อมูลธนาคาร**
<![CDATA[SELECT e.cheques_no AS chequeNo, e.cheques_date AS chequeIssueDate, e.company_bank_account as bankAccountNo, e.paid_no as paidNo, e.amount_pay as amount, b.batch_no as batchNo, a.receipt_date as paid_date FROM tx_ncl_pay_pycust_tran a INNER JOIN tx_ncl_pay_batch b ON b.id = a.batch_id INNER JOIN tx_ncl_pay_pycust_tran_total_pay d ON d.id = a.total_paid_customer_id INNER JOIN tx_ncl_pay_cheques_headoffice e ON e.pycust_tran_total_id = d.id WHERE e.status_code = &#39;T14&#39; --AND e.cheques_date &lt;= :dateTo -- รอบ 1 รันวันที่ 22 --AND e.cheques_date BETWEEN :dateFrom AND :dateTo -- รอบ 2 รันวันที่ 24 (กรณีที่ไม่มี dateFrom)]]>
Step 2. ข้อมูล Voucher ที่ **DB : adwetl**
นำ edwPaidNo และ batchNo ไปค้นหารายการ edwProcessLog โดยกรุ๊ปข้อมูล batchNo, edwPaidNo ที่ได้จาก claimtx
**Query ดึงข้อมูลธนาคาร**
<![CDATA[select cs.tx_adwpc_process_log_id as edwProcessLogId, lo.system_key as edwSystemKey, lo.tx_adwpc_dashboard_manual_id, dm.reference_number as finReferenceNo, dm.requested_payment_date as requestPaymentDate, dm.payment_date as paymentDate, dm.posting_date as postingDate, dm.accounting_approved_date as approveDate, dm.accounting_approved_username as approveBy from tx_cms_transaction cs left join tx_adwpc_process_log lo on lo.id = cs.tx_adwpc_process_log_id left join tx_adwpc_dashboard_manual dm on dm.id = lo.tx_adwpc_dashboard_manual_id where cs.transaction_type = &#39;FINANCE&#39; and cs.transfer_type = &#39;C&#39; and cs.batch_no in :batchNo and cs.paid_no in :paidNo]]>
ตรวจสอบข้อมูลที่ได้จาก claimtx และ edw หากข้อมูลไม่เท่ากัน ระบบจะหยุดทำงาน และแจ้งเตือน Migrate ไม่สำเร็จ
2.ส่งข้อมูลไปยัง[WS Landing ข้อมูลรายการเช็ครอขึ้นเงินของธุรกรรม CS (Migrate)](/pages/viewpage.action?pageId=1350795401) โดยมี Input ดังนี้
โดย Group ข้อมูล edwProcessLogId

| Field | Type | Description | ตัวอย่างข้อมูล | Mapping Data |
|---|---|---|---|---|
| **ข้อมูลระดับ Voucher, Batch Payment** |

| paymentDate | Date | วันที่ตัดเงินจากบัญชีบริษัท | 2026-06-01 | paymentDate |

| totalTransaction | Numeric | จำนวนรายการรวม | 2 | Sum (จำนวนรายการที่ได้จาก claimtx โดยมี edwProcessLogId เดียวกัน) |

| approvedDate | DateTime | วันและเวลาที่อนุมัติ | 2025-08-01 08:00:00 | approvedDate |

| edwProcessLogId | Numeric | EDW Process Log Id | 1 | edwProcessLogId |
