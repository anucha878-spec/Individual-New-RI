1.เรียก [03 WS สำหรับ Call Program : OLIS/SPGN031 เพื่อขอ Sequence Id จากระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1289750156) **สำหรับข้อมูล Header** (Path : "/QSYS.LIB/OLIS.LIB/SPGN031R.PGM") โดยส่ง Parameter ดังต่อไปนี้

| Name | Description | Value |
|---|---|---|
| system | ชื่อระบบ | Fix "CNPAY" |
| table | ชื่อไฟล์ที่จะ Generate | Fix "BFPPAYHD" |
| year | ปีปัจจุบัน (ค.ศ.) | systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลข |
| month | เดือนปัจจุบัน | systemDate เอาเฉพาะเดือน เป็นตัวเลข |
| groupGen | กลุ่มที่จะ Generate | Null |
| totalKey | จำนวนรายการที่ต้องการจองเลข PK | 1 |

จากนั้น อ่านข้อมูล Output ของ WS ถ้า primaryFlag = "T" ให้เก็บข้อมูล headerID = seqPrimaryKey จาก WS
2.เรียก [03 WS สำหรับ Call Program : OLIS/SPGN031 เพื่อขอ Sequence Id จากระบบ AS400](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1289750156) **สำหรับข้อมูล Transaction** (Path : "/QSYS.LIB/OLIS.LIB/SPGN031R.PGM") โดยส่ง Parameter ดังต่อไปนี้

| Name | Description | Value |
|---|---|---|
| system | ชื่อระบบ | Fix "CNPAY" --> "APUTR" ปรับแก้จาก ariya.pi 6/11/2568 |
| table | ชื่อไฟล์ที่จะ Generate | Fix "BFPPAYTR" |
| year | ปีปัจจุบัน (ค.ศ.) | systemDate เอาเฉพาะปี คศ. 4 หลัก เป็นตัวเลข |
| month | เดือนปัจจุบัน | systemDate เอาเฉพาะเดือน เป็นตัวเลข |
| groupGen | กลุ่มที่จะ Generate | Null |
| totalKey | จำนวนรายการที่ต้องการจองเลข PK | 1 |

จากนั้น อ่านข้อมูล Output ของ WS ถ้า primaryFlag = "T" ให้เก็บข้อมูล transactionID = seqPrimaryKey จาก WS

| endorseNo | เลขที่สลักหลัง-- ปรับแก้ตาม กระบวนการแก้ไขกระบวนการนำเข้าข้อมูลการจ่ายเงินเพื่อบ้นทึก Update ข้อมูลที่ระบบ AS400 โดย ariya.pi เมือ 16/12/2568 | String | [tx_payment](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment).endorse_no |

| paymentRound | รอบการจ่าย | Numeric (2,0) | Fix 1 --> [tx_payment](http://wiki.thaisamut.co.th/display/RDSCPENH/tx_payment).payment_round ปรับแก้โดย ariya.pi 10/11/2568 |
| confirmPaymentDate | วันที่ยืนยันการจ่าย-- ปรับแก้ตาม กระบวนการแก้ไขกระบวนการนำเข้าข้อมูลการจ่ายเงินเพื่อบ้นทึก Update ข้อมูลที่ระบบ AS400 โดย ariya.pi เมือ 16/12/2568 | Date | Fix 0000-00-00 Format Date YYYY-MM-DD --> Null ปรับแก้โดย ariya.pi 10/11/2568 |

| chequeStatus | สถานะเช็ค | String | Null |

| createdBy | ผู้สร้างรายการ | String | Login User |
| createdProgram | โปรแกรมสร้างรายการ | String | Fix 'Delete Button' |

5.เรียก Update ข้อมูล AS400 ที่ WS : [02 WS Insert ข้อมูลเพื่อรอ Update ข้อมูลที่ระบบ AS400 บนตาราง MBFLIB.BFPPAYHD และ MBFLIB.BFPPAYTR](http://wiki.thaisamut.co.th/pages/viewpage.action?pageId=1286963782) โดยส่งข้อมูลดังนี้
