## Objectives

1. สร้าง File รายการทำจ่ายเพื่อส่งเข้าธนาคาร กรณีโอนเงินให้ บลจ. (TTB)

## Process Overview

1. เมื่อมีการยืนยันรายการคำสั่งซื้อกองทุนเรียบร้อยแล้ว
2. รายการเข้าระบบ Claim payment เพื่อทำการโอนเงินให้กับ บลจ.

## Precondition

1. ยืนยันรายการคำสั่งซื้อเพื่อโอนเงินให้กับ บลจ

## Input

- รายการรอทำจ่าย
