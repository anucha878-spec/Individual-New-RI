เพิ่มการตรวจสอบ Value ดังต่อไปนี้ เพื่อตรวจสอบความถูกต้องของข้อมูล ของชุดข้อมูลดังนี้
- 1. กรณีประเภทช่องทาง (isAgent)
  - ถ้าเป็น 'ALT' (Non Agent): autopostFlag ต้องเป็น 'N' เท่านั้น
  - ถ้าเป็น 'AGT' (Agent): autopostFlag เป็นได้ทั้ง 'Y' และ 'N' (ตรวจตามเงื่อนไขข้อ 2 และ 3)
- 2.กรณีสำนักงานใหญ่ (branch = '0001')
  - accBranch: ต้องเป็น 'HO' หรือ NULL เท่านั้น
  - autopostFlag: เป็นได้ทั้ง 'Y' หรือ 'N' (ขึ้นอยู่กับว่าต้องการส่งข้อมูลเข้าระบบอื่นต่อหรือไม่)
- 3. กรณีสาขา (branch ไม่ใช่ '0001')
  - ถ้า autopostFlag = 'Y' (ส่งบันทึกบัญชี): accBranch ต้องเป็น 'BRANCH'
  - ถ้า autopostFlag = 'N' (ไม่บันทึกบัญชีสาขา): accBranch ต้องเป็น 'NULL'
หากชุดข้อมูล input ไม่ผ่านเงื่อนไข Validation ข้อ (1.1 - 1.3) ให้ระบบหยุดการทำงานทันที และ Return Error Code ตามตาราง Exception เพื่อแจ้งผู้ใช้งาน
1. บันทึกสถานะอนุมัติรับฝาก และสถานะคืนรับฝาก ที่ TX_DEPOSIT_HEADER

| approve_datenattapong.che 18/11/65 | timestamp | นำค่าจาก depositDate มาบันทึกผล | 2021-08-02 09:00:000 |

2. กรณีที่ TX_DEPOSIT_HEADER.file_baac มีค่า ให้ทำการอัปเดท TX_DEPOSIT_HEADER.flag_baac มีค่า = Y
3. กรณีที่ TX_DEPOSIT_MONEY.is_cheque_return มีค่า = Y ให้ทำการอัปเดท TX_DEPOSIT_HEADER.flag_baac มีค่า = Y
4. กรณีที่ TX_DEPOSIT_MONEY.is_cheque_return มีค่า = Y แล้วมี TX_DEPOSIT_MONEY.moneyTypeCode มากกว่า 1 รายการ ให้ Error แล้วสิ้นสุดการทำงาน

## Exception

<อธิบายว่า มี exception อะไรที่ต้องจัดการหรือระวังบ้าง>

| Error Code | Error Message | สาเหตุ (Description) |
|---|---|---|
| **ERR-DEP-001** | สาขา 0001 ไม่รองรับการลงบัญชีแบบ BRANCH | ส่ง branch = '0001' แต่ระบุ accBranch = 'BRANCH' (สนญ. ต้องลงเป็น HO เท่านั้น) |
| **ERR-DEP-002** | ประเภท Non-Agent ไม่สามารถส่ง Autopost ได้ | ส่ง isAgent = 'ALT' แต่ระบุ autopostFlag = 'Y' |
| **ERR-DEP-003** | ข้อมูลการบันทึกบัญชีไม่ถูกต้องสำหรับ Flag N | ส่ง autopostFlag = 'N' แต่ระบุ accBranch เป็น 'BRANCH' |
| **ERR-DEP-004** | ข้อมูลการรับชำระไม่ถูกต้อง | ระบุ accBranch เป็น 'BRANCH' แต่ส่ง moneyTypeCode <> '01' |
