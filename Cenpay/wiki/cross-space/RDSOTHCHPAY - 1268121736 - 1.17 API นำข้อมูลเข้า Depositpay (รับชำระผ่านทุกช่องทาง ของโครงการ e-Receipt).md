## Objective

- API ของระบบ Depositpay
- เพื่อรับข้อมูลการชำระเบี้ยผ่านทุกช่องทาง สำหรับบันทึกยังระบบ MSA-Depositpay (ข้อมูลรายการรับชำระ)
- ตรวจสอบข้อมูลก่อนบันทึกข้อมูลลง MSA-Depositpay
- บันทึกข้อมูลลง MSA-Depositpay
- บันทึกข้อมูลลง เว็บรับฝาก (เป็นการตั้งรับฝากสาขา)
  - ยกเว้น รายการตัวแทนนำส่งเงิน จะไม่ทำการตั้งรับฝาก
- ส่งผลกลับไปให้ผู้เรียก MSA

## Overview

1. จัดเตรียมข้อมูลรายละเอียดข้อมูลการชำระเบี้ย
  1. จัดการข้อมูลที่รับมาจากทุกช่องทาง
  2. ค้นหาข้อมูลกรมธรรม์ ที่ระบบ AS400 แยกหาตามประเภทกรมธรรม์
2. นำข้อมูลที่ได้บันทึกลง ที่ MSA-Depositpay( Table [TX_HYDRA_IMPORT_HEADER](http://wiki.thaisamut.co.th/display/RDSTQP/TX_HYDRA_IMPORT_HEADER) และ [TX_HYDRA_IMPORT_DETAIL](http://wiki.thaisamut.co.th/display/RDSTQP/TX_HYDRA_IMPORT_DETAIL) )
3. นำข้อมูลบันทึกที่ ตั้งรับฝาก ทุกรายการที่ชำระด้วย ทุกช่องทาง
  1. กรณีที่บันทึกเว็บรับฝากไม่สำเร็จให้ update รายการที่ Table TX_HYDRA_IMPORT_HEADER และ TX_HYDRA_IMPORT_DETAIL
  2. กรณีที่บันทึกเว็บรับฝากสำเร็จ update ข้อมูล เลขที่รับฝาก และ วันที่รับฝาก Table TX_HYDRA_IMPORT_HEADER และ TX_HYDRA_IMPORT_DETAIL
4. Return สถานะการนำเข้าข้อมูลไปยังระบบต้นทาง
