## หน้าจอหลัก

หน้าจอสำหรับ สร้าง File ส่ง Outsource เพื่อออกจดหมาย
เดิม เมื่อทำการ กดปุ่ม "ดาวน์โหลดข้อมูล LD02" หรือ "ดาวน์โหลดข้อมูล LD03" ระบบจะทำการสร้าง text file เพื่อนำส่ง ให้กับทาง Vendor ทำการพิมพ์ จดหมาย
ใหม่ เมื่อทำการ กดปุ่ม "ดาวน์โหลดข้อมูล LD02" หรือ "ดาวน์โหลดข้อมูล LD03" ตัดการ Gen Text file และบันทึกข้อมูล รอ Process ระบบ Email Notification นำข้อมูล ไป ตรวจสอบการส่งจดหมาย ว่าเป็น Email หรือ จัดทำ File ส่งให้ Vendor โดยอัตโนมัติ
