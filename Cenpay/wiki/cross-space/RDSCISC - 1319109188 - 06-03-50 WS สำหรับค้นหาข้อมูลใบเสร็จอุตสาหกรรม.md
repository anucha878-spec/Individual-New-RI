| surrenderMark | String | Mark 1 = nc มาจากเวนคืน |   |
| allowMark | String | Mark 1=case อนุโลมค่าคอมเป็น 40% |   |
| affiliationMark | String | Mark สังกัดหน่วยงาน โดยที่ 0 = ปช. ,1 = ขพ . ,2 = sm. 3 = อื่น ๆ |   |
| caseTransferBook | String | เลขที่หนังสือโอน |   |
| paymentTerm | String | ระยะ/ชำระเบี้ย |   |
