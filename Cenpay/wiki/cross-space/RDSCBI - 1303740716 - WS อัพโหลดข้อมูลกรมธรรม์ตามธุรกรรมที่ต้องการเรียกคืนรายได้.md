## Process

**ข้อมูลตัวแทน**
1. ตรวจสอบ Require ของ Input Parameters
1.1 กรณีที่ส่งข้อมูลที่ Require มาไม่ครบ (null or emtry) >> ให้ระบบ Return Response status = FAIL :Message "policyNo is required.", "policyType is required." , "clawbackType is required.", "systemSource is required.","transactionDate is required.","systemKey is required."
** ให้แสดงข้อความแจ้งเตือนแค่ข้อมูล Field ที่ไม่ได้ส่งข้อมูลมา เช่น ขาดข้อมูลแค่ ชื่อระบบต้นทาง(systemSource) ให้แสดงข้อความ "systemSource is required."
1.2 ตรวจสอบว่า clawbackType ไม่พบค่าอยู่ในตาราง [CF_CATALOG](/display/RDSCBI/CF_CATALOG) >> ให้ระบบ Return Response status = FAIL :Message "clawbackType is invalid."
<![CDATA[select config_value1 from cf_catalog where config_type=&#39;CLAWBACK_TYPE&#39; and active_flag=&#39;Y&#39;]]>
1.3 กรณีที่ส่งข้อมูลที่ Require มาครบ และตรวจสอบ clawback_type มีค่าตาม ตาราง [CF_CATALOG](/display/RDSCBI/CF_CATALOG) >> ทำ Process ข้อ 2 ต่อ
2. นำข้อมูลลงที่ตาราง [TX_DEBT_LANDING](/display/RDSCBI/TX_DEBT_LANDING) ตาม mapping ดังนี้
