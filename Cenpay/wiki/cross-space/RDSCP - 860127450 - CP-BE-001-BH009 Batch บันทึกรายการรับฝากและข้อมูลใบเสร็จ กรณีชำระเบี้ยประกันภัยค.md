## Objectives

- เพื่อบันทึกรายการ รับฝากเบี้ยประกันภัยปีต่อ และ รับฝากเบี้ยเคสใหม่ ที่ฐานข้อมูลบนระบบรับฝาก
- เพื่อบันทึกรายการ เบี้ยประกันภัยค้างชำระ(งวดสุดท้าย),ชำระเบี้ยประกันภัยปีต่อ ที่ฐานข้อมูลบนระบบใบเสร็จส่วนกลาง

## Process Overview

![img](/download/attachments/860127450/image2021-9-20%2010%3A36%3A2.png?version=1&modificationDate=1632108962378&api=v2)

## Preconditions

- รายการชำระเบี้ยประกันภัยค้างชำระ(งวดสุดท้าย) ,ลงทะเบียนชำระเบี้ยประกันภัยปีต่อ และลงทะเบียนเคสใหม่ ที่มีการอนุมัติการจ่ายในขั้นที่ 2 และต้องเป็นการโอนครั้งแรก(เพิ่มวันที่ 05/08/2564) โดยวันที่ปัจจุบันมากกว่าหรือเท่ากับวันที่โอนจ่ายเงินให้ลูกค้า
- Batch ถูกตั้งทำงานทุกวัน ณ เวลา 04.00 น.

## Process Description

1. ระบบดึงข้อมูลรายการจ่ายเงินผลประโยชน์ ที่มีเบี้ยประกันภัยค้างชำระ(งวดสุดท้าย) หรือลงทะเบียนชำระเบี้ยประกันภัยปีต่อ หรือลงทะเบียนเคสใหม่ ที่มีการอนุมัติการจ่ายในขั้นที่ 2 และต้องเป็นการโอนครั้งแรก โดยวันที่ปัจจุบันมากกว่าหรือเท่ากับวันที่โอนจ่ายเงินให้ลูกค้ากรณียอดเงินสุทธิเท่ากับ 0 - วันที่ปัจจุบันมากกว่าเท่ากับวันที่โอนเงินผลประโยชน์ให้ลูกค้า(วันที่ Payment Date) และต้องยังไม่มีเลขที่รับฝาก กรณียอดเงินสุทธิมากกว่า 0 - วันที่ปัจจุบันมากกว่าเท่ากับวันที่โอนเงินผลประโยชน์ให้ลูกค้า(วันที่ Transfer Date) และต้องยังไม่มีเลขที่รับฝาก
2. จากรายการข้อ(1) ตรวจสอบว่ามีรายการลงทะเบียนเคสใหม่หรือไม่2.1. ถ้าพบว่ามีรายการลงทะเบียนเคสใหม่ อ้างอิงรายละเอียดจาก [Batch สำหรับตั้งรับฝากและบันทึกข้อมูลที่ระบบ Hydra](/pages/viewpage.action?pageId=905609304) 2.1.1. บันทึกรายการเข้าระบบรับฝาก 2.1.2. ทำการบันทึกรายการเข้าระบบ Auto Post 2.1.3. return เลขที่รับฝากกลับมาบันทึกที่ระบบ cenpay2.2. ถ้าไม่พบรายการลงทะเบียนเคสใหม่ให้ทำต่อในข้อ(3)
3. นำข้อมูลรายการชำระเบี้ยประกันปีต่อ หรือ เบี้ยประกันภัยค้างชำระ(เบี้ยงวดสุดท้าย) ที่ได้มาจากการทำขั้นตอน(2) มาทำรายการดังนี้มาตรวจสอบว่ามีหมายเหตุ "เรียกเก็บเงินเพิ่ม" หรือไม่ (update 05/08/2564)3.1. รายการที่ไม่พบหมายเหตุ "เรียกเก็บเงินเพิ่ม" ให้นำเข้าระบบใบเสร็จส่วนกลาง แยกตามประเภทรายการตามรายละเอียดด้านล่าง (update 05/08/2564)**3.1.1. ชำระเบี้ยปีต่อ** 3.1.1.1. บันทึกรายการรับฝากและรายการชำระเบี้ยที่ Hydra โดยอ้างอิงรายละเอียดจาก [Batch สำหรับตั้งรับฝากและบันทึกข้อมูลที่ระบบ Hydra](/pages/viewpage.action?pageId=905609304)3.1.1.2. ทำกระบวนการที่ระบบ Hermes โดยดึงข้อมูลจาก Hydra เข้า Hermes อ้างอิงกระบวนการจาก [1.CenPay-Batch-01 Batch สำหรับเรียก MSA เพื่อดึงข้อมูลชำระเงินเบี้ยปีต่อหรืองวดสุดท้ายผ่าน Centralized Payment บันทึกลง HERMES - PAYMENT_IMPORT_DETAIL](/pages/viewpage.action?pageId=905052503) ทุกๆ 10 นาที3.1.1.3. ทำกระบวนการที่ระบบ Hermes เพื่อประมวลผลใบเสร็จโดยอ้างอิงจาก: [2.CenPay-Batch-02 Batch สำหรับประมวลผลสร้างใบเสร็จ](/pages/viewpage.action?pageId=905609264)3.1.1.4. อัพเดทสถานะการลงทะเบียนหักชำระเบี้ย(ส่วนของการชำระเบี้ยปีต่อเท่านั้น)ที่ระบบ cenpay เป็น "นำส่งใบเสร็จส่วนกลางแล้ว **3.1.2. ชำระเบี้ยเบี้ยงวดสุดท้าย** 3.1.2.1. ส่งข้อมูลเพื่อบันทึกที่ระบบใบเสร็จส่วนกลาง Hydra .และสร้างเลขที่ใบเสร็จและวันที่ออกใบเสร็จ ของ "ดอกเบี้ยเบี้ยประกันภัยค้างชำระ" โดยจัดเก็บที่ฐานข้อมูลระบบ Centralized Payment โดยอ้างอิงรายละเอียดจาก [Batch สำหรับตั้งรับฝากและบันทึกข้อมูลที่ระบบ Hydra](/pages/viewpage.action?pageId=905609304)**********หมายเหตุ** กรณีครบสัญญาสามัญให้แตกงวดตามข้อมูลงวดใบเสร็จของAS400 ถ้ามีการค้างชำระเบี้ยมากกว่า 1 งวดก่อนส่งรายการเข้า Hydra3.1.2.2. ทำกระบวนการที่ระบบ Hermes โดยดึงข้อมูลจาก Hydra เข้า Hermes อ้างอิงกระบวนการจาก [1.CenPay-Batch-01 Batch สำหรับเรียก MSA เพื่อดึงข้อมูลชำระเงินเบี้ยปีต่อหรืองวดสุดท้ายผ่าน Centralized Payment บันทึกลง HERMES - PAYMENT_IMPORT_DETAIL](/pages/viewpage.action?pageId=905052503) ทุกๆ 10 นาที3.1.2.3. ทำกระบวนการที่ระบบ Hermes เพื่อประมวลผลใบเสร็จโดยอ้างอิงจาก: [2.CenPay-Batch-02 Batch สำหรับประมวลผลสร้างใบเสร็จ](/pages/viewpage.action?pageId=905609264) **หมายเหตุ** รับเลขที่ใบเสร็จ, วันที่ออกใบเสร็จ,เลขที่รับฝาก และวันที่รับฝาก เพื่อจัดเก็บที่ฐานข้อมูล Centralized Payment โดยอ้างอิงจาก [CP-BE-001-BH022 Batch สำหรับอัพเดทข้อมูลใบเสร็จชำระเบี้ยปีต่อ งวดสุดท้ายที่ Centralized Payment จากระบบใบเสร็จส่วนกลาง และสร้างเลขที่ใบเสร็จดอกเบี้ยเบี้ยค้างชำระ](/pages/viewpage.action?pageId=905609334)

## Post-conditions

1. บันทึกรายการ รับฝากเบี้ยประกันภัยปีต่อ และ รับฝากเบี้ยเคสใหม่ บนระบบรับฝาก
2. บันทึกรายการชำระเบี้ยประกันปีต่อ,เบี้ยประกันภัยค้างชำระ และ ดอกเบี้ยเบี้ยประกันภัยค้างชำระ บนระบบใบเสร็จส่วนกลาง
**Remark**
1) กรณีที่มีการ rollback รายการกรณี error table receipt ให้ทำการเปลี่ยนสถานะเป็น cancel
2) [HERMES - insert ข้อมูลบัญชีขาตั้งรับฝาก](/pages/viewpage.action?pageId=258900363) ต้องกรอง channel ที่เป็น cenpay ออกเพื่อไม่ให้ลงบัญชีขาตั้งซ้ำ
3) [HERMES - 12. รายงานข้อมูลใบเสร็จที่ส่งพิมพ์ Outsource Printing](/pages/viewpage.action?pageId=250937732) --> ให้ dev ตรวจสอบเพิ่มไม่ให้มีเคส cenpay กรณีแสดงที่เป็นใบเสร็จเบี้ยรายการค้างชำระ(เบี้ยงวดสุดท้าย)
4) กรณีเบี้ยค้างชำระหรือจ่ายเบี้ยปีต่อ อุตสาหกรรมมากกว่า1งวด - - สามารถส่งยอดรวมไปยังใบเสร็จส่วนกลางได้เลย โดยที่ระบบใบเสร็จส่วนกลางจะทำการแตกงวดเอง
