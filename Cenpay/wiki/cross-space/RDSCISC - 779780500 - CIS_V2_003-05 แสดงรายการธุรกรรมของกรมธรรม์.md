### เหตุการณ์ก่อนเข้าหน้าจอ

- เข้าระบบ NBS -> เลือกเมนู ลูกค้าสัมพันธ์ -> เลือกเมนู ระบบ CIS -> เลือกเมนู ข้อมูลลูกค้า -> กดปุ่มค้นหา -> ข้อมูลกรมธรรม์ -> เลือกธุรกรรม -> เลือกรายการธุรกรรมของกรมธรรม์

### ตารางคำอธิบาย

แสดงธุรกรรมที่กรมธรรม์นั้นสามารถทำได้ โดยแบ่งการแสดงออกเป็นหมวดหมู่ แต่ประเภทกรมธรรม์จะแสดงไม่เหมือนกัน
1. ประเภทอุตสาหกรรม จะแสดง
  1. สมัคร
  2. สลักหลัง
  3. การรับเรื่อง
  4. จ่ายตามเงื่อนไข
  5. เงินกู้
  6. ใบเสร็จอุตสาหกรรม
  7. ต่อสัญญา
  8. จดหมายแจ้งเตือน
2. ประเภทสามัญ จะแสดง
3. ประเภทอุบัติเหตุ จะแสดง
4. ประเภท Unit Link จะแสดง
