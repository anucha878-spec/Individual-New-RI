## Objectives

- นำเข้ารายการจ่ายเงินผลประโยชน์ และรายการไม่ผ่านตรวจสอบ ของแต่ละกรมธรรม์เข้าระบบ EDW และทำการประมวลข้อมูลบัญชี
- เมื่อมีการอนุมัติจากหน้าอนุมัติจ่ายและบันทึกบัญชี ระบบ Payment Management แล้วจะทำการ Trigger กลับมายังระบบ EDW เพื่อบันทึกบัญชี และสร้าง File SUN ส่งไปยัง Path ที่กำหนด
- ข้อมูลที่ระบบ EDW จะถูกนำไปใช้ต่อในการออกรายงาน IFRS17

## Process Overview

- นำเข้าข้อมูล Transaction จ่ายเงิน, รายการไม่ผ่านตรวจสอบ และค่าธรรมเนียมธนาคาร ของแต่ละกรมธรรม์เข้าระบบ EDW
- ทำการประมวลข้อมูลบัญชีและนำข้อมูลบัญชีกลับไปแสดงที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1275560833) ระบบ Payment Management
- เมื่อ user อนุมัติจ่ายและบันทึกบัญชี หรืออนุมัติบันทึกบัญชี ระบบจะทำการส่งข้อมูลกลับมาบันทึกที่ระบบ EDW
- ระบบทำการ Generate File SUN และส่งไปยัง Path ที่กำหนด เพื่อนำเข้าระบบ SUN ต่อไป
- Flow การทำงาน [https://app.diagrams.net/#G1qJtWCgXrzUQajyoL5yENY6a3UaJprQ6M#%7B%22pageId%22%3A%224HrWbLuUve8qX5SWq9_W%22%7D](https://app.diagrams.net/#G1qJtWCgXrzUQajyoL5yENY6a3UaJprQ6M#%7B%22pageId%22%3A%224HrWbLuUve8qX5SWq9_W%22%7D) Tab FLOW : 02_62_01 LANDING EDW (PM)![img](/download/attachments/1284571785/CenpayPh2-FLOW%20_%20LANDING%20EDW%20%28PM%29.drawio%20%281%29.png?version=1&modificationDate=1758446149365&api=v2)

## Preconditions

1. User ทำการยืนยันการตรวจสอบรายการ ดังนี้
  1. กด บันทึกผลการตรวจสอบ ที่ [หน้าจอค้นหา Generate Batch Payment](/pages/viewpage.action?pageId=1276117777)
  2. กด บันทึกผลการตรวจสอบ ที่ [หน้าจอ Paperbase Payment](/display/RDSCPENH/03-04-04+Paperbase+Payment+-+Checker) สิทธิ์เจ้าหน้าที่การเงิน Checker
2. ระบบ Payment Management ส่งข้อมูลTransaction จ่ายเงิน, รายการไม่ผ่านตรวจสอบ และค่าธรรมเนียมธนาคาร เข้าระบบ EDW
3. เมื่อข้อมูลส่งไปยังระบบ EDW แล้ว ระบบ EDW จะทำประมวลผลเก็บข้อมูลและบันทึกบัญชี จากนั้นข้อมูลจะถูกนำกลับไปแสดงที่หน้าจออนุมัติจ่ายและบันทึกบัญชี ระบบ Payment Management สิทธิเจ้าหน้าที่การเงิน Authorizer เพื่อทำการตรวจสอบและอนุมัติจ่ายและบันทึกบัญชี รายละเอียดการทำงานของหน้าจออนุมัติจ่ายและบันทึกบัญชี อ้างอิง Link [หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1275560833)

## Process Description

1. **Setting ผังบัญชี**
  1. ตั้งค่าผังบัญชีรายละเอียดอ้างอิงตาม [05_138 ระบบ Payment Management](/pages/viewpage.action?pageId=1284571542) หัวข้อผังบัญชี ข้อ 1 โดยทำการ Config ผังเพิ่มที่ [cf_event_code](http://wiki.thaisamut.co.th/display/RDSADW/cf_event_code) รายละเอียดการ Setting อ้างอิงหัวข้อใน Initial Data จาก Wiki event_code PM_FIN_01, PM_FIN_02, PM_FIN_03
  2. ตั้งค่าการบันทึกจำนวนเงินในผังบัญชีเพิ่มที่ [cf_adwpc_query_model](/display/RDSADW/cf_adwpc_query_model) รายละเอียดการ Setting อ้างอิงหัวข้อใน Initial Data event_code PM_FIN_01, PM_FIN_02, PM_FIN_03
2. **เ**มื่อกดอนุมัติจะนำเข้าข้อมูลจาก Table Landing ลงที่ EDW Core ทั้งหมด 2 กลุ่มข้อมูล และ **Gen file SUN**ดังนี้****
  1. event_code PM_FIN_01 รายการไม่ผ่านตรวจสอบ
    1. กลุ่มข้อมูล Transaction จะทำการบันทึกลง อ้างอิงการทำงานจาก [LANDING : Mapping Table Landing from Payment Management](/display/RDSADW/LANDING+%3A+Mapping+Table+Landing+from+Payment+Management) ข้อ 2.1 ในส่วนของ Mapping Field ตาม Model
