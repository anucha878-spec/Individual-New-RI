## Objectives

- นำเข้ารายการรับคืนเช็คหมดอายุ ของแต่ละกรมธรรม์เข้าระบบ EDW และทำการประมวลข้อมูลบัญชี
- เมื่อมีการอนุมัติจากหน้าอนุมัติจ่ายและบันทึกบัญชี ระบบ Payment Management แล้วจะทำการ Trigger กลับมายังระบบ EDW เพื่อบันทึกบัญชี และสร้าง File SUN ส่งไปยัง Path ที่กำหนด
- ข้อมูลที่ระบบ EDW จะถูกนำไปใช้ต่อในการออกรายงาน IFRS17

## Process Overview

- นำเข้าข้อมูล Transaction รับคืนเช็คหมดอายุ ของแต่ละกรมธรรม์เข้าระบบ EDW ผ่าน Batch: [PM-BH-003 อัปเดตสถานะเช็คหมดอายุ](/pages/viewpage.action?pageId=1293124517) ของระบบ Payment Management
- ทำการประมวลข้อมูลบัญชีและนำข้อมูลบัญชีกลับไปแสดงที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1275560833) ระบบ Payment Management
- เมื่อ user อนุมัติจ่ายและบันทึกบัญชี หรืออนุมัติบันทึกบัญชี ระบบจะทำการส่งข้อมูลกลับมาบันทึกที่ระบบ EDW
- ระบบทำการ Generate File SUN และส่งไปยัง Path ที่กำหนด เพื่อนำเข้าระบบ SUN ต่อไป
- Flow การทำงาน [https://app.diagrams.net/#G1qJtWCgXrzUQajyoL5yENY6a3UaJprQ6M#%7B%22pageId%22%3A%222wew1Dff1ASgdYx5W6Ya%22%7D](https://app.diagrams.net/#G1qJtWCgXrzUQajyoL5yENY6a3UaJprQ6M#%7B%22pageId%22%3A%222wew1Dff1ASgdYx5W6Ya%22%7D) Tab FLOW : 02_62_03 LANDING EDW (PM)![img](/download/attachments/1285881930/CenpayPh2-FLOW%20_%203.LANDING%20EDW%20%28PM%29.drawio.png?version=1&modificationDate=1758455669858&api=v2)

## Preconditions

1. Batch: [PM-BH-003 อัปเดตสถานะเช็คหมดอายุ](/pages/viewpage.action?pageId=1293124517) ของระบบ Payment Management ทำการประมวลผลและมีรายการเช็คหมดอายุ
2. Batch จะทำการส่งข้อมูลTransaction รับคืนเช็คหมดอายุ เข้าระบบ EDW
3. เมื่อข้อมูลส่งไปยังระบบ EDW แล้ว ระบบ EDW จะทำประมวลผลเก็บข้อมูลและบันทึกบัญชี จากนั้นข้อมูลจะถูกนำกลับไปแสดงที่หน้าจออนุมัติจ่ายและบันทึกบัญชี ระบบ Payment Management สิทธิเจ้าหน้าที่การเงิน Authorizer เพื่อทำการตรวจสอบและอนุมัติเพื่อบันทึกบัญชี รายละเอียดการทำงานของหน้าจออนุมัติจ่ายและบันทึกบัญชี อ้างอิง Link [หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1275560833)

## Process Description

1. **Setting ผังบัญชี**
  1. ตั้งค่าผังบัญชีรายละเอียดอ้างอิงตาม [05_138 ระบบ Payment Management](/pages/viewpage.action?pageId=1284571542) หัวข้อผังบัญชี ข้อ 1 โดยทำการ Config ผังเพิ่มที่ [cf_event_code](http://wiki.thaisamut.co.th/display/RDSADW/cf_event_code) รายละเอียดการ Setting อ้างอิงหัวข้อใน Initial Data จาก Wiki event_code PM_FIN_06
  2. ตั้งค่าการบันทึกจำนวนเงินในผังบัญชีเพิ่มที่ [cf_adwpc_query_model](/display/RDSADW/cf_adwpc_query_model) รายละเอียดการ Setting อ้างอิงหัวข้อใน Initial Data event_code PM_FIN_06
2. **เ**มื่อกดอนุมัติจะนำเข้าข้อมูลจาก Table Landing ลงที่ EDW Core ทั้งหมด 2 กลุ่มข้อมูล และ **Gen file SUN**ดังนี้****
  1. กลุ่มข้อมูล Transaction จะทำการบันทึกลงอ้างอิงการทำงานจาก [LANDING : Mapping Table Landing from Payment Management](/display/RDSADW/LANDING+%3A+Mapping+Table+Landing+from+Payment+Management) ข้อ 2.6 ในส่วนของ Mapping Field ตาม Model
    - [tx_adw_account_head](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_account_head)
    - [tx_adw_account_head_system](/pages/viewpage.action?pageId=759529628)
    - [tx_adw_transaction_policy](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_transaction_policy)
    - [tx_adw_transaction_detail](/display/RDSADW/tx_adw_transaction_detail)
    - [tx_adw_group_trans](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_group_trans)
    - [tx_adw_group_trans_detail](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_group_trans_detail)
    - [tx_adw_benefit_detail](/display/RDSADW/tx_adw_benefit_detail)
    - [tx_adw_bank_ho_detail](/display/RDSADW/tx_adw_bank_ho_detail)
    - ข้อมูลจาก Table Landing ดูจาก column Payment Management Landing
    - ข้อมูลปลายทางที่มาลงดูจาก column EDW Core
  2. กลุ่มข้อมูลการลงบัญชี ให้ดูจาก [LANDING : Mapping Table Landing from Payment Management](/display/RDSADW/LANDING+%3A+Mapping+Table+Landing+from+Payment+Management) ข้อ 2.6 ในส่วน Mapping ผังบัญชี กับ Table Landing บันทึกลง
    1. [tx_adw_double_entry_detail](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_double_entry_detail)
  3. การ Gen file SUN อ้างอิงการทำงานจาก [02_00_03_02 Process การสร้างข้อมูล File SAP สำหรับข้อมูล Payment](/pages/viewpage.action?pageId=878772596)

## Post-conditions

- ดำเนินการหมุนข้อมูลเข้า EDW Core
- นำข้อมูลไปแสดงที่เมนูตรวจสอบรายการ (รายงาน Query) [03_08 หน้าจอตรวจสอบรายการ EDW](/pages/viewpage.action?pageId=784400468)
