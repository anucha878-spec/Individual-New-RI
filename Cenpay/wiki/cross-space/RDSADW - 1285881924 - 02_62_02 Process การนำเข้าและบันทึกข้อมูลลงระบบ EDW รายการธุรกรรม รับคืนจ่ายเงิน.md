## Objectives

- นำเข้า Transaction รับคืนจ่ายเงินไม่สำเร็จ และรับคืนค่าธรรมเนียมธนาคาร (จ่ายไม่สำเร็จ) ของแต่ละกรมธรรม์เข้าระบบ EDW และทำการประมวลข้อมูลบัญชี
- เมื่อมีการอนุมัติจากหน้าอนุมัติจ่ายและบันทึกบัญชี ระบบ Payment Management แล้วจะทำการ Trigger กลับมายังระบบ EDW เพื่อบันทึกบัญชี และสร้าง File SUN ส่งไปยัง Path ที่กำหนด
- ข้อมูลที่ระบบ EDW จะถูกนำไปใช้ต่อในการออกรายงาน IFRS17

## Process Overview

- นำเข้าข้อมูล Transaction รับคืนจ่ายเงินไม่สำเร็จ และรับคืนค่าธรรมเนียมธนาคาร (จ่ายไม่สำเร็จ) ของแต่ละกรมธรรม์เข้าระบบ EDW
- ทำการประมวลข้อมูลบัญชีและนำข้อมูลบัญชีกลับไปแสดงที่[หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1275560833) ระบบ Payment Management
- เมื่อ user อนุมัติจ่ายและบันทึกบัญชี หรืออนุมัติบันทึกบัญชี ระบบจะทำการส่งข้อมูลกลับมาบันทึกที่ระบบ EDW
- ระบบทำการ Generate File SUN และส่งไปยัง Path ที่กำหนด เพื่อนำเข้าระบบ SUN ต่อไป

## Preconditions

1. User ทำการบันทึกผลการโอนเงิน ที่ [หน้าจอบันทึกผลการจ่าย](/pages/viewpage.action?pageId=1275560769) ระบบ Payment Management ดังนี้
  1. บันทึกผลการโอนเงินไม่สำเร็จ กรณีช่องทางการจ่ายเงินเป็น โอนเงิน
  2. ยกเลิกเช็ค กรณีช่องทางการจ่ายเงินเป็น เช็ค
  3. ยกเลิกรหัสรับเงิน BBL กรณีช่องทางการจ่ายเงินเป็น รหัสรับเงิน BBL
2. ระบบ Payment Management ส่งข้อมูลTransaction รับคืนจ่ายเงินไม่สำเร็จ, รับคืนค่าธรรมเนียมธนาคาร (จ่ายไม่สำเร็จ) เข้าระบบ EDW
3. เมื่อข้อมูลส่งไปยังระบบ EDW แล้ว ระบบ EDW จะทำประมวลผลเก็บข้อมูลและบันทึกบัญชี จากนั้นข้อมูลจะถูกนำกลับไปแสดงที่หน้าจออนุมัติจ่ายและบันทึกบัญชี ระบบ Payment Management สิทธิเจ้าหน้าที่การเงิน Authorizer เพื่อทำการตรวจสอบและอนุมัติเพื่อบันทึกบัญชี รายละเอียดการทำงานของหน้าจออนุมัติจ่ายและบันทึกบัญชี อ้างอิง Link [หน้าจออนุมัติจ่ายและบันทึกบัญชี](/pages/viewpage.action?pageId=1275560833)

## Process Description

1. **Setting ผังบัญชี**
  1. ตั้งค่าผังบัญชีรายละเอียดอ้างอิงตาม [05_138 ระบบ Payment Management](/pages/viewpage.action?pageId=1284571542) หัวข้อผังบัญชี ข้อ 1 โดยทำการ Config ผังเพิ่มที่ [cf_event_code](http://wiki.thaisamut.co.th/display/RDSADW/cf_event_code) รายละเอียดการ Setting อ้างอิงหัวข้อใน Initial Data จาก Wiki event_code PM_FIN_04, PM_FIN_05
  2. ตั้งค่าการบันทึกจำนวนเงินในผังบัญชีเพิ่มที่ [cf_adwpc_query_model](/display/RDSADW/cf_adwpc_query_model) รายละเอียดการ Setting อ้างอิงหัวข้อใน Initial Data event_code PM_FIN_04, PM_FIN_05
2. **เ**มื่อกดอนุมัติจะนำเข้าข้อมูลจาก Table Landing ลงที่ EDW Core ทั้งหมด 2 กลุ่มข้อมูล และ **Gen file SUN**ดังนี้****
  1. event_code PM_FIN_04 รับคืนจ่ายเงินไม่สำเร็จ
    1. กลุ่มข้อมูล Transaction จะทำการบันทึกลงอ้างอิงการทำงานจาก [LANDING : Mapping Table Landing from Payment Management](/display/RDSADW/LANDING+%3A+Mapping+Table+Landing+from+Payment+Management) ข้อ 2.4 ในส่วนของ Mapping Field ตาม Model
      - [tx_adw_account_head](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_account_head)
      - [tx_adw_account_head_system](/pages/viewpage.action?pageId=759529628)
      - [tx_adw_transaction_policy](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_transaction_policy)
      - [tx_adw_transaction_detail](/display/RDSADW/tx_adw_transaction_detail)
      - [tx_adw_group_trans](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_group_trans)
      - [tx_adw_group_trans_detail](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_group_trans_detail)
      - [tx_adw_benefit_detail](/display/RDSADW/tx_adw_benefit_detail)
      - [tx_adw_bank_ho_detail](/display/RDSADW/tx_adw_bank_ho_detail)
      - ข้อมูลจาก Table Landing ดูจาก column Payment Management Landing
      - ข้อมูลปลายทางที่มาลงดูจาก column EDW Core
    2. กลุ่มข้อมูลการลงบัญชี ให้ดูจาก [LANDING : Mapping Table Landing from Payment Management](/display/RDSADW/LANDING+%3A+Mapping+Table+Landing+from+Payment+Management) ข้อ 2.4 ในส่วน Mapping ผังบัญชี กับ Table Landing บันทึกลง
      - [tx_adw_double_entry_detail](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_double_entry_detail)
    3. การ Gen file sap อ้างอิงการทำงานจาก [02_00_03_02 Process การสร้างข้อมูล File SAP สำหรับข้อมูล Payment](/pages/viewpage.action?pageId=878772596)
  2. event_code PM_FIN_05 รับคืนค่าธรรมเนียมธนาคาร (จ่ายไม่สำเร็จ)
    1. กลุ่มข้อมูล Transaction จะทำการบันทึกลงอ้างอิงการทำงานจาก [LANDING : Mapping Table Landing from Payment Management](/display/RDSADW/LANDING+%3A+Mapping+Table+Landing+from+Payment+Management) ข้อ 2.5 ในส่วนของ Mapping Field ตาม Model
      - [tx_adw_account_head](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_account_head)
      - [tx_adw_account_head_system](/pages/viewpage.action?pageId=759529628)
      - [tx_adw_group_trans](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_group_trans)
      - [tx_adw_group_trans_detail](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_group_trans_detail)
      - [tx_adw_bank_ho_detail](/display/RDSADW/tx_adw_bank_ho_detail)
      - [tx_adw_operating_expense_detail](/display/RDSADW/tx_adw_operating_expense_detail)
      - ข้อมูลจาก Table Landing ดูจาก column Payment Management Landing
      - ข้อมูลปลายทางที่มาลงดูจาก column EDW Core
    2. กลุ่มข้อมูลการลงบัญชี ให้ดูจาก [LANDING : Mapping Table Landing from Payment Management](/display/RDSADW/LANDING+%3A+Mapping+Table+Landing+from+Payment+Management) ข้อ 2.5 ในส่วน Mapping ผังบัญชี กับ Table Landing บันทึกลง
      - [tx_adw_double_entry_detail](http://wiki.thaisamut.co.th/display/RDSADW/tx_adw_double_entry_detail)
    3. การ Gen file SUN อ้างอิงการทำงานจาก [02_00_03_02 Process การสร้างข้อมูล File SAP สำหรับข้อมูล Payment](/pages/viewpage.action?pageId=878772596)

## Post-conditions

- ดำเนินการหมุนข้อมูลเข้า EDW Core
- นำข้อมูลไปแสดงที่เมนูตรวจสอบรายการ (รายงาน Query) [03_08 หน้าจอตรวจสอบรายการ EDW](/pages/viewpage.action?pageId=784400468)
