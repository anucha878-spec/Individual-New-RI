## Input

<แสดงข้อมูล Parameter ที่ระบบนี้จะต้องส่งไปยัง external service>

| Name | Type | Description | Example | Validation |
|---|---|---|---|---|
| cardId | String | เลขบัตรประชาชน/เลขที่หนังสือเดินทาง | 1225887491627 | Not Null |
| clientName | String | ชื่อภาษาไทย/ชื่ออังกฤษ/ชื่อเดิม | ทดสอบ | Not Null |
| clientSurname | String | นามสกุลภาษาไทย/นามสกุลอังกฤษ/นามสกุลเดิม | นามสมมติ | Not Null |

## Process

|   | ฟิลด์ที่ตรวจสอบ | ตรวจสอบที่ |
|---|---|---|
| 1 | นำชื่อ และ นามสกุล ของผู้ขอเอาประกันและผู้ชำระเบี้ยประกันไปตรวจสอบ | select * from batch_filter where first_name = '@clientName' and surname = '@clientSurname'หากพบข้อมูลถือว่า ติดปปง. ---> return @hit = trueหากไม่พบข้อมูลถือว่า ไม่ติดปปง. ---> return @hit = false |
| 2 | นำชื่อ+นามสกุล ของผู้ขอเอาประกันและผู้ชำระเบี้ยประกันไปตรวจสอบ | select * from batch_filter where single_string_name = '@clientName+@clientSurname'หากพบข้อมูลถือว่า ติดปปง. ---> return @hit = trueหากไม่พบข้อมูลถือว่า ไม่ติดปปง. ---> return @hit = false |
| 3 | นำเลขบัตรประชาชนของผู้ขอเอาประกันและผู้ชำระเบี้ยประกันไปตรวจสอบ | select * from batch_filter where id_value = '@cardId'หากพบข้อมูลถือว่า ติดปปง. ---> return @hit = trueหากไม่พบข้อมูลถือว่า ไม่ติดปปง. ---> return @hit = false |

| sourceId | String | แหล่งข้อมูล | [PEP-01-A-009] |
