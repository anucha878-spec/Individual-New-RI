### ขั้นตอนการส่ง OTP เพื่อยืนยันยกเลิกใบคำขอ

## Objectives

- เมื่อผู้ขอเอาประกันภัย ขอยกเลิกใบคำขอ ผ่านระบบ E-Application เรียบร้อยแล้ว ผู้ขอเอาประกันภัย จะทำการยืนยันผ่าน รหัส OTP ด้วย เบอร์โทรศัพท์มือถือ ที่ระบุไว้ในใบคำขอ tab:ที่อยู่ของผู้ขอเอาประกันภัย [[Ref. UIที่อยู่ ผู้เอาประกัน]](/pages/viewpage.action?pageId=710967370)

| **Step การทำงาน** เมื่อผู้ขอเอาประกันภัย กดที่ **ปุ่ม "ยืนยันการยกเลิกคำขอเอาประกันภัย" จาก Pop-Up** หรือ ปุ่ม **"ดำเนินการยกเลิกคำขอเอาประกันภัย" จาก หน้าจอกรอกข้อมูลบัญชีเงินฝากที่ต้องการรับเบี้ยประกันภัยคืน กรณีชำระเบี้ยด้วย Thai QR** [[Ref:UI-ยกเลิกใบคำขอ]](/pages/viewpage.action?pageId=923140250) ระบบจะทำการ ส่ง OTP ไปยังเบอร์โทรศัพท์มือถือของผู้ขอเอาประกันภัย [Eros-rn call msa-app [service Generate OTP](/pages/viewpage.action?pageId=912556313)] **Process ข้อ 2.**โดยระบบ **msa-application** จะ **[call service msa-otp generate OTP](/display/RDSEAPP/01-WS-Generate+OTP)** เพื่อทำการ Generate OTP ขั้นตอนดังนี้**(****ใน Process ข้อ 2 จะทำงานอยู่ที่ ระบบ msa-otp )** 2.1 ระบบจะทำการตรวจสอบว่า เลขที่ใบคำขอนี้ เคยมีส่งขอ OTP หรือไม่ โดยเงื่อนที่ใช้ในการตรวจสอบ คือ จะใช้ input parameters >> userId และ appId ไปตรวจสอบข้อมูล ที่ **DB:OTP****table msa_otp**ถ้าผลลัพธ์ ของ Query เป็น **Not null และ วันที่เวลาในการ generate otp ( table msa_otp .created_date) + 1 นาที > current date**หมายถึง เคยมีการส่ง OTP และ รหัส OTP ยังไม่หมดอายุ ระบบจะทำการส่ง Response Msg กลับมาดังนี้ "CANNOT_CREATE_OTP("OTP01","Can't issue OTP.")" และหน้าจอจะแสดง **alert message แจ้งเตือน** "รายการ OTP Code :xxxx ยังไม่หมดอายุ" Ref:UI Alert Msg ![img](/download/attachments/912228544/MSG-02.PNG?version=1&modificationDate=1636370215529&api=v2) ถ้าผลลัพธ์ ของ Query เป็น **Null**หมายถึง ยังไม่เคยมีการส่ง OTP โดยระบบทำการ Generate OTP และ insert data ที่ Table:msa_otp เพื่อใช้ข้อมูลนี้สำหรับส่ง SMS OTP Process ข้อ 3. ระบบจะทำการส่ง Response msg "SUCCESS("OTP00","Success")" และ หน้าจอจะแสดง **alert message สำเร็จ** "ระบบส่งรหัส OTP ให้ทางโทรศัพท์ของท่าน ตามหมายเลข xx-xxxx-4323 ทีบันทึกไว้ในระบบเรียบร้อยแล้ว " และเมื่อกดปุ่มตกลง ระบบจะ Redirect ไปยังหน้าจอ [[Ref UI:3.1.21 OTP]](/display/RDSEAPP/3.1.22+OTP) Process ข้อ 4.
