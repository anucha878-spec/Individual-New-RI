## **Overview**

- API สำหรับรองรับเรียกใช้เพื่อตรวจสอบจดหมายตีกลับ
- ระบบจะประมวลผลตรวจสอบข้อมูลจากตาราง [TX_BOUNCE_LETTER](/display/RDSBLT/TX_BOUNCE_LETTER)

## **Preconditions**

1. ระบบต้นทางเรียกใช้ API เพื่อดึงข้อมูลจดหมายตีกลับ
2. รายการประเภทจดหมายต้องมีอยู่ใน [MS_LETTER_REGISTER](/display/RDSBLT/MS_LETTER_REGISTER) ตรงกันระหว่างระบบต้นทางและระบบจดหมายตีกลับ
3. ตรวจสอบข้อมูลด้วย Barcode จดหมายในตาราง [TX_BOUNCE_LETTER](/display/RDSBLT/TX_BOUNCE_LETTER)

## **Input Parameter**

<ข้อมูล Input แบ่งออกเป็น 2 ส่วน: Header Level และ Detail Level >
- ตาราง [TX_BOUNCE_LETTER](/display/RDSBLT/TX_BOUNCE_LETTER) (ข้อมูลจดหมายตีกลับ)
- ตาราง [MS_BOUNCE_CAUSE](/display/RDSBLT/MS_BOUNCE_CAUSE) (ข้อมูลสาเหตุที่จดหมายตีกลับ)

| Parameter Name | Type | Description | Required/ Optional | Validation | Example |
|---|---|---|---|---|---|
| letter_code | String | รหัสประเภทจดหมาย | Required | รองรับรหัสประเภทจดหมาย 3 หลัก | 99 |
| returnStartDate | timestamp | วันที่บันทึกตีกลับ | Required | วันที่บันทึกตีกลับ ต้องน้อยกว่าเท่ากับ วันที่ ถึงวันที่บันทึกตีกลับ | 2026-10-10 |
| returnEndDate | timestamp | ถึงวันที่บันทึกตีกลับ | Required | ถึงวันที่บันทึกตีกลับ ต้องมากกว่าเท่ากับ วันที่บันทึกตีกลับ | 2026-10-10 |
