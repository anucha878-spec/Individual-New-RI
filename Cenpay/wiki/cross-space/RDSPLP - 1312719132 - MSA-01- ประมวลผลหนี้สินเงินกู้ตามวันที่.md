## Overview

มีหน้าที่รับข้อมูลเงื่อนไขที่จำเป็นสำหรับการคำนวณยอดหนี้เงินกู้ เพื่อนำไปใช้ในการประมวลผลยอดหนี้ที่ต้องชำระ
รองรับเงินกู้
- **PL (Policy Loan)**
- **APL (Automatic Premium Loan)**
**ระบบที่เรียกใช้**

| No | ระบบ | รายละเอียด |
|---|---|---|
| 1 | Cenpay | เรียกใช้เมื่อมีการคำนวณหนี้สินเพื่อไปเตรียมบันทึกบัญชี |
| 2 | I-service | เรียกใช้เมื่อคำนวณหนี้สินสำหรับกู้และขารับชำระ |
| 3 | CS(Claim System) | เรียกใช้กรณีคำนวณหนี้สินเพื่อไป Offset หนี้สิน |

MSA Service : [https://intranet-api.ochi.link/thaisamut/pub/newloan/swagger#/loan/getLoanDebt](https://intranet-api.ochi.link/thaisamut/pub/newloan/swagger#/loan/getLoanDebt)

## Input

<แสดงข้อมูล Parameter ที่ต้องการ>

| Name | Type | Description | Required/Optional | Example | Validation |
|---|---|---|---|---|---|
| policyNo | string | เลขที่กรมธรรม์ | Required | 0018239 | - |
| policyType | string (Enum) | ประเภทกรมธรรม์ \nORD : สามัญ \nIND : อุตสาหกรรม | Required | ORD | ต้องเป็นค่า `ORD` หรือ `IND` |
| debtCalulateDate | Date | วันที่และเวลาที่ใช้คำนวณหนี้สินวันที่จ่าย/ชำระเงินกู้หมายเหตุ : ระบบจะคำนวณหนี้สินถึงวันที่จ่าย/ชำระเงินกู้ - 1 วัน (Athikan.pa ปรับ 07/04/2026) | Required | 2026-04-02T05:43:53.496Z |   |
| loanType | string (Enum) | ประเภทเงินกู้APLPL | Optional | PL | ต้องเป็นค่า `APL` หรือ `PL` |

Business Rule
- กรณีไม่ระบุ `loanType` ให้คำนวณหนี้สินของทุกประเภทเงินกู้
- วันที่คำนวณหนี้สิน : ระบบจะคำนวณหนี้สินถึง วันที่คำนวณหนี้สิน (แบบInclusive)
  - ตัวอย่าง กรณีที่ลูกค้ามาชำระหนี้สิน วันที่ 30/01/2026 แล้วต้องคำนวณหนี้สิน ถึงวันที่ 29/01/2026 (วันที่ชำระ -1 วัน) ระบบต้นทางที่เรียกใช้ต้อง ส่งวันที่คำนวณหนี้สิน(debtCalulateDate) = 29/01/2026 30/01/2026 (Athikan.pa ปรับ 07/04/2026)

## Process

ดึงข้อมูลจาก ESB และประมวลผล Output อ้างอิงตาม
[P-02-Core Process การคำนวณหนี้สินเงินกู้ตามวันที่](/pages/viewpage.action?pageId=1312097006)
****
**คำอธิบายเพิ่มเติม (สำหรับ Cenpay)**
คลิกดูรายละเอียด
กรณีไม่ได้ระบุ **loanType** Service จะ Return Output ของเงินกู้ทั้ง APL และ PL ไปพร้อมกัน (ุถ้ามี)
กรณีที่ต้องการแยกหนี้เงินกู้ ตามความหมายของการบันทึกบัญชี

| No | Loan Type | Accounting Description | Loan Description | Field | Remark |
|---|---|---|---|---|---|
| 1 | PL | เงินกู้ประกันชีวิต | หนี้สินเงินต้นของเงินกู้ตามกรมธรรม์ (PL) | principal |   |
| 2 | PL | ดอกเบี้ยรับ-เงินกู้ประกันชีวิต | ดอกเบี้ยทบต้น + ดอกเบี้ยค้างรับ + ดอกเบี้ยระหว่างวัน | compoundInterest +accruedInterest+accruedIncome | เนื่องจากฝั่งบัญชีมองดอกเบี้ยเป็น GL เดียวกัน |
| 3 | APL | เงินกู้ประกันชีวิตอัตโนมัติ APL | หนี้สินเงินต้นของเงินกู้ APL | principal |   |
| 4 | APL | ดอกเบี้ยรับทบต้น APL | ดอกเบี้ยทบต้น | compoundInterest |   |
| 5 | APL | ดอกเบี้ยเงินกู้ค้างรับ APL | ดอกเบี้ยค้างรับ = ดอกเบี้ยค้างรับ(คิดเต็มวันได้)+ดอกเบี้ยไม่เต็มวันรวมเรียกว่า ดอกเบี้ยระหว่างปี | accruedInterest+accruedIncome | เนื่องจาก APL จะแยก GL ดอกเบี้ยเป็น 2ตัว คือ ทบต้นและค้างรับ |
