## Process

**ขั้นตอนที่ 1: ตรวจสอบรายการธุรกรรม และ การจ่ายเงินคืน**
เมื่อได้รับค่า `request_no` หรือ `policy_no` ให้เริ่มตรวจสอบสถานะจากตารางการเปลี่ยนแปลงกรมธรรม์ก่อน
- ให้ดำเนินการ Query ข้อมูลจากตาราง [TPSHAL01 (POLICY HEAD ALTERATION )](/pages/viewpage.action?pageId=583139550) และ ตาราง [TPSRFP01 (REFUND REQUEST)](/pages/viewpage.action?pageId=566887253)
- เงื่อนไขการตรวจสอบ:
  - กรณีที่ 1: หากสถานะอนุมัติ "ไม่เท่ากับ อนุมัติ" (เช่น อยู่ระหว่างพิจารณา หรือ ยกเลิก)
    - ให้หยุดการค้นหาและส่งสถานะนั้นเป็น Output ทันที
  - กรณีที่ 2: หากสถานะอนุมัติ "เท่ากับ อนุมัติ"
    - ให้ดำเนินการต่อในขั้นตอนที่ 1.1

#### ขั้นตอนที่ 1.1: ตรวจสอบสถานะการจ่ายเงินคืน

  - ให้ตรวจสอบ paymentDate และ paymentName ก่อน
    - ถ้ามี ให้ return สถานะการจ่าย
  - นำสถานะการอนุมัติจ่ายเงินคืนที่พบจากตารางนี้ ส่งกลับเป็น Output
    - หากสถานะอนุมัติ "เท่ากับ อนุมัติ"
**ขั้นตอนที่ 2: ตรวจสอบรายการนำเข้าข้อมูลที่ตาราง**[TPSCPY01 ตาราง landing ข้อมูลคำร้องจากระบบ cenpay](/pages/viewpage.action?pageId=1317405423)
ในกรณีที่ ค้นหาข้อมูลในขั้นตอนที่ 1 ไม่พบ ให้ตรวจสอบย้อนกลับไปที่ข้อมูลขาเข้าจากต้นทาง
- ให้ดำเนินการ Query ข้อมูลจากตาราง [TPSCPY01 ตาราง landing ข้อมูลคำร้องจากระบบ cenpay](/pages/viewpage.action?pageId=1317405423)
- เพื่อตรวจสอบว่าคำร้องถูกส่งจากระบบ Cenpay เข้ามาถึงระบบ UL แล้วหรือยัง
- นำสถานะการนำเข้าข้อมูล (Import Status) จากตารางนี้ ส่งกลับเป็น Output
**ขั้นตอนการประมวลผล**
**ค้นหาสถานะรายการอนุมัติธุรกรรม และ สถานะรายการอนุมัติการจ่ายเงินคืน**
SQL Script
<![CDATA[select h.cprnvc as requestNo ,h.polnvc as policyNo ,CASE WHEN p.srfpnm IS NOT NULL THEN &#39;P&#39; || p.srfpnm WHEN r.srfpnm IS NOT NULL THEN &#39;R&#39; || r.srfpnm ELSE &#39;H&#39; || h.alstnm END as statusCode ,CASE WHEN p.srfpnm IS NOT NULL THEN ps.alstvc WHEN r.srfpnm IS NOT NULL THEN rs.alstvc ELSE hs.alstvc END as statusDescription ,c.remkvc as remark ,COALESCE(p.upbyvc, r.upbyvc, h.upbyvc) as createdBy ,CASE WHEN p.updadt IS NOT NULL AND length(CAST(p.updadt AS text)) = 17 THEN to_timestamp(CAST(p.updadt AS text), &#39;YYYYMMDDHH24MISSMS&#39;) WHEN r.updadt IS NOT NULL AND length(CAST(r.updadt AS text)) = 17 THEN to_timestamp(CAST(r.updadt AS text), &#39;YYYYMMDDHH24MISSMS&#39;) WHEN h.updadt IS NOT NULL AND length(CAST(h.updadt AS text)) = 17 THEN to_timestamp(CAST(h.updadt AS text), &#39;YYYYMMDDHH24MISSMS&#39;) END as createdDate from tpshal01 h left join ccmalt01 hs on h.alstnm = hs.alstnm left join tpsalt08 c on h.altrid = c.altrid left join tpsrfp01 r on h.altrid = r.altrid left join ccmalt01 rs on r.srfpnm = rs.alstnm left join tpsrfp02 p on r.rfrqid = p.rfrqid left join ccmalt01 ps on p.srfpnm = ps.alstnm where h.altynm in (14,15) and h.rqchvc = &#39;C&#39; and (h.cprnvc || &#39;|&#39; || h.polnvc) in (:requestKeys) -- ตัวอย่าง requestKeys -&gt; &#39;F2568-02/1500/000001|UL00001248&#39; ]]>

<![CDATA[SELECT rqnovc AS requestNo, polnvc AS policyNo, imstnm AS statusCode, CASE WHEN imstnm = &#39;1&#39; THEN &#39;Pending Import&#39; WHEN imstnm = &#39;2&#39; THEN &#39;Processing&#39; WHEN imstnm = &#39;3&#39; THEN &#39;Fund Trading&#39; WHEN imstnm = &#39;4&#39; THEN &#39;Import Failed&#39; WHEN imstnm = &#39;5&#39; THEN &#39;Import Success&#39; ELSE &#39;Not Found&#39; END AS statusDescription, remkvc AS remark, CASE WHEN updadt IS NOT NULL AND length(CAST(updadt AS text)) = 17 THEN to_timestamp(CAST(updadt AS text), &#39;YYYYMMDDHH24MISSMS&#39;) END as createdDate, upbyvc AS createdBy FROM tpscpy01 WHERE (rqnovc || &#39;|&#39; || polnvc) IN (:keyFindStatus) -- ตัวอย่าง keyFindStatus -&gt; &#39;F2568-02/1500/000001|UL00001248&#39; ]]>
