## **Overview**

- API สำหรับรองรับข้อมูลจดหมายส่งออกจากระบบงานภายนอก ที่ไม่ได้จัดส่งผ่านระบบจดหมายส่งออก ( Email Notification )
- ระบบจะประมวลผลจัดเก็บข้อมูลลงตาราง TX_HEADER_LETTER_EXT (ข้อมูล Header จดหมาย) และ TX_DETAIL_LETTER_EXT (ข้อมูลรายละเอียดจดหมาย)
- รองรับข้อมูลจดหมายส่งออกรูปแบบไปรษณีย์ที่ส่งออกจากทุกระบบงาน พร้อมบันทึกและติดตามสถานะการดำเนินงานตลอดกระบวนการ

## **Preconditions**

1. ระบบต้นทางสร้างข้อมูลจดหมายส่งออกได้สำเร็จ แล้วจึงเรียกใช้ API ส่งข้อมูลเข้าระบบจดหมายตีกลับ
2. รายการประเภทจดหมายต้องมีอยู่ใน [MS_LETTER_REGISTER](/display/RDSBLT/MS_LETTER_REGISTER) ตรงกันระหว่างระบบต้นทางและระบบจดหมายตีกลับ
3. อ้างอิงการบันทึกประเภทจดหมายตามหน้าจอ :: [บันทึกประเภทจดหมาย](/pages/viewpage.action?pageId=779485279)

## **Input Parameter**

<ข้อมูล Input แบ่งออกเป็น 2 ส่วน: Header Level และ Detail Level >

| Parameter Name | Type | Description | Required/ Optional | Validation | Example |
|---|---|---|---|---|---|
| letterCode | String | รหัสประเภทจดหมาย | Required | รองรับรหัสสูงสุด 3 หลักประกอบด้วยตัวอักษรและตัวเลข (Alphanumeric) | 99 |
| letterNameAbbr | String | ชื่อย่อจดหมาย | Required | รองรับรหัสสูงสุด 4 หลักประกอบด้วยตัวอักษรและตัวเลข (Alphanumeric) | LL02 |
| letterNameFull | String | ชื่อประเภทจดหมาย (เต็ม) | Required | รองรับ 255 ตัวอักษร | ใบแจ้งข้อมูลการกู้ยืมเงินและดอกเบี้ยเงินกู้ |

## **Output**

<ระบบจะตอบสถานะการบันทึกข้อมูลของแต่ละรายการกลับไปให้ระบบต้นทาง>

| Param Name | Type | Description | Example |
|---|---|---|---|
| responseCode | String | รหัสสถานะของผลลัพธ์การส่งข้อมูล** รายละเอียดใน Exception | S01 |
| responseMessage | String | รายละเอียดผลลัพธ์การส่งข้อมูล หรือข้อผิดพลาด | Sucess |
| createdDate | Timestamp | วันที่สร้างหรือบันทึกรายการ | - |

## Exception

| responseCode | responseMessage | คำอธิบาย |
|---|---|---|
| S01 | Sucess | `ดำเนินการบันทึกข้อมูลสำเร็จ` |
| E01 | ไม่พบข้อมูลจดหมาย letterCode, letterNameAbbr |   |
| E02 | เกิดข้อผิดพลาดข้อมูล Input Parameter |   |
| E99 | Service Unavailable เกิดข้อผิดพลาดในระบบกรณีอื่น ๆ |   |
